## 0. 요약

1. **하루 = 잠 한 번.** 낮(한지)·밤(수면) 화면은 몽망이가 깨어 있는지를 따른다. 깸 = 깰 수 있는 시각 `max(잠든 뒤 6h, 잠든 뒤 처음 오는 아침 시각, 지난 깸 + 12h)`(앱이 닫혀 있어도 그 시각에 깬다), 아침 연출(현상) = 그 뒤 첫 방문. 첫날은 예외로 바로 잘 수 있다(C3).
2. **하루 세 박자.** 아침 = 현상(물 위 한지를 건져 올림), 낮 = 먹 갈기 + 한 획 + 탭, 밤 = 재우기(연적 탭). 진행이 걸린 행동은 **획 1개**뿐이다.
3. **성향 4축**(느긋↔재빠름, 섬세↔대담, 혼자↔다가옴, 안온↔호기심)은 **최근 습관을 따라가는 값**이다(누적형 폐기, I1). 매일 밤 한 축(그날의 결)이 가장 크게 움직이고, 아침 문장 한 줄로 원인을 말한다.
4. **모양은 손, 자리는 몸, 칠은 성향.** 획의 모양은 손 그대로, 붙는 자리는 몸이 회전·이동으로 고르고(D-12), 성향은 그 획의 칠(번짐·비백·끝 처리·톤)과 몸짓·소리·꿈을 정한다.
5. **몸 = 핵.** 획은 핵에 입혀진다. 핵은 획 수에 따라 `coreScale`로 자란다(1.0 → 7획 1.25 → 30획 1.54, 상한 1.6).
6. **시간.** 정산 상한 72시간, 역행 0, 마름 시각 상한 0.6.
7. **화면 획 상한 24**(나이 0~20 + 고정 ≤3). 바램 시간표 0~7 새 획 담묵(`stroke-ink`) / 8~20 더 옅게 바램 / 21~ 스밈 층 / 60~ 보관 — **나이가 많을수록 더 옅다**(아트 v1.2.1 4절). 1.0 범위, MVP 7일에는 바래는 획이 없다.

## 1. 하루 루프 [MVP]

### 1.1 동사 표 (정본 — 아트 7·8절이 이 표를 참조한다)

| 동사 | 사물 | 제스처 | 반응 모션(아트 8절) | 소리·햅틱(아트 9절) | 성향 입력 | 대체 입력 |
|---|---|---|---|---|---|---|
| **긋기** | 붓 | 붓 탭 → 긋기 모드 → 손가락을 대고 **뗄 때까지가 한 획**(최대 6초) | 획 0ms 추종, 손을 떼면 부착(회전·이동 180ms 시작, 800ms 정착, 1200ms 번짐) | 종이 마찰음(속도 연동), 부착 light 1회 | 속도·길이·몸과의 거리·새로움 | 시작점·끝점 + 곡률 손잡이 |
| 먹 갈기(준비) | 벼루 | 벼루 위에 원 그리기(0~20초) | 먹 농도 표시(벼루 먹물이 짙어짐), 몽망이가 벼루 쪽을 봄 | 먹 가는 사각 소리 루프 | 먹 농도 → boldness·tempo | 길게 누르기(누른 시간 = 간 시간) |
| **탭** | 몽망이 / 종이 | 몽망이 탭 = 쓰다듬기, 몽망이 **길게 누르기 = 문지르기**(합침), 종이 탭 = 그쪽을 봄 | 눌림 0.9·100ms → 복원·빗 흔들림 800ms. 길게 누르면 번짐이 숨 쉬듯 커졌다 작아짐(주기 1.2초) | 짧은 허밍, light 1회 | 접촉량·길게 누르기 속도·탭 위치 분산 | 스크린리더 "쓰다듬기" 동작 |
| **재우기** | 연적 | 연적 탭(물이 몽망이에게 온다 — 몽망이를 물에 끌어다 넣지 않는다) | 첫 물결 200ms → 조수 2400ms, 몸 색 전환, 눈 감은 호(‿) | 물 한 방울 '톡' + 잔향, 길고 약한 연속 3회 | 없음 | 버튼 그대로 |
| **현상** | (아침 화면의 물 위 한지) | 한지를 손가락으로 **건져 올림**(위로 끌기) | 물이 빠짐 1600ms → 카드 800ms | 대금 한 프레이즈 | 없음 | "꿈 꺼내기" 버튼 |

- MVP 동사는 **4개 + 준비 동작 1개**다. 톡톡(부르기)·별도 문지르기 동사는 탭에 합쳤다(I2·I8). 꾸미기·먹이·미니게임은 없다.
- 복귀 물 한 방울(3.6)은 **연적**에서 떨어진다. 복귀 첫 탭은 원래 하려던 행동(붓 열기 등)도 그대로 실행한다(첫 탭을 소비하지 않음).

### 1.2 세 박자

| 박자 | 화면 | 유저가 하는 것 | 시간 | 몽망이 반응 |
|---|---|---|---|---|
| **아침**(깬 뒤 첫 방문) | 수면 위에 한지 한 장이 떠 있음 | 현상 → 인화 카드(저장·공유), 아침 문장 한 줄 | 30초~1분 | 깨어나며 기지개(성향별 몸짓) |
| **낮** | 한지 위 몽망이, 붓·벼루·연적 | 먹 갈기 → 한 획(하루 1번, 하고 싶을 때), 탭(언제든) | 1~4분 | 획 부착 연출, 탭 반응 |
| **밤**(잠 시각 무렵) | 하품, 번짐이 느려짐, 연적 쪽을 봄 | 재우기(연적 탭). 안 해도 잠 시각에 백그라운드면 잔다 | 10~30초 | 먹이 물에 풀리며 '꿈이 만들어지는 중' 무늬 |
| **자는 동안** | 수면 위에서 자는 몽망이(감은 호 눈) | 수면을 건드리면 잔물결만(깨지 않음) | 수 초 | 잠꼬대 허밍 |

### 1.3 "하루 한 획만으로는 짧다"에 대한 답

짧음은 결함이 아니다(Neko Atsume·Finch도 방문이 짧다). 문제는 **"다시 열었는데 아무것도 안 바뀌었다"**이다. MVP에서 돌아올 때마다 달라져 있는 것은 셋이다.

| 무엇 | 왜 다시 열게 하나 | 제작비 |
|---|---|---|
| 졸림·마름·빛 | 시간에 따라 숨·번짐 속도와 빛 색조가 바뀐다 | 파라미터 |
| 획 미루기 | "오늘 어디에 그을지" 하루 종일 둘 수 있다. 붓 라벨 "오늘의 한 획 · 아직 남아 있음" | 0 |
| 아침 카드 | 그날 획이 꿈속에 다시 나온다 | 모티프 풀 |

자유도 체감 장치는 **두 개만** 둔다(D-02, 리뷰 I7).
- ① **한 획 = 붓을 뗄 때까지**(MVP 기본, 비용 0). 꺾고 돌고 감아도 한 획이라 하루 한 번의 리듬을 지키면서 모양의 자유가 크게 늘어난다. D-12의 "모양은 손"과 짝이다.
- ② **연습지**(A/B 후보). 한지 왼쪽 아래 귀퉁이(화면 14% × 10%)에 진행과 무관한 낙서를 무제한 허용한다. 성향 입력이 아니다. 밤에 물에 씻기고, 가장 긴 낙서 하나가 그날 꿈 카드의 재료가 된다. 첫 테스트에서 '연습지 있음/없음'으로 "내가 이렇게 만들었다" 비율을 비교해 채택을 정한다.
- 산책 흔적(몽망이가 종이 위를 돌아다님)은 1.x로 뺐다(부록 A-4). 아트 바이블에 이동 모션·흔적 그림 규칙이 없고 렌더 비용 추정도 없다.

### 1.4 하루 여러 번 방문하면

| 방문 | 새로 보이는 것 | 진행에 걸린 것 |
|---|---|---|
| 1회차(아침) | 꿈 카드, 아침 문장 | 없음 |
| 2회차(낮) | 낮 몸짓, 빛 | 획(아직 안 그었다면) |
| 3회차(저녁) | 하품·느려진 번짐 | 재우기(선택) |
| 4회차 이상 | 같다 — 일부러 그렇다 | 없음 |

많이 오는 유저를 보상하지도, 적게 오는 유저를 벌하지도 않는다.

## 2. 성향 모델 [MVP]

### 2.1 축 4개

값은 −0.85..+0.85(유효 범위), 시작은 0 근처(2.4). 축 이름은 화면에 나오지 않는다.

| 축 id | −쪽 | +쪽 | 한 줄 해석 |
|---|---|---|---|
| `tempo` | 느긋 | 재빠름 | 먹이 퍼지는 속도와 숨 |
| `boldness` | 섬세 | 대담 | 붓의 힘, 획 끝의 결단 |
| `closeness` | 혼자 | 다가옴 | 유저 손에 대한 거리감 |
| `curiosity` | 안온 | 호기심 | 종이 밖에 대한 관심 |

양쪽 끝은 **똑같이 매력적**이어야 한다. "혼자"는 외로움이 아니라 "혼자 잘 노는 아이"다(D-03).

### 2.2 입력 → 신호 (MVP 입력 3종: 획·먹 갈기·탭)

모든 신호는 **모집단 중앙값(0.5)을 뺀 값**에 이득을 곱한다(중심화해야 모두가 한쪽으로 쏠리지 않는다).

| 입력 | 측정값(0..1) | tempo | boldness | closeness | curiosity |
|---|---|---|---|---|---|
| 획 속도 | 평균 속도 | +0.20 | | | |
| 먹 갈기 | 원 그리기 시간(0 = 안 갊, 1 = 20초 이상) | −0.04 | +0.12 | | |
| 획 길이 | 핵 폭 대비 | | +0.08 | | |
| 몸과 획의 거리 | 부착 전 원래 위치(0 = 몸에 붙음, 1 = 종이 끝) | | | −0.10 | |
| 획의 새로움 | 이전 획들과 각도·모양 차이 | | | | +0.16 |
| 탭 접촉량 | 하루 쓰다듬기 + 길게 누르기 시간 | | | +0.06 | |
| 길게 누르기 속도 | 손가락 미세 이동 속도 | +0.04 | | | |
| 탭 위치 분산 | 종이 여기저기를 탭하는 정도 | | | | +0.04 |

- 표의 값 = `이득 × (측정값 − 0.5)`. **하루 예산**: 축마다 ±0.15에서 자른다.
- **획 굵기는 MVP 입력에서 뺐다.** 압력이 없는 기기(테스트 기기 다수일 수 있는 Android)에서는 속도 역수가 되어 tempo와 boldness가 묶인다(리뷰 사소). boldness는 먹 갈기와 획 길이로만 받는다.
- 방문 시각 분산·산책 흔적 입력은 1.x(부록 A-4).
- **방치는 축을 움직이지 않는다.** 오지 않은 날은 신호 0이고, 습관 흔적(h)도 그날은 갱신하지 않는다(멀어졌다고 성향이 0으로 돌아가지 않음).

### 2.3 밤의 스밈 — 최근 습관 추종형 (v1 누적형 폐기)

v1 누적형은 30일 시뮬에서 약 2주 만에 네 축이 모두 ±1.00에 붙었고, 그 뒤 점수가 모두 0이 되어 argmax가 첫 키를 골라 tempo가 15밤 연속 나왔다(리뷰 I1, 이 문서 2.7에서 재현). 그래서 누적이 아니라 **목표를 따라가는 값**으로 바꾼다.

```ts
// packages/core/src/temperament/settle.ts (의사코드)
const BETA = 0.30, G = 18, VMAX = 0.85, A_FOCUS = 0.40, A_REST = 0.15, EPS = 0.03;
function settleNight(v: Temperament, h: Habit, s: Signals, hist: (AxisId|null)[]): NightResult {
  // 1) 최근 습관 흔적: 약 3밤 기억
  const h2 = mapAxes(h, (k, x) => x + BETA * (s[k] - x));
  // 2) 목표 = 포화 함수. |T| < VMAX 이므로 끝에 붙지 않는다
  const T  = mapAxes(h2, (k, x) => VMAX * Math.tanh(G * x));
  // 3) 그날의 결 = 목표와 가장 멀리 떨어진 축. 같은 축 3밤 연속 금지. 최대 간격 < EPS면 결 없음(null)
  const banned = lastTwoSame(hist);                       // 직전 두 밤이 같은 축이면 그 축
  const focus  = argmaxStrict(AXES.filter(k => k !== banned), k => Math.abs(T[k] - v[k]), EPS); // 동점이면 앞 축, 모두 EPS 미만이면 null
  // 4) 추종: 결 축은 빠르게, 나머지는 천천히
  const next = mapAxes(v, (k, x) => x + (k === focus ? A_FOCUS : A_REST) * (T[k] - x));
  return { next, habit: h2, focus, delta: focus ? next[focus] - v[focus] : 0 };
}
```

- 끝 근처에서는 변화 대신 **'깊어짐'** 으로 표현한다(2.6 문장 종류 ②). 같은 방향 습관이 이어지면 성향 값은 그대로여도 "버릇이 깊어졌다"는 문장과 몸짓 강도(1.0)로 보여 준다.
- 습관을 바꾸면 따라온다: 15일 A형 → B형으로 바꾼 유저의 tempo는 **5밤 뒤 부호가 바뀌고 9밤 뒤 −0.40**에 닿는다(v1은 9밤·13밤). "내가 바꿨는데 안 바뀐다"를 줄인다.

### 2.4 첫날(0일차) 규칙

첫 세션 신호는 **2배**(축당 ±0.25에서 자름)로 바로 반영한다("타고난 결"). 습관 흔적 h의 초깃값은 첫 세션 신호 그대로다. 난수 씨앗은 쓰지 않는다(달라진 이유를 늘 설명할 수 있어야 한다).

### 2.5 축 → 표현

원칙(D-12): **획의 모양은 손, 자리는 몸이 고른다.** 성향은 그 획이 그어지는 순간의 성향으로 **칠(StrokeStyle)을 정해 고정**한다. 그래서 몸은 성향의 일기가 된다. 몸짓·소리·꿈은 **현재** 성향을 따른다. 성향은 획의 모양과 자리를 바꾸지 않는다.

| 축 | 획의 칠(그을 때 고정) | 몸짓(현재) | 소리(현재) | 꿈(현재) |
|---|---|---|---|---|
| tempo | 번짐 반경 1.5px(재빠름)~5px(느긋), 번짐 퍼지는 시간 0.4~1.6초 | 숨 주기 2.2~5.5초, 반응 지연 | 허밍 템포 | 잔물결 / 긴 너울 |
| boldness | 비백 양, 끝: 둥근 테이퍼(섬세)/꺾인 방필(대담), 톤 회청~짙은 흑 | 몸짓 진폭 | 높고 가늘게 / 낮고 굵게 | 여백 많은 소품 / 화면을 가르는 큰 형체 |
| closeness | 부착 연출 속도(위치·모양은 그대로) | 눈이 터치 지점을 따라오는 강도, 반김: 다가와 비비기 / 멀리서 고개만 | 탭에 대답하는 빈도 | 다른 존재(손 그림자, 다른 방울) 비율 |
| curiosity | 번짐 방향성: 둥글게 / 한쪽으로 뻗음 | 시선 이동 빈도, 종이 탭에 고개 돌리는 반경 | 허밍 끝 올림/내림 | 가까운 것(이불·찻잔·창) / 먼 것(산·바다·별) |

**구간 버릇(MVP는 축당 +·− 하나씩 = 8개).** 축마다 세 구간(≤ −0.35, 가운데, ≥ +0.35)을 두고, 구간에 들어가면 눈에 띄는 버릇 하나가 열린다(예: 다가옴+ = 손가락을 대면 몸을 기울여 비빔). 81 기질 조합표·말버릇 선택 키는 1.x(부록 A-5).

### 2.6 '숨기되 읽히게' — 아침 문장 규칙

1. **하루 한 줄.** `[어제의 원인 행동] + [그래서] + [지금 보이는 변화]`. 한국어 40자, 영어 80자 이내.
2. 문장 종류는 우선순위대로 하나: ① **변화**(결 축 |Δ| ≥ 0.04) ② **깊어짐**(어제 신호가 현재 성향과 같은 방향이고 |v| ≥ 0.25인 축이 있음: "어제도 천천히 그어서, 번짐이 더 느긋해졌어요" + 버릇 강도 +) ③ **관찰**(꿈 내용: "간밤엔 먼 바다 꿈을 꿨어요"). 거짓 인과를 지어내지 않는다.
3. 원인은 그 축에 가장 크게 기여한 입력에서, 결과는 그 축의 표현 채널 하나에서 고르고 채널은 5일 안에 겹치지 않게 돌린다.
4. **보이는 것만 말한다.** 문장이 말한 변화는 현상 직후 1.5초 과장해 실제로 보여 준다.
5. 금지: 숫자, 축 이름, 평가어("잘했어요"), 명령, 죄책감("보고 싶었어요"류).
6. 템플릿 조각은 키로 관리하고(`cause.grind.long.2`, `effect.tempo.minus.bleed.1`), 한국어·영어를 따로 쓴다(D-06).

**이레(7번째 아침) 문장**은 세 줄: 가장 많이 움직인 두 축 + 첫 획 이야기("첫날 그은 획이 아직 등을 감싸고 있어요").

## 3. 시간 규칙 [MVP] (D-07 정본)

### 3.1 기준 시각
- 시뮬레이션은 **UTC epoch ms**로 계산한다. 시간대는 잠 시각·아침 시각을 현지로 풀 때만 쓴다.
- `simNow = max(wallNow, clock.hwm)`. `hwm`은 지금까지 본 가장 늦은 시각이며 줄지 않는다.

### 3.2 하루 경계 = 잠 한 번 (C3 수정판)

| 규칙 | 값 | 이유 |
|---|---|---|
| 유저 시각 | 잠 시각 기본 23:00, 아침 시각 기본 06:00. 첫날 해질녘(잠 시각 −1h 이후 처음 켤 때, 또는 첫 30초 직후 이미 그 시각이면 그때) 한 화면에서 함께 묻고 건너뛰면 기본값. 공방 노트에서 바꿈 | 하루 경계를 생활에 맞춘다 |
| 잠들기 | ① 연적 탭 ② 잠 시각이 지났고 앱이 백그라운드면 그 시각(이미 지났으면 백그라운드 전환 시각)에 자동. 앱이 켜져 있으면 하품만 하고 기다린다. **그 잠 시각 다음 아침이 백그라운드 전환보다 앞이면(밤이 이미 끝났으면) 다음 잠 시각으로 넘긴다**(v1.2: 05:50 설치 → 06:10 닫기에 바로 자서 첫날이 사라지던 문제) | 밤에 놀고 있는 유저를 끊지 않는다 |
| 재우기 가능 | 깬 뒤 8시간 **또는** 현지 시각이 잠 시각 −2h 이후 | 연속 재우기로 하루를 돌리는 것 방지 |
| 깨기 | `wakeableAt = max(sleepAt + 6h, nextMorningAfter(sleepAt), lastWakeAt + 12h)`. **깸(dayIndex +1, 획 충전, `lastWakeAt`) = 이 시각**이고 앱이 닫혀 있어도 깬다. 아침 연출(현상·아침 문장) = 그 뒤 처음 앱을 연 순간(v1.2 문구 정리) | 하루가 짧아지지 않으면서 아침이 생활 시각에 온다 |
| 첫날 | 설치 세션은 깨어 있음. `lastWakeAt = min(installAt, 직전에 지나간 아침 시각)`. 첫날에 잠·아침 시각을 바꾸면 새 아침 시각으로 다시 계산 | 저녁·새벽 설치자도 첫날 밤을 맞는다 |
| 콜드 스타트 | 앱이 앞에 있던 채로 끝난 세션(강제 종료·OS 회수)은 **저장 시각에 백그라운드로 간 것**으로 본다(v1.2). 세이브는 백그라운드 전환 처리 뒤에 쓴다 | 앱이 죽어도 다음 날 아침이 온다 |
| `dayIndex` | 깸 횟수. 표기 "몽망이·이레째"(세로쓰기, 공백 없이 가운뎃점) | 달력이 아니라 함께한 잠의 수 |

- **낮/밤 화면은 수면 상태를 따른다.** 시계는 빛 색조만 바꾼다(해질녘 = 잠 시각 −1h부터).
- **시간대 이동**: 잠 시각·아침 시각은 새 현지 시각으로 다시 계산한다. 6h·12h 규칙 때문에 하루가 두 번 오지 않는다.
- **획 충전**: 깰 때 1개, 이월 없음. 성장은 획 수로 세므로 놓친 날도 잃지 않는다.
- 아직 자는데 열면 수면 화면에 한 줄: "몽망이는 아직 자고 있어요 · 아침 6시쯤 깨요".

### 3.3 오프라인 정산
- 상한 **72시간**. 정산은 루프가 아니라 **다음 전이 시각으로 점프**한다(`nextTransition`: 잠들기 → 깰 수 있음 → 마름 단계).
- 여러 밤이 지났어도 **꿈 카드는 1장**("긴 잠" 카드). 밀린 카드 더미를 만들지 않는다.
- 비운 동안 `dayIndex`는 정산 상한 안에서만 오른다. 72h를 넘기면 **마지막 72h만** 정산하고 그 앞에 밀린 전이는 구간 시작에 한 번 일어난다. 그래서 오래 비우면 보통 +3, 구간 시작이 아침 직후에 걸리면 **최대 +4**다(v1.2, 이전 '최대 +3' 정정. 성장은 획 수로 세므로 손해는 없다).

### 3.4 시계 조작
| 상황 | 판정 | 처리 |
|---|---|---|
| 뒤로 | `wallNow < hwm` | 경과 0, `hwm` 유지, 1시간 넘으면 `suspect: 'rewind'`(분석용) |
| 크게 뒤로(시계 보정) | `hwm − wallNow > 12h` | **시계 보정**: 경과 0, `hwm`을 wallNow로 재설정(살아 있는 시각은 같은 폭만큼 함께 옮김), 잠금 없음, `suspect: 'reset'` (v1.2) |
| 앞으로 | `wallNow − lastSimAt > 72h` | 72h에서 자름 |
| 세션 안 어긋남 | `performance.now()` 경과와 10분 넘게 차이 | 세션 안에서는 `performance.now()` 경과 사용 |

얻는 이득은 "12시간마다 획 하나"뿐이고 유료 재화·순위가 없다. 서버 시간·단조 시계 모듈은 그런 것이 생길 때 붙인다.

변경 이력
- v1.2(11-20): '크게 뒤로' 행 추가. 이전 규칙(hwm은 절대 줄지 않음)에서는 시계를 1년 앞당겼다가 바로잡은 유저의 몽망이가 실제 시각이 hwm을 따라잡을 때까지(1년) 깨지 않았다(sim 리뷰 1-3). **D-03(처벌 없음)을 우선**해, 12h 넘는 역행은 조작이 아니라 시계 보정으로 본다. 앞당겨서 얻을 수 있는 이득은 기존 72h 상한(한 번에 최대 +4일·획 충전)으로 이미 제한된다.

### 3.5 마름(방치) 시각 상한
| 경과(마지막 돌봄 이후) | dryness | 보이는 것 |
|---|---|---|
| 0~12h | 0 | 촉촉, 윤기 |
| 24h | 0.15 | 윤기 살짝 빠진 무광 |
| 48h | 0.4 | 숨 느려짐, 번짐 맥동 멈춤, 가장자리에 아주 옅은 비백 |
| 72h~ | **0.6(상한)** | 무광 먹, 동그랗게 말고 쉼. 눈·획 그대로, 갈라짐·조각남 없음 |

마름은 성향·성장에 영향이 없다. 바램(4.3)과 섞지 않는다.

### 3.6 복귀 연출
1. 앱을 열면 마른 몽망이가 그대로 보인다(1초). 문구 없음.
2. 첫 터치에 **연적에서 물 한 방울**이 저절로 떨어진다 → 번짐이 1.5초 크게 피고 dryness → 0. 그 첫 터치가 원래 하려던 행동도 그대로 실행된다.
3. 반김은 closeness 구간이 정한다.
4. 밤이 지났으면 그다음이 아침 현상.
5. 복귀 문장은 사실만("먹이 다시 촉촉해졌어요").

알림(D-03): 하루 최대 1회 "간밤의 꿈이 현상됐어요"(깰 수 있는 시각 이후, 아침 시각 기준). 선택형 1회: 잠 시각 30분 전 "몽망이가 졸려 해요". 마름·방치 알림 없음.

### 3.7 첫 밤 안심 문구
첫 재우기(또는 첫 자동 잠 뒤 첫 밤 방문) 때 한 번: "물에 풀린 먹은 아침이면 다시 몸으로 돌아와요". 밤 화면 부제에 "획이 물에 풀린다/녹는다" 같은 상실 표현은 쓰지 않는다(리뷰 I6).

## 4. 성장 구조

### 4.1 단계와 핵 성장 [MVP는 이레까지]

몸 = 핵(D-10). 획은 핵에 입혀지고, 핵은 획 수로 자란다(리뷰 I4).

```ts
coreScale(n) = 1 + 0.6 * (1 - Math.exp(-n / 13))   // n = strokesTotal, 상한 1.6
// n=0 1.00 · 1 1.04 · 7 1.25 · 14 1.39 · 30 1.54 · ∞ 1.60  (아트 1-2: 1.0 → 1.25W → 1.5W, 상한 1.6W)
```

| 단계 | 조건 | 모습(형태 정본 = 아트 1-1·1-2) | 표식 |
|---|---|---|---|
| **방울** | 0획 | 작은 먹 방울, 눈 둘(종이 빈자리), 몸에 붙은 짧은 E 빗(0.18W 돌출) | — |
| **첫 두름** | 1획 | 첫 획이 핵에 붙는다(보통 등을 감싸는 두름). **첫 두름은 평생 고정 획**이다(바래지 않음). 몸통이 되지 않는다 | 낙관 "첫날" |
| **새끼** | 2~6획 | 획이 두름·받침 라벨로 핵을 감싼다(D-12). E 빗이 조금씩 길어지고 굵어진다 | — |
| **이레** | 7획 | 핵 1.25W, E 빗 완성(0.3W). **MVP 끝 표식**: 7장 꿈 카드 + 몸이 자란 과정을 이은 두루마리 한 폭 | 두루마리 "첫 이레" |
| 그 이후 | 끝 없음 | 부록 A-1 | — |

- E 빗(종 표식)은 유저 획과 별개로 시스템이 그린다. 빗 자리는 D-12 금지 자리 ①에 들어 있어 유저 획이 빗에 섞이지 않는다.
- 표식은 획 수 기준이라 띄엄띄엄 오는 유저도 똑같이 도달한다. 연속 기록은 쓰지 않는다.

### 4.2 획 좌표계 [MVP] (D-13)
- 정본 점열은 **그을 때 핵 중심 원점, 그때의 W 단위**로 저장한다.
- 렌더 때는 파생 극좌표(θ = 핵 각도, d = 핵 표면에서의 거리, W₀ 단위)로 바꿔 `표면(θ)·coreScale_now + d`에 놓는다. 핵이 자라도 획은 몸에 붙어 있고, 기기 폭이 달라도 같다(스파이크 01의 '머리 기준 px' 좌표는 폐기).

### 4.3 화면 획 상한과 바램 시간표 [값 = 정본, 구현은 1.0]

화면 예산은 아트가 정한다(30일차 보이는 획 20~25, 핵 면적 55% 이상). 이 표가 아트 1-3 '획의 나이'와 같은 값이다. 11-20(아트 v1.2.1): 0~7은 '짙은 먹'이 아니라 `stroke-ink` 담묵이고, 토큰 순서 몸 → `stroke-ink` → `ink-mid` → `ink-faded` → 바탕은 낮·밤 휘도로 단조다(`packages/core/test/body.test.ts`가 고정).

| 나이(깸 수) | 보이는 것 | 렌더 |
|---|---|---|
| 0~7 | 새 획 담묵 `stroke-ink`(가장자리는 몸과 한 coverage, 안쪽만 담묵 — 아트 1-3-1) | 개별 경로 |
| 8~20 | `stroke-ink` → `ink-mid` → `ink-faded`(모두 바탕 쪽으로 점점 옅어짐), 불투명도 1.0 → 0.45 | 개별 경로 |
| 21~59 | **스밈 층**: 핵 마스크 안에 15% 불투명도의 결로 구움 | 텍스처 1장, 하루 1회 굽기 |
| 60~ | 스밈 층에서도 빠지고 **두루마리 보관**(정본 점열은 남음) | 렌더 안 함 |

- **개별 경로 상한 24** = 나이 0~20 획(최대 21) + 고정 획(최대 3: 첫 두름 1 + 1.0 낙관 2).
- MVP(7일)에는 바래는 획이 없다. 이 표는 1.0 구현 때 그대로 쓴다.
- 되돌리기 [MVP]: 획을 긋고 5초 안에 "물로 씻기" 1회(그날 획을 다시 긋는다).

### 4.4 렌더 비용 상한 [MVP]
| 항목 | 상한 |
|---|---|
| 개별 경로 획 | 24 |
| 획당 렌더 점 | 64(파생 단순화) — 정본 점은 ≤512(D-13) |
| 매 프레임 움직이는 획 | 최근 7획 + 첫 두름, 나머지는 `Picture` 캐시 |
| 스밈 층 | 텍스처 1장(1/2 해상도), 1.0 |
| 세이브 | 24획 × ≤512점 × 4값 int16 ≈ 최대 100KB, 보통(획당 150점) 30KB 안팎 — D-13 확정 조건 64KB는 보통 기준 |

## 5. 콘텐츠 공급 [MVP 보유량만]

| 층 | 누가 | 다양성 |
|---|---|---|
| ① 몸(획) | 유저 | 무한, 제작비 0 |
| ② 결(칠·몸짓·소리) | 규칙 | 연속값 + 버릇 8 |
| ③ 꿈 모티프 | 팀 | 한정 — 고갈 위험 |
| ④ 문장 조각 | 팀 | 조합으로 늘어남 |
| ⑤ 허밍 | 팀 | 16 × 3 |

- 꿈 카드 = 모티프(curiosity × closeness 사분면 + 가운데) × 구도 3 × 물결(tempo) × 먹 톤(boldness) × **그날 획의 재해석**. 같은 카드는 두 번 나오지 않는다.
- **MVP 보유량: 모티프 10개**(접근 풀 약 40% ≈ 4개 × 구도 3 = 12장면 → 7밤 모두 다른 장면). 아침 원인 조각 언어당 24, 결과 조각 언어당 48.
- 1.0 보유량·월 생산 계획은 부록 A-6. 생산 속도("1인 + AI 하루 1모티프")는 낙관적이다(OPERATING 0-1의 'AI 탐색 → 팀 재구성' 공정). **1.0 전 실제로 1개를 만들어 시간을 잰다.**

## 6. 반증 — 이 루프가 실패하는 시나리오

### 시나리오 1. 2주 차 권태
- 징후: D7 → D14 급락, 세션 1분 미만, 획을 그은 날만 옴.
- 대응: ① 꿈 카드에 그날 획을 반드시 등장시킨다 ② 깊어짐 문장과 버릇 강도로 "자란다"를 보인다 ③ 1.x 첫 확장은 장소(종이 종류) — 할 일을 늘리지 않고 무대를 바꾼다. MVP는 7일이라 이 시나리오는 1.0 판단 자료다.

### 시나리오 2. 성향이 안 보인다
- 징후: "달라 보인다"는 통과하지만 이유가 전부 형태.
- 대응: ① 스파이크 02에서 JND 측정 ② 현상 직후 1.5초 과장 ③ 구간 문턱 0.35 → 0.25 ④ 축을 3개로 줄이는 안.
- 측정: 같은 형태·다른 결 두 몽망이 → 외부 5명이 "어느 쪽이 느긋한가" 맞히는 비율 70% 이상.

### 시나리오 3. 망칠까 봐 못 긋는다 / 그었는데 미워서 정이 떨어진다
- 대응: ① D-12 보정(자리·떨림, 단계는 테스트) ② 5초 물로 씻기 ③ 연습지(A/B)로 '연습해 보고 긋기' ④ 부착 연출에서 몽망이가 늘 기뻐함.
- 측정: 붓 진입 대비 확정 비율, 첫 획 후 30초 이탈률, D-12 테스트의 두 점수.

### 시나리오 4. "왜 아직 아침이 안 와?"
- 대응: 3.2 규칙(아침 시각 기준) + 수면 화면 한 줄 안내. 측정: 플레이테스트 문의 0건(D-07 확정 조건).

## 7. `packages/core` 타입·함수 스케치 [MVP] (구현 없음)

원칙: 순수 함수, React·RN import 금지, 시드 RNG를 상태에 보관, 시계는 주입. 문자열은 키만 낸다. 기하 함수는 worklet에서도 돌도록 배열 연산만(D-13).

```ts
export type Millis = number;
export type AxisId = 'tempo' | 'boldness' | 'closeness' | 'curiosity';
export type Temperament = Readonly<Record<AxisId, number>>; // -0.85..0.85
export type Habit = Readonly<Record<AxisId, number>>;       // 최근 습관 흔적

// D-13: 정본 점 — 그을 때 핵 중심 원점, W 단위. 저장은 int16 양자화
export interface RawPoint { x: number; y: number; t: number; p?: number }
export interface Attach { rot: number; dx: number; dy: number; level: 1 | 2 | 3; attachVersion: number }
export interface StrokeStyle { bleedPx: number; bleedMs: number; dryBrush: number; endCap: 'taper' | 'square'; tone: number; spreadDir: number }
export interface Stroke {
  id: string; day: number; createdAt: Millis;
  raw: readonly RawPoint[];            // ≤512, 정본, 불변
  attach: Attach;                      // D-12 결과(결정적으로 재계산 가능하지만 버전 고정용으로 저장)
  drawnAtCoreScale: number; meshVersion: number;
  grind: number; style: StrokeStyle;
  pinned: 'first' | null;              // 첫 두름. 낙관은 1.0
}

export type Phase = 'awake' | 'asleep';
export interface ClockState { hwm: Millis; lastSimAt: Millis; tzOffsetMin: number; suspect: null | 'rewind' | 'jump' }
export type InputKind = 'stroke' | 'grind' | 'tap';
export interface DayLedger { signals: Record<AxisId, number>; used: Record<InputKind, number>; strokeUsed: boolean; washUsed: boolean; topContributor: Partial<Record<AxisId, InputKind>> }
export interface DreamCard { night: number; motifId: string; composition: 0 | 1 | 2; inkTone: number; flowSeed: number; strokeRef: string | null; nightsMerged: number }
export interface MorningLine { kind: 'change' | 'deepen' | 'observation' | 'seven-day'; keys: string[]; vars?: Record<string, string | number> }

export interface State {
  schemaVersion: 1; rng: number; createdAt: Millis; clock: ClockState;
  phase: Phase; sleepAt: Millis | null; lastWakeAt: Millis;
  dayIndex: number; bedtimeLocalMin: number; morningLocalMin: number;
  temperament: Temperament; habit: Habit; focusHistory: (AxisId | null)[];
  strokes: Stroke[]; strokesTotal: number;
  ledger: DayLedger; lastCareAt: Millis;
  pendingCard: DreamCard | null; pendingLine: MorningLine | null;
  recentMotifs: { motifId: string; composition: number; night: number }[]; recentLineKeys: string[];
}

export type Event =
  | { type: 'stroke'; at: Millis; raw: RawPoint[]; grind: number }
  | { type: 'washStroke'; at: Millis }
  | { type: 'grind'; at: Millis; durationMs: number }
  | { type: 'tap'; at: Millis; target: 'body' | 'paper'; holdMs: number; x: number; y: number }
  | { type: 'putToSleep'; at: Millis }            // 연적 탭
  | { type: 'developCard'; at: Millis }           // 건져 올리기
  | { type: 'setTimes'; at: Millis; bedtimeLocalMin: number; morningLocalMin: number }
  | { type: 'appForeground'; at: Millis; tzOffsetMin: number; monoDeltaMs?: number }
  | { type: 'appBackground'; at: Millis };

export type Effect =
  | { type: 'slept'; at: Millis } | { type: 'woke'; at: Millis; dayIndex: number }
  | { type: 'cardReady'; card: DreamCard; line: MorningLine }
  | { type: 'strokeAccepted'; strokeId: string } | { type: 'strokeRejected'; reason: 'used' | 'asleep' | 'tooShort' }
  | { type: 'stageReached'; stage: 'drop' | 'firstStroke' | 'young' | 'ire7' } | { type: 'bandEntered'; axis: AxisId; band: -1 | 0 | 1 }
  | { type: 'rehydrated' } | { type: 'clockSuspect'; kind: 'rewind' | 'jump' };

// time/
export function resolveNow(clock: ClockState, wallNow: Millis, monoDeltaMs?: number): { simNow: Millis; elapsedMs: number; capped: boolean; suspect: ClockState['suspect'] };
export function wakeableAt(s: State): Millis;                 // max(sleepAt+6h, nextMorningAfter(sleepAt), lastWakeAt+12h)
export function canPutToSleep(s: State, now: Millis): boolean; // 깬 지 ≥8h || 현지 ≥ 잠 시각−2h
export function initialLastWake(installAt: Millis, morningLocalMin: number, tzOffsetMin: number): Millis; // 첫날 예외
export function nextTransition(s: State, foreground: boolean): { at: Millis; kind: 'sleep' | 'wakeable' | 'dryStep' } | null;
export function dryness(s: State, now: Millis): number;

// sim/
export function createInitial(now: Millis, tzOffsetMin: number, seed: number): State;
export function tick(s: State, now: Millis, opts?: { foreground: boolean }): { state: State; effects: Effect[] };
export function apply(s: State, e: Event): { state: State; effects: Effect[] };

// temperament/
export function settleNight(v: Temperament, h: Habit, l: DayLedger, hist: (AxisId | null)[]): { next: Temperament; habit: Habit; focus: AxisId | null; delta: number };

// geometry/ (D-12·D-13, worklet 호환)
export function simplifyStroke(raw: readonly RawPoint[], max?: 64): RawPoint[];   // 파생

export function toCorePolar(raw: readonly RawPoint[], attach: Attach, coreScaleThen: number): { theta: number; d: number }[];

export interface VisualState { phase: Phase; light: 'dawn' | 'day' | 'dusk' | 'night'; coreScale: number; breathPeriodS: number; gazeFollow: number; dryness: number; habits: string[]; strokes: { stroke: Stroke; opacity: number; live: boolean }[] }
export function selectVisual(s: State, now: Millis): VisualState;   // 낮·획·밤 화면이 모두 이것 하나를 쓴다

// save/
export interface SaveEnvelope { schemaVersion: number; savedAt: Millis; data: State }
export function migrate(env: SaveEnvelope): SaveEnvelope;
```

## 부록 A. 1.x 장치 (MVP 구현 대상 아님, 테스트 결과로 대부분 바뀔 수 있음)

- **A-1 이레 이후 표식**: 보름(15획) 주사 획 첫 해금, 첫 달(30획) 두루마리 권. 이후 매달 두루마리.
- **A-2 고정 획 = 낙관 최대 2**(+ 첫 두름 = 3): 아끼는 획에 낙관을 찍으면 바래지 않는다. 넘기려면 하나를 거둔다. 낙관은 한지 위 **먹색 인장**으로 찍는다(주사는 한 화면 한 곳 원칙).
- **A-3 바램·스밈·보관**: 4.3 표 그대로 구현.
- **A-4 산책 흔적**: 앱을 닫은 동안 몽망이가 남긴 먹 점. 전제: 아트 바이블에 이동 모션·흔적 그림 규칙과 렌더 비용 추정이 먼저 있어야 한다. 성향 입력(흔적 건드리기·방문 시각 분산)은 그때 추가.
- **A-5 기질·말버릇**: 81 기질 조합, 허밍 말버릇 선택 키, 축당 버릇 2개.
- **A-6 콘텐츠 1.0**: 출시 전 모티프 40개(120장면), 이후 월 10~15개. 반복 규칙: 같은 모티프 14밤, 같은 모티프 + 구도 60밤 금지(생산이 못 따라가면 45밤).
- **A-7 회차·화첩·결 도감**: 새 방울(회차)은 선택, 이전 몽망이는 화첩에서 쉼, 형태 도감은 만들지 않고 결 도감만.
- **A-8 원상**: 아트 1-3 ④. 리뷰 I5 권고대로 기본안은 "잘 때만 펼침".
