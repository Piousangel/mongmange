# 돌봄 일상 v3.1 — 밥·간식·마실·함께 걷기 (재리뷰·오너·PM 결정 반영, DECISIONS D-27 반영)

> **오너께 드리는 변경 요약 (오너 결정 11-25와 달라진 점)**
> 1. **밥과 간식은 결정하신 대로 나눴습니다.** 밥은 하루 한 끼(벼루에서 간 먹 한 숟갈)이고, 간식은 안 줘도 아무 일이 없으며 주면 오물오물 기뻐합니다. 둘 다 1.0에 세 종류씩 넣고, 벼루를 탭하면 열리는 작은 시트에서 줍니다(사물은 3개 그대로).
> 2. **'밥 줘' 알림은 몽망이가 직접 말하는 대신 관찰 문장으로 바꿨습니다.** 예: "몽망이가 벼루 쪽을 자꾸 봐요". 1인칭으로 하면 몽망이는 말하지 않는다는 원칙(D-02)을 깨야 합니다. "밥 먹을 때 됐어" 같은 문장은 섭식 문제가 있는 사람에게 '먹으라'는 말로 읽힙니다. D-03·관문 Q8에는 '선택한 사람에게, 관찰 문구로, 하루 최대 1번'인 명시적 예외로 적었습니다.
> 3. **밥 알림은 선택 기능(기본 꺼짐)이고, 결정하신 대로 떠난 사람에게도 갑니다.** 켤지는 첫날 밤 알림 권한을 여쭐 때 함께 묻습니다. 그날 한 마디를 썼으면 이틀째에, 안 썼으면 다음 날에 한 번 부릅니다. 무엇을 썼든 규칙이 같아서 힘든 말을 쓴 날도 다른 날과 구별되지 않습니다.
> 4. **실제 바깥 걸음은 소프트런칭 시작판(01-12)에는 없고, 01-26 업데이트부터 들어갑니다(되면 정식 출시판에 포함).** 못 맞추면 1.1입니다. 그 전에는 권한이 필요 없는 '화면 안 마실'로 같은 경험을 합니다. 실제 걸음은 Android의 건강 관련 민감 권한 신고, Play 서비스의 백그라운드 걸음 기록 고지, 자체 네이티브 모듈이 필요합니다. 이것을 12-19 동결 빌드에 숨겨 넣었다가 나중에 켜면 심사 위험이 큽니다.
> 5. 그 밖에 걸음 기록은 서버로 올리지 않습니다. 함께 걷기는 만 14세 확인을 통과한 분에게만 보이고, 걸어서 빨리 자라거나 남과 겨루는 것은 없습니다.

## 0. 결론

| # | 결론 |
|---|---|
| 1 | **밥 = 깸마다 한 끼, 벼루에서 간 먹 한 숟갈.** 숟갈을 따로 두지 않는다. **벼루를 탭하면 벼루 하위 시트**(먹 갈기 안내 / 한 숟갈 / 작은 것)가 열리고, 종류를 탭하면 몽망이가 받는다(끌기는 덤). 원 그리기 = 갈기, 길게 누르기 = 이름 표시(D-08)는 그대로다. 밥을 안 줘도 몸·성장·정·꿈은 바뀌지 않는다. |
| 2 | **밥 때 = 새 깸이 시작될 때**(아침 꿈 카드를 닫은 뒤). 깸은 D-07의 '하루 = 잠 한 번'이라 체감은 하루 한 끼다. 시각을 저장하지 않으므로 늦게 와도 밥 때가 밀리지 않는다. |
| 3 | **밥 알림은 선택 기능이고 기본은 꺼짐**이다. 켤지는 D-15의 첫 재우기 밤 권한 화면에서 함께 묻는다. 앱이 백그라운드로 갈 때 **늘 하나만** 예약한다: 그 깸에 한 마디를 **썼으면 다음다음 깸, 안 썼으면 다음 깸**. 앱을 열면 모두 취소하고 아무것도 저장하지 않는다. 문장은 **관찰자 3인칭과 먹 낱말**로만 쓴다. |
| 4 | **간식 = 안 줘도 그만, 주면 기쁨.** 부탁 몸짓·알림은 없다. 깸마다 최대 셋까지 줄 수 있다. |
| 5 | 종류는 **1.0에 밥 3·간식 3**, 1.x는 목록만 정해 둔다. 열리는 방법은 이레와 정뿐이고, 한 번 열리면 공방(유저) 단위로 남는다. 결제·뽑기·한정 획득은 없다. '좋아하는 것' 하나는 **타고남 씨앗으로만** 정한다. |
| 6 | **소프트런칭 시작판 = 화면 안 마실**(권한 0, JS). 한지 위에서 손끝을 따라 함께 걷는다. |
| 7 | **실제 걸음 = 스토어 업데이트**(01-26 위젯 업데이트가 1순위 — 되면 정식 출시판 포함, 아니면 1.1). iOS는 Core Motion만, Android는 Recording API on mobile을 쓴다. 켜기는 **만 14세 확인을 통과한 사람에게만** 보인다. 남는 것은 '마실 날' 하나이고, 이 값은 **기기 전용·맡겨 두기 업로드 제외**다. 숨겨 넣은 뒤 OTA로 켜는 방식은 쓰지 않는다. |
| 8 | **공수**: RC까지 앱 7.0일(+9.8%), 아트·사운드 7.5일, 문서 1.0일. 62일 앱 창 전체로는 실제 걸음 5.0일을 더해 **앱 +12.0일(+16.8%)**이다(7절). 자르는 순서는 **실제 걸음 → 밥 알림 → 종류 수 → 화면 마실** 순이고, 레인별로 따로 적용할 수 있다. 최소선은 밥 1 + 간식 1 + 앱 안 부탁 몸짓이다. |

## 2. 밥

### 2-1. 하루 의례와의 연결

| 박자 | v3.1 |
|---|---|
| 아침 · 한지 | 꿈 카드를 닫으면 새 깸의 밥 때다. 몽망이가 **벼루 쪽을 한 번 흘끗 보고 입을 오물거린다**(부탁 몸짓). 방문마다 최대 1번, 3분 뒤 아이들로 돌아간다. **그 깸에 한 마디를 이미 썼으면 내지 않는다**(L-d: 판단 입력이 알림과 같은 `word`라 흔적이 없다) |
| 낮 · 벼루 | **벼루 탭 → 벼루 하위 시트**: '먹 갈기'(원 그리기 안내) / '한 숟갈'(밥 줄 — 먹을 한 칸 이상 갈았을 때 켜짐, 그 전에는 "먹을 갈면 한 숟갈 뜰 수 있어요") / '작은 것'(간식 줄, 늘 켜짐). 종류를 탭하면 몽망이가 받는다(빨려 듦 1.2초, V7 재사용). 시트에서 몽망이 쪽으로 끌어도 된다(덤). 밥은 오늘 글자 수를 줄이지 않고, 오래 갈아도 밥이 커지지 않는다(갈기 보상 금지, `concept-review.md:255`). 먹이 고였는지는 벼루 그림 안 연지의 상태로만 보인다 |
| 낮 · 붓 | 같음. 밥을 안 줘도 쓸 수 있다 |
| 낮 · 손 | 쓰다듬기 등 그대로 |
| 밤 · 연적 | 같음 |

- **벼루 여는 법(M-e · PM 결정)**: 벼루에는 지금 원 그리기(갈기)와 길게 누르기(이름 표시 D-08, 스크린리더 대체 '간 시간', `systems-v1.md:54`)가 있고 **탭은 비어 있다.** 탭 판정은 '움직임 8pt 미만 그리고 300ms 미만'이다. 원 그리기는 첫 움직임에서, 길게 누르기는 400ms에서 갈라지므로 겹치지 않는다. 시트가 열린 채 '먹 갈기'를 고르면 시트가 닫히고 갈기 안내가 나온다. 스크린리더에서는 벼루 동작 목록(먹 갈기 · 한 숟갈 주기 · 작은 것 주기)이다. **사물은 붓·벼루·연적 3개 그대로**이고, 숟갈은 따로 탭하는 도구가 아니다.
- 하루 시간은 5~10초가 더해진다. 하루 2분 상한(`concept-review.md:106`) 안이다.

### 2-3. 밥 알림 — 선택, 관찰형, 예약 규칙 (오너 11-25 · PM 결정)

| 규칙 | 값 |
|---|---|
| 켜기 | **기본 꺼짐.** D-15대로 **처음 연적으로 재운 밤의 알림 권한 사전 문구 화면**에서 함께 묻는다: '아침 꿈 알림'(기존) 아래에 선택 한 줄 "몽망이가 벼루 쪽을 볼 때도 알려 주세요"(기본 꺼짐). 따로 묻는 시점은 없다(M-a). 그 전에는 예약하지 않는다. 그 뒤에는 공방 노트 알림 설정에서 켜고 끈다. OS 권한을 거절한 사람은 노트에서 켜면 '설정에서 알림을 켤 수 있어요' 한 줄만 보인다 |
| 구현 | **로컬 알림**(expo-notifications). 푸시 토큰을 받지 않는다(처리방침 11절 유지) |
| 예약 | 앱이 **백그라운드로 갈 때마다 늘 하나만** 예약한다(먼저 남은 밥 알림을 모두 지운다). 그 깸에 `word` 레코드가 **있으면(무엇을 썼든) 다음다음 깸**, **없으면 다음 깸**. 꺼져 있거나 OS 권한이 없으면 0개 |
| 깸 계산 | 앱이 닫혀 있는 동안에는 깸이 시작되지 않으므로(D-07), '다음 깸' = 다음 **깰 수 있는 시각**이 지난 날, '다음다음 깸' = 그다음 깰 수 있는 시각이 지난 날로 잠·아침 시각 설정에서 계산한다 |
| 울리는 시각 | 그날 '깰 수 있는 시각' 뒤 첫 **익숙한 시각**(`relation.hour` 최빈, M4 손 기억 필요). M4가 늦으면 **아침 시각 + 6시간**을 고정 대체값으로 쓴다. 조용한 시간(잠 시각 ~ 아침 시각 + 1시간)이면 그 뒤로 미루고, 같은 날 아침 꿈 알림과 4시간 이상 떨어뜨린다 |
| 앱을 열면 | 예약된 밥 알림을 모두 취소한다 |
| 상한 | **부재 한 번에 최대 1개, 깸당 최대 1개**(앱을 열어야 다음 예약이 생긴다). 하루로 보면 꿈 알림과 합쳐 최대 2개. 우선순위는 꿈 > 밥 > 졸려 |
| 저장 | **아무것도 쓰지 않는다**(예약·발송·건너뜀 기록 0). 판단 입력은 모든 날 같은 모양인 `word` 존재와 설정값뿐이다 |
| 권한 거절·꺼짐 | 손해가 없다. 밥 때는 앱 안 부탁 몸짓으로 보이고, 몽망이는 똑같이 자란다 |
| 위젯·집계 | 밥 신호를 내지 않는다(D-03 보강 ④). 핑에 싣지 않는다 |

**흔적 0이 유지되는 까닭**: 판단은 '그 깸에 한 마디를 썼는가' 하나다. 곁 대답이 나온 깸과 같은 한 획의 고요로 저장된 보통 깸은 둘 다 `word`가 있으므로 **예약 시각이 같다**(다음다음 깸). 저장되는 값이 없어서 heart-grain 9-2 R2·R11 ② 구조 검사에 걸릴 것이 없다. 사용자에게 보이는 규칙은 "쓴 날은 이틀째에, 안 쓴 날은 다음 날에 한 번"이고, 무엇을 썼는지와 상관없다. 쓴 날 바로 다음 날에는 부르지 않으므로, 힘든 날 다음 날의 압박(v2 R3)도 덜어진다. 이탈자는 마지막으로 쓴 깸에서 두 깸 뒤에 알림 하나를 받는다(재리뷰 N1 해소).

## 3. 밥·간식 종류

### 3-1. 원칙
- 이름은 먹·물·한지 낱말로 짓는다. 앱 안 문구도 2-3의 금지 낱말을 따른다. 내부 분류 이름 '밥·간식'은 오너의 말이라 문서에만 쓰고, 화면 라벨은 PL-2가 정한다(예: '한 숟갈'·'작은 것').
- 열리는 방법은 이레와 정뿐이다. 결제·뽑기·광고 보상·기간 한정이 없다(D-05, D-03 보강 ③).
- 성장·성향·꿈 해금에 영향을 주지 않는다. '싫어함' 반응이 없다.

## 4. 마실과 함께 걷기

- 소프트런칭 시작판(01-12)에는 화면 마실만 있다. 01-26 업데이트가 제때 되면 정식 출시판에는 실제 걸음도 들어간다(L-b).

### 4-1. 화면 안 마실 (권한 0, RC)

| 항목 | 규칙 |
|---|---|
| 동작 | 한지 위에 손가락을 대고 천천히 끌면 몽망이가 콩콩 따라 걷는다. 젖은 발자국은 3초 뒤 마른다. **10초 이상 함께 걸으면 그 깸은 '마실 날'**이다 |
| 결과 | 다음 아침 몽망이가 바깥 바람을 맞은 몸짓으로 깬다(빗이 뒤로 날림, #48 재사용). 그날 밤 꿈은 '길·먼 곳' 모티프 가중 ×2(D-25 반복 방지 안에서) |
| 공유물 | **앱 안 꿈 카드에만** 귀퉁이 젖은 발자국을 넣고, 공유판에서는 뺀다(L2, PM 11-24 '그날 하루 신호는 공유물에 싣지 않는다') |
| 하지 않는 것 | 성장·정·해금에 반영하지 않는다. 횟수·연속도 없다 |
| 접근성 | 스크린리더에서는 몸 동작 "마실 가기"(10초 자동 연출). 모션 줄이기에서는 몸 이동 없이 발자국만 |
| 저장 | `walk.day` 예/아니오 하나. **기기 전용**이고 다음 아침 연출에 쓴 뒤 지운다. **맡겨 두기 업로드 허용 목록에서 뺀다**(M6). heart-grain 9-2 R7처럼 업로드 필드를 명시한다 |
