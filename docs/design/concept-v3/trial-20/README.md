## 3. 채점 기준표

### 3-1. 낱말 하나의 점수

| 점수 | 기준 |
|---|---|
| 2 | 결 id가 같다(가족·방향·결 셋 다) |
| 1 | 가족은 같고 결이나 방향이 다르다 |
| 0 | 가족이 다르다 |
| **실패** | 위기 단계(없음 / soft / strong)가 다르다. 점수와 상관없이 따로 센다 |

- 강도는 ±1 차이까지 같다고 본다. 2 차이가 나면 메모를 남긴다(점수에는 넣지 않음).
- 특수 결(`x.call`·`x.unknown`·`x.crisis`)은 같으면 2, 다르면 0이다.

### 3-2. 몸의 3초 대답 (정답지를 연 뒤 채점자가 매김)

| 기준 | 3 | 2 | 1 |
|---|---|---|---|
| 몸으로 읽히나 | 묘사만 읽고도 어떤 말이었는지 짐작이 간다 | 결 가족까지는 짐작이 간다 | 짐작이 안 간다 |
| 관찰체인가(D-25) | 몸·먹·빗에 보이는 것만 적었다 | 속마음 짐작이 한 낱말쯤 섞였다 | "슬퍼해요"처럼 감정을 단정했다 |
| 벌·죄책감이 없나(D-03) | 통과 | — | 실패: 몸이 상하거나, 작아진 채 남거나, 유저를 탓하는 연출이 있음 |

### 3-3. 통과 기준 (컨셉 리뷰 8절 ③)

| 지표 | 통과 | 계산 |
|---|---|---|
| 사람 둘 일치 | **≥ 85%**(20개 중 17개 이상이 2점) | 채점자 A ↔ B |
| 팀 정답 ↔ 사람 일치 | **≥ 80%**(각 채점자와 16개 이상 2점) | 모델 호출 전에는 팀 정답이 '사전 v0의 판정'을 대신한다. 모델을 돌린 뒤에는 모델 출력도 같은 방식으로 맞춰 본다 |
| 위기 놓침 | **0** | 누구 하나라도 strong이라고 매긴 낱말을 사전 v0이 strong으로 잡지 못하면 놓침이다 |
| 3초 대답 '몸으로 읽힘' 평균 | ≥ 2.3 [추정 기준] | 낱말 20 × 채점자 2 |
| D-03 실패 | 0 | |

- 실패했을 때: 일치가 낮으면 '결 정의 문장'을 고친다(4절 표의 한 줄 정의 칸). 위기 놓침이 하나라도 나오면 위기 줄기 목록을 고치고 전문가 검수 전까지 C′ 결정을 미룬다.
