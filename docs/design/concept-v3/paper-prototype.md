# 종이 프로토타입 — 설계와 판정 (검증 ①)

- 작성: PL-1 + PL-2, 2026-11-24. 인쇄물: **`paper-kit.html`**(A4 9쪽 한 파일. 브라우저에서 열어 인쇄하면 된다. 인쇄 모드에서 쪽마다 넘침 0을 확인했다).
- 테스터는 5명이고 오너가 섭외한다. 한 사람에 15분, 진행 1명 + 기록 1명이 필요하다(기록자가 없으면 녹음).

## 1. 무엇을 재나

| 묻고 싶은 것 | 재는 방법 | 키트 위치 |
|---|---|---|
| 내 말이 반영됐다고 느끼나 | Q1(1~5) + "어느 순간에" | 9쪽 |
| '내가 키웠다' 체감(컨셉 리뷰 8절 ① 지표) | Q2(1~5) | 9쪽 |
| 28밤 뒤 곁에 남기 / 떠나기 선호(D-26 '테스터 반응으로 확정') | Q3. A·B 카드 순서를 테스터마다 바꾼다 | 8·9쪽 |
| 공유하고 싶은가 | Q4(1~5) + 누구에게 + 그림만인지 말까지인지 | 9쪽 |
| 감정 일기 같은 부담 | Q5 | 9쪽 |
| 무엇을 쓸지 몰라 멈추나 | 붓을 들고 첫 획까지 걸린 초, 10초 넘는 멈춤 | 기록 표 |
| 사전 밖 비율(현장 추정) | 진행자가 '모르는 말' 카드를 든 횟수 / 15낱말 | 기록 표 '판정한 결' |
| 첫 낱말의 갈래 | 감정 / 사물·자연 / 사람·이름 / 장난 | 기록 표 |

## 2. 판정 기준

컨셉 리뷰 8절 ①은 A+(한 획)와 C′를 비교하도록 되어 있었다. 하지만 이번 과제는 **15분 C′ 단독**이다. 그래서 비교 기준을 절대 기준으로 바꿨다. **이 변경은 오너 확인이 필요하다.** A+ 비교를 지키려면 아래 '선택: A+ 5분'을 붙여 20분으로 한다.

| 지표 | 통과 | 근거 |
|---|---|---|
| Q1 반영 | 평균 **≥ 4.0**, 그리고 5명 중 4명 이상이 4점 이상 | '직접 반영'이 이번 컨셉 변경의 이유다(D-26) |
| Q2 '내가 키웠다' | 평균 ≥ 4.0 | 8절 ①을 절대 기준으로 옮긴 것 [추정 기준] |
| Q5 부담 '예' | **≤ 1/5** | 8절 ① |
| 10초 넘는 멈춤이 한 번이라도 있었던 사람 | **≤ 2/5** | 8절 ① |
| Q4 공유 | 평균 ≥ 3.5 [추정 기준] | 기둥 ② |
| Q3 남기 / 떠나기 | 통과 기준 없음. **결정 재료**다. 3명 이상이 한쪽이면 그쪽을 기본안으로, 갈리면 팀 기본안(곁에 남기)을 유지하고 소프트런칭 설문으로 넘긴다 | D-26 |

- 5명은 작은 표본이다. 숫자는 방향만 보여 준다. 그래서 **혼잣말과 반응 기록이 숫자만큼 중요하다.** 특히 "대답 카드를 볼 때 웃음·'아'가 나왔나"(체감)와 Q1의 "어느 순간"을 본다.
- 하나라도 미달하면, 원인을 '말이 반영되는 방식'(대답 카드 문제)과 '무엇을 쓸지 모름'(프롬프트 문제)으로 나눠 다음 수정안을 낸다.

## 3. 설계에서 고른 것과 그 까닭

| 고른 것 | 까닭 |
|---|---|
| 하루를 3번만 돈다 | 15분 안에 첫 대답의 놀람과 반복의 리듬을 모두 보려면 세 번이 최소다. 7번을 돌면 질문 시간이 없어진다 |
| 진행자가 '감정'이라는 말을 쓰지 않는다 | 감정을 쓰라고 시키면 Q5 결과가 오염된다. 컨셉 리뷰 5-2 '감정을 쓰라고 강요하지 않는다' |
| 커닝표에 없으면 '모르는 말' 카드 | 진행자가 즉석에서 가까운 결을 지어내면 실제 앱보다 똑똑하게 보인다. 사전 v0의 실제 커버리지를 그대로 시험한다 |
| 28밤은 건너뛰어 완성 카드로 보여 준다 | 시간 압축. 흔적 조각은 테스터가 쓴 말의 가족에서 가져오므로 '내 말로 자란 아이'라는 인과가 유지된다 |
| 결말 A·B를 같은 크기, 같은 길이로 쓰고 순서를 바꾼다 | 순서 효과와 문구 편향을 줄이려는 것이다 |
| 만 19세 이상을 권한다 | 14~18세는 보호자 동의 절차가 필요하다. 이번 5일 안에 하기 어렵다. 실제 타깃은 14세 이상이므로 10대 반응은 소프트런칭 전에 따로 본다 |
| 위기 낱말이 나와도 진행을 멈추지 않는다 | 멈추면 '알아챘다'는 신호가 되어 오히려 부담이 된다. 끝난 뒤 조용히 한 번만 확인한다(키트 1쪽). 이 절차는 개인정보 담당이 미리 읽어야 한다 |

## 4. 선택: A+ 비교 5분 (오너가 비교를 원할 때)

1. 15분 순서 **앞에** 5분을 붙인다(T1·T3·T5) 또는 **뒤에** 붙인다(T2·T4).
2. 테스터가 붓펜으로 선 하나를 긋는다 → 진행자가 몽망이 카드 몸 둘레에 그 선을 작게 따라 그린다 → 3번 반복한다.
3. Q2만 다시 묻는다. 통과 기준은 8절 원안인 **C′ ≥ A+ + 1.0**이다.

## 5. 끝난 뒤 (기획이 할 일)

- '판정한 결'과 사전 v0이 어긋난 낱말(진행자가 커닝표에서 찾지 못한 활용형 등)은 `lexicon-v0`의 표면형 후보로 옮긴다.
