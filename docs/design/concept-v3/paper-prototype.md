# 종이 프로토타입 — 설계와 판정 (검증 ①, v0.4)

- 작성: PL-1 + PL-2. 2026-11-24 v0 → v0.2(독립 리뷰 H6·H7·M3) → v0.3(자살예방 안전 검수 5절: 게이트키퍼 교육·마무리 질문·직접 질문·진행자 돌봄).
- v0.4(11-25): 가라앉음 5결 대답 카드의 '돌아오기'가 곁으로 와서 붙어 앉기로 바뀌었다(넓은 그물). Q5-2를 더했다.
- v0.5(11-25): **일상 문항 D1~D4**(4분, `care-rituals.md` 4-2)를 Q6 뒤에 더했다. 30분을 지키려고 **기존 Q7('기억에 남는 반응', 자유)과 '내일이라면 무엇을 써 주고 싶나요?'를 뺐다**(둘 다 판정 지표가 아니고, 반응 기억은 Q1(C′)의 '어느 순간에'와 기록자 반응 칸이 받는다). 22~25분의 여유 3분은 Q3~Q6에 쓰므로, 앞 블록이 늘면 **D4를 건너뛴다**. 일상 카드 8장은 6쪽 아래, 문항은 10쪽 아래. 인쇄 모드 10쪽, 쪽마다 넘침 0을 다시 확인했다(헤드리스 Chromium A4).
- 인쇄물: **`paper-kit.html`**. A4 10쪽짜리 한 파일이다. 브라우저에서 열어 인쇄하면 되고, 인쇄 모드에서 쪽마다 넘침이 0인 것을 확인했다.
- 테스터는 5명이고 오너가 섭외한다. **한 사람에 30분**이고 A+ 비교가 들어 있다. 진행 1명과 기록 1명이 필요하다. 기록자가 없으면 녹음한다.

## 1. 무엇을 재나

| 묻고 싶은 것 | 재는 방법 | 키트 위치 |
|---|---|---|
| 내가 한 것과 몽망이 반응의 관계 | Q1(1~5, 중립 문장). **A+·C′ 둘 다** 묻는다 | 9쪽 |
| 이 아이가 자란 데 내가 준 영향(V0-1 지표) | Q2(1~5, 중립 문장). A+·C′ 둘 다 묻는다 | 9쪽 |
| 28밤 뒤 곁에 남기 / 떠나기 선호 | Q3. A·B 카드의 놓는 순서를 테스터마다 바꾼다 | 8·10쪽 |

- **쓴 낱말은 기록하지 않는다.** 범주만 적는다: 감정 / 사물·자연 / 사람·이름 / 장난 / 모르는 말 / 곁 대답. 한지는 사진으로 남기지 않고, 끝나면 테스터에게 돌려주거나 그 자리에서 함께 버린다(리뷰 H7).

## 2. 판정 기준 (PM 결정: A+ 비교, V0-1 원안)

판정 문구는 '통과'가 아니라 **"계속 진행할 신호"(기각되지 않음)**로 쓴다. 5명 표본이기 때문이다. 숫자 옆에는 사람별 점수를 그대로 싣는다. 혼잣말과 반응 기록도 숫자와 같은 무게로 보고한다.

| 지표 | 계속 진행 신호 | 비고 |
|---|---|---|
| **Q2 C′ − Q2 A+ (평균)** | **≥ 1.0** | **주 지표**(V0-1 원안). 사람별 차이도 함께 싣는다 |
| Q1 C′ − Q1 A+ (평균) | ≥ 1.0 | 같은 방향인지 본다 |
| Q2 C′ 절대값 | 평균 ≥ 3.5 | 보조 지표. 둘 다 낮은데 차이만 큰 경우를 거른다 |
| Q5 부담 | **'예' + '조금' ≤ 2/5** | 리뷰 M3. '조금'도 센다 |
| Q5-2 살펴보는 느낌(E3) | **'예' + '조금' ≤ 2/5** | 넓은 그물(heart-grain 8-0)의 압박 확인. 1.0 관문 개정안(8-8)의 한 줄 |
| 10초 넘는 멈춤이 있었던 사람 | ≤ 2/5 | 실제 앱 첫날 화면(빈 한지인지, 연습지 예시가 있는지)과 조건이 같아야 한다. 앱보다 어려운 조건이면 멈춤이 부풀려진다 [V3 쓰기 화면과 대조 필요] |
| Q4 공유 | 평균 ≥ 3.5 [추정 기준] | |
| D2 돌봄감 ㄴ − ㄱ (평균) | ≥ −0.5 | 미달이면 번역형 이름·연출 재검토(`care-rituals.md` 5절 오너 질문 1) |
| D3 ㄴ '부담스럽다 + 조금' | ≤ 1/5 | 미달이면 1.x 확장(V30 마실) 보류 |
| D1 '먹이기' | ≥ 3/5이면 V27(한 방울)을 지킨다 | 결정 재료 |
| D4 최다 | '쓰다듬기'가 최다면 1.0은 M4·M5 지키기에 집중 | 결정 재료. **C′ 판정과 섞지 않는다**(Q6 뒤에 묻는 별도 질문) |
| Q3 남기 / 떠나기 | 결정 재료(기준 없음) | 3명 이상이 한쪽이면 그쪽을 기본안으로 하고, 갈리면 팀 기본안(곁에 남기)을 둔 채 소프트런칭 설문으로 넘긴다 |

- **순서 효과**: A+ 먼저 3명(T1·T3·T5), C′ 먼저 2명(T2·T4)이라 균형이 3:2다. 5명이라 피할 수 없다. 순서별 차이를 따로 표에 적고, 판정 문구에도 이 사실을 쓴다.
- **한계**: 이번에는 연구 윤리상 성인만 모신다. 그래서 **10대 데이터가 0**이다(특히 10대 말투의 위기·과장 표현). 이 한계를 판정 문구에 적고, 10대 반응은 소프트런칭 전에 따로 본다.

## 3. 공정성 장치 (리뷰 H6)

| 장치 | 내용 |
|---|---|
| 같은 연기량 | 두 조건 모두 진행자가 3초 몸짓을 흉내 내고, 꿈 카드·완성 카드·낙관을 같은 무게로 준다. A+ 몸짓은 시스템 v1의 몸 반응(받는 쪽으로 6° 기욺 + 번짐)이다 |
| 유도 문장 제거 | "네 말은 이 아이의 몸과 마음이 돼요"(붓 카드), "당신이 쓴 말로 자란 아이예요"(완성 카드)를 뺐다. 두 조건 모두 **"스물여덟 밤이 지나 다 여문 아이예요."** 한 문장만 쓴다 |
| 중립 질문 | Q1 "몽망이의 반응이 내가 한 것과 **얼마나 관계있어 보였나요**(1 = 전혀 관계없어 보였다 … 5 = 아주 관계있어 보였다)", Q2 "자란 모습에 내가 한 일이 **얼마나 영향을 줬다고** 느껴지나요" |
| 결말 카드 | A·B를 같은 크기·같은 길이로 쓰고, 놓는 순서를 바꾼다 |
| 일상 카드 | 묶음 ㄱ·ㄴ 네 장씩 같은 크기·비슷한 길이·같은 문형('…해요. 몽망이가 …')으로 쓰고, '쓰다듬기'는 두 묶음에 같은 글로 넣는다(기준 카드). 묶음 순서는 T1·T3·T5 ㄱ 먼저, T2·T4 ㄴ 먼저. 진행자는 '돌봄'·'반려'·'현실'을 먼저 말하지 않고 카드 글만 읽는다. D1은 카드를 보이기 전에 묻는다(카드가 답을 끌지 않게). D3은 '부담스럽다'만 묻지 않고 '부담스럽지 않다'까지 세 칸을 같이 읽는다 |

## 4. 안전 (리뷰 H7 + 자살예방 안전 검수 5절, 키트 1쪽)

- **진행자 준비**: 진행자 중 1명 이상(= 안전 담당, 키트 첫머리에 이름 칸)이 한국생명존중희망재단의 '보고 듣고 말하기' 게이트키퍼 교육(무료·온라인, 과정명·시간 [확인 필요])을 마치고 진행한다. 자료 10분 읽기로는 직접 묻고 연결하는 연습이 되지 않는다.
- **섭외 안내 한 줄**: "요즘 마음이 많이 힘든 시기라면 이번엔 쉬셔도 괜찮아요."
- **동의서 한 줄**: "어떤 낱말을 써도 괜찮아요. 힘든 말을 쓰시면 끝나고 도움 받을 곳을 안내해 드려요." 녹음을 한다면 범주 기록 뒤 바로 지운다.
- **모두에게 같은 마무리**: "오늘 해 보니 마음이 어떠세요?" + '이야기 나눌 곳' 쪽지(무료·이름 말하지 않아도 됨·문자 가능, 109·마들랜·1388(24세까지, 문자 수신번호 1388)·112·119). 그래서 따로 묻는 것이 덜 튄다.
- **직접 질문**: 위기 낱말을 쓴 테스터에게 그다음 한 번만 **'자살'이라는 말을 넣어** 묻는다. "혹시 요즘 자살을 생각한 적이 있으세요?" 근거: Dazzi 외(2014) *Psychological Medicine* 44(16):3361–3363 — 직접 물어도 생각이 커지지 않는다.
- **즉각 위험**(계획·수단·오늘 밤): 혼자 두지 않기 → 위험한 물건에서 떨어져 있게 돕기(구체적 수단은 말하지 않음, WHO LIVE LIFE) → 멈추기 → 함께 109(문자 = 마들랜)·1388에 연락 → 즉각 위험이면 112·119 → 연락을 거부하면 강요하지 않고 "오늘 밤 누구와 함께 있을 수 있어요?" → 기록에는 '안전 절차 진행'만, PM에게 그날 알림(내용 없음).
- **진행자 마음 돌봄**: 안전 절차를 한 진행자는 그날 PM과 짧게 이야기한다. 진행자도 109·마들랜을 쓸 수 있다.
- 위기 낱말은 분석에서 **'곁 대답이 나왔다'는 범주로만** 쓴다.

## 5. 설계에서 고른 것과 그 까닭

| 고른 것 | 까닭 |
|---|---|
| 하루를 조건마다 3번 돈다 | 첫 대답의 놀람과 반복의 리듬을 보는 최소 횟수다 |
| 진행자가 '감정'이라는 말을 쓰지 않는다 | 감정을 쓰라고 시키면 Q5가 오염된다 |
| 커닝표에 없으면 '모르는 말' 카드 | 진행자가 즉석에서 결을 지어내면 실제 앱보다 똑똑해 보인다 |
| 28밤은 건너뛰어 완성 카드로 보여 준다 | 시간 압축. C′ 흔적 조각은 테스터가 쓴 말의 가족에서 나온다 |
| 위기 낱말이 나와도 진행을 멈추지 않는다 | 멈추면 '알아챘다'는 신호가 된다. 다만 즉각 위험이면 멈춘다(4절) |

## 6. 끝난 뒤 (기획이 할 일)

- 5부의 기록을 한 표로 모은다(이름 없음, 낱말 없음).
- 커닝표에서 찾지 못한 활용형이 있었으면, 진행자가 기억하는 **형태만**(누가 썼는지와 분리해서) 사전 표면형 후보로 옮긴다. 곁 대답 범주의 말은 옮기지 않는다.
- 기록은 30일 뒤 지운다.
