# '무슨 말을 썼나' 블라인드 — 자극물 만들기와 합격 기준 (검증 ④, v0.2)

- 작성: PL-1. 2026-11-24 v0, 같은 날 v0.2(독립 리뷰 M1 반영). 제작은 아트 + 모션 팀, 모집은 오너 또는 PM이 맡는다.
- 묻는 것: **같은 사람이 서로 다른 낱말로 키운 몽망이를 보고, 남이 그 낱말을 맞힐 수 있나?** 맞힐 수 있으면 "말이 몸에 반영된다"는 증거다.
- **PM 결정(11-24)**: 이번 단계의 주 시험은 **S1 정지 그림 3지선다**다(이레 흔적을 잰다). rollout V0-4 원안인 **3초 몸짓 4지선다(S2)는 V6c(3초 몸짓 구현) 뒤에 실기기판으로 다시 한다.**
  - **한계**: 오너의 지적("반영되는 것 같지 않다")은 **매일의 3초 대답**에 더 가깝다(리뷰 M1). S1은 그중 '이레 흔적' 쪽 가설만 잰다. 그래서 S1이 통과해도 **3초 대답이 읽히는지는 아직 증명되지 않은 상태**다. V0-5 결정 문구에 이 한계를 적는다.

## 1. 자극 설계 (S1)

| 세트 | 같은 '사람'(고정) | 낱말 3개(가족이 모두 다름) |
|---|---|---|
| A | 씨앗 1 · 송연먹 · 손 획 시드 1 | 짜증(뾰족) · 비(자연) · 사랑해(포근) |
| B | 씨앗 2 · 유연먹 · 손 획 시드 2 | 졸려(포근) · 시험(나날) · 바다(자연) |
| C | 씨앗 3 · 자연먹 · 손 획 시드 3 | ㅋㅋ(들뜸) · 엄마(곁) · 슬퍼(가라앉음) |
| D | 씨앗 4 · 송화먹 · 손 획 시드 4 | 귤(살림) · 무서워(뾰족) · 별(자연) |
| **F(가짜 흔적, 통제)** | 씨앗 5 · 송연먹 · 손 획 시드 5 | 짜증 · 비 · 사랑해. 세 그림에 **가족과 상관없는 편집**을 진짜 세트와 **같은 양만큼** 무작위로 한다. 정답지는 제작 전에 무작위로 정해 둔다 |

- 그림 한 장 = 첫 이레(7밤)를 마친 아침의 몸이다. 7밤 중 5밤은 그 낱말, 2밤은 '모르는 말'(가족에 세지 않음)이다. 그래서 그 낱말 가족의 이레 흔적 **하나만** 스민다. 같은 세트의 세 그림은 가족 흔적만 다르다.
- **가짜 흔적 세트 F의 뜻**(리뷰 M1 제안): v0의 '편집 없는 같은 그림 세트 N'은 정답이 정의되지 않았고, 우연만으로도 약 9% 확률로 시험 전체를 잘못 무효로 만들었다. 또 참가자가 "세 장이 똑같다"를 알아채면 학습 효과가 생겼다. F는 편집량은 같고 가족과의 연결만 없다. F의 정답률이 우연 근처여야 **"편집의 양이 아니라 가족 흔적이 단서"**라는 것이 증명된다.

## 2. 지금 렌더로 근사하는 방법

지금 렌더는 이레 흔적을 그리지 못한다. 그래서 몸은 실제 렌더로 캡처하고, 흔적만 정한 수치대로 편집한다. 코드는 바꾸지 않는다.

| 단계 | 방법 | 비고 |
|---|---|---|
| ① 바탕 캡처 | 웹 렌더(`pnpm web`)의 M1 보드(`?screen=m1`, `apps/mobile/src/screens/M1Board.tsx`)와 같은 조합: `traitsOf(seed)` + 먹 + `handRecords(seed, 7, shape)`(`packages/core/src/visual/pose.ts`). 세트마다 1장, 2배 해상도, 낮, 빈 한지. 캡처 방식은 `scripts/m1-capture.mjs`(playwright)와 같다 | 단독 보기(`?seed=`)를 다는 일은 범위 밖 [확인 필요] |
| ② 세 장 복제 | 같은 바탕을 3장으로 | |
| ③ 흔적 편집 | 아래 표의 **수치만** 적용한다(Figma 덮기 또는 이미지 편집기). 편집 기록을 남긴다. F 세트는 '가짜 편집 표'에서 무작위로 고른다 | 편집자는 낱말을 모르고 가족 id만 받는다 |
| ④ 내보내기 | 같은 크기·같은 압축(PNG 무손실), 파일 이름 무작위 4자 | 새는 단서 막기 |
| ⑤ 썸네일판 | 같은 그림을 96px로 줄인 판(D-24) | 보조 |

**가족 흔적 편집 수치**(heart-grain 3절. W = 몸 폭)

| 가족 | 편집 |
|---|---|
| 들뜸 | 빗 세 가닥 위로 +6°. 번짐 고리 바깥에 고리 색 잔방울 6~8개(지름 0.02W) |
| 포근 | 번짐 고리 폭 ×1.25, 고리 가장자리 블러 +2px(2배 해상도 기준) |
| 뾰족 | 빗 끝을 45° 사선으로 각지게. 번짐 고리 블러 −50%(경계 또렷) |
| 가라앉음 | 번짐 고리 폭 ×1.2 + 블러 +3px. 몸 가장자리 안쪽에 폭 0.03W의 '물기 윤' 띠(몸 색에서 종이 쪽 10%). 빗 −8°(늘어뜨림) |
| 자연 | 번짐 고리를 오른쪽 위로만 ×1.3 |
| 살림 | 몸 안 잔물결 두 겹: 몸 중심에서 아래로 0.15W 지점을 중심으로 반지름 0.18W·0.28W 호 두 개(위쪽 반은 그리지 않음, 몸 윤곽 안으로 자름), 선 굵기 0.012W, 몸 색에서 종이 쪽 8%. 몸 윤곽·크기·받침 띠 그대로(QA-3 R8 A안). 가라앉음의 '몸 가장자리 안쪽 물기 윤 띠'와의 혼동률을 따로 본다 |
| 곁 | 빗 바깥 두 가닥을 가운데로 3°씩 모음, 몸 전체를 앞(아래)으로 4° 기울임 |
| 나날 | 빗 세 가닥의 각도 차를 0으로, 빗 전체를 곧게 +4°(몸 크기 변화 없음, QA-3 R8-1) |

**가짜 편집 표**(F 세트. 크기는 진짜와 같고 가족과 무관하다): 몸 전체를 좌우 대칭으로 뒤집기 / 번짐 고리를 왼쪽 아래로 ×1.3 / 빗 가운데 가닥만 길이 ×1.15 / 몸 안 위쪽에 옅은 잔물결 한 겹(A안과 같은 종류, 가족과 무관 — QA-3 R8-5) / 받침 띠를 오른쪽으로 0.05W 밀기 / 고리 블러 +2px를 아래쪽 절반에만. 그림마다 둘을 무작위로 고른다(세 그림이 서로 다르게).

- **하지 않는 것**: 소품·아이콘·글자·눈물·하트·빗방울, 먹 색조 바꾸기, 표정 바꾸기.

### S2(V6c 뒤): 3초 몸짓 4지선다

- V6c 구현이 끝나면 **실기기 녹화**로 한다. 같은 바탕 몸에 heart-grain 4절의 3초 대답을 넣고, 소리 없이 3초 한 번만 재생한다. 낱말 4개 × 2세트 = 8클립, 4지선다다. 합격은 정답률 ≥ 50%(우연 25%)다(V0-4 원안 그대로, 참고: 80문항 중 40개 이상이면 우연일 확률 1.3×10⁻⁶).

## 3. 진행

|---|---|
| 참가자 | 외부 10명. 종이 프로토타입 테스터는 뺀다(결 카드를 이미 봤다). 앱을 모르는 사람. 온라인이고 이름·연락처는 받지 않는다. **설문 도구의 이메일 수집과 로그인 요구를 끈다**(Google Forms '이메일 주소 수집: 수집 안 함' [확인 필요]). 연령은 종이 시험과 맞춰 **만 19세 이상**으로 묻는다(설문 첫 문항 예/아니오, '아니오'면 종료) |
| 형식 | 온라인 설문 한 개, 약 8분 |
| 순서 | ① **몸만**: 세트 5개(A·B·C·D·F)를 무작위 순서로, 세트 안 그림 순서도 섞어서 보여 준다. 그림 3장과 낱말 3개를 함께 보여 주고 **그림마다 낱말 하나를 고르게 한다**(다시 골라도 된다). 확신(상/하)과 "무엇을 보고 골랐나" 한 줄을 받는다 ② **몸 + 꿈 카드**(그날 꿈 카드를 곁들임) ③ **96px 썸네일**로 ①을 반복한다 |
| 왜 ①을 먼저 하나 | 꿈 카드(비 → 빗소리)는 너무 쉬운 단서라서, 몸만으로 맞히는지를 먼저 깨끗하게 재야 한다 |

## 4. 합격 기준 (S1, 몸만)

같은 사람의 12문항은 서로 독립이 아니다(같은 세트 3장을 나란히 보고 소거법을 쓸 수 있다). 그래서 **사람 단위를 주 기준**으로 하고, 전체 정답률은 보조로 둔다(리뷰 M1).

| 지표 | 합격 | 근거 |
|---|---|---|
| **사람 단위(주 기준)** | 10명 중 **7명 이상**이 진짜 세트 12문항 중 **5개 이상** 맞힘 | 우연이면 한 사람이 5/12 이상일 확률 0.37 → 10명 중 7명 이상일 확률 **0.035** |
| 세트별 | 진짜 세트 4개 중 **3개 이상이 ≥ 50%(30문항 중 15개 이상)** + **가족별 오답 행렬**(어느 가족을 어느 가족으로 착각했나)을 함께 보고 | 한 세트가 우연으로 15/30을 넘을 확률 0.043. 4세트 모두를 요구하면 참 정답률 55%에서도 통과 확률이 0.35밖에 안 돼서, 3/4 세트로 둔다 |
| 전체 정답률(보조) | 진짜 세트 120문항 중 ≥ 50%(60개) | 독립이라고 가정하면 p ≈ 1.2×10⁻⁴. 보조 지표로만 쓴다 |
| **가짜 흔적 세트 F** | 정답률 **≤ 50%(30문항 중 15개 이하)** | 우연으로 16개 이상일 확률 0.019. 넘으면 '편집 양' 같은 다른 단서가 있다는 뜻 → 그 결과를 보류하고 원인을 찾는다(바로 무효로 하지 않는다) |
| "무엇을 보고 골랐나" 감사 | 편집 표에 없는 단서(색·파일 순서 등)를 말한 답이 10% 이상이면 재검토 | |
| 보조: 몸 + 꿈 카드, 96px | 기록만 한다 | 몸만으로는 떨어지고 꿈 카드로만 붙으면 "꿈이 일을 다 하고 몸은 반영이 약하다" → 흔적을 강화한다 |

- **검정력(정직하게)**: 참 정답률이 45%면 사람 단위 기준을 통과할 확률은 0.64, 50%면 0.89, 55%면 0.98이다. 효과가 중간 정도면 떨어질 수 있다. 떨어지면 오답 행렬로 헷갈린 두 가족의 편집 수치를 벌리고, 하루 안에 다시 시험한다.
- 판정: 사람 단위·세트별·F·감사 네 가지를 모두 지키면 **④(S1) 계속 진행 신호**다. 3초 대답(S2)은 V6c 뒤에 따로 판정한다.

## 5. 한계

- **근사다.** 실제 렌더(셰이더 번짐·숨)는 손 편집과 다르다. 구현 뒤 실제 렌더로 다시 한다(시드 100개 썸네일 거리 검사와 함께).
- 실제 유저의 7밤은 한 낱말을 5번 쓰지 않는다. 이 시험은 '흔적이 보이는가'의 **상한**을 잰다.
- **공유와의 긴장**: 이 시험이 통과한다는 것은 남이 그림만 보고 가족을 짐작할 수 있다는 뜻이다. 그래서 공유 이미지에서 마음 가족 흔적을 지울지는 heart-grain 13-1에서 PM이 정한다.
