## 2. 형식 (스키마 요약)

```json
{
  "lexVer": "0.1.0", "lang": "ko", "sensesVer": "0.1.0", "lengthLimit": 6,
  "entries": [
    { "id": "ko.0069", "lemma": "짜증", "forms": ["짜증나", "짜증남", "짱나", "ㅉㅈ"],
      "sense": "spiky.out.irritated", "intensity": 2, "flags": [], "pos": "noun",
      "source": "hand-v0", "review": { "status": "draft", "by": [] } }
  ]
}
```

- `forms`에는 **정규화한 뒤의 모습**을 적는다(띄어쓰기 없음, 로마자는 소문자). 린트가 이것을 강제한다.
- `intensity`는 내부 값이다. 몸짓 진폭에만 쓰고 누적에는 넣지 않는다. **욕설은 2 이하**다.
- `flags`: `profane`(욕설: 결은 받고, 공유에서 글자 가림, 강도 ≤ 2) · `crisis_strong`/`crisis_soft`(이게 붙으면 `sense`는 반드시 `x.stay`, 스키마가 강제) · `homonym` · `hyperbole` · `silly` · `muted`(운영 파일 전용).
- `x.stay`(곁 대답)는 **런타임 전용**이다. 세이브에는 `warm.in.still`(고요)로 저장한다(heart-grain 9절).
- `id`는 한 번 주면 다시 쓰지 않는다. 결을 바꾸는 수정은 minor 이상, 표면형만 더하는 수정은 patch로 버전을 올린다. 지난 말은 다시 해석하지 않는다(D-13).

## 3. 정규화 규칙

| # | 규칙 | 예 |
|---|---|---|
| 3-1 | NFC로 바꾸고 **로마자는 소문자로**(한국어 문자열 안의 `JMT`도) | `JMT` = `jmt` |
| 3-2 | 띄어쓰기를 모두 지운다 | `짜증 나` = `짜증나` |
| 3-3 | 문장부호·꾸밈 기호를 지운다. 이모티콘 토큰(`:(` `<3` `^^` 등)은 먼저 떼어서 본다 | `happy!!` → `happy` |
| 3-4 | 동음이의어는 '한 마디로 썼을 때 가장 흔한 뜻'으로 정하고 `homonym`을 단다 | 눈 = 雪, 풀 = 草, 엄마야 = 가족(놀람 감탄과 겹침), back·hurt |
| 3-5 | **반복 접기**: 1글자 단위(3번 이상)와 **2글자 단위**(2번 이상)를 2개 → 1개 순으로 접는다. 원래 5번 이상 반복이면 강도 +1 | `ㅋㅋㅋㅋㅋ`→`ㅋㅋ` 강도 2, `loooool`→`lol`, `ㅈㅅㅈㅅ`→`ㅈㅅ` |
| 3-6 | **강조·약화 접두**: 강조(완전·진짜·너무·엄청·되게·겁나·존나·졸라·개·존·핵·왕·킹·찐·넘 / so·very·super·really·too) +1, 약화(좀·조금·약간·살짝 / kinda·a bit) −1. **ko는 남는 줄기 2자 이상**이고, 예외(개강·개학·개인·개미·왕자·핵심·존경·찐빵·넘어)는 벗기지 않는다 | `개짜증나`→짜증 3, `겁나배고파`→밥 3, `개강`→벗기지 않음 |
| 3-7 | 굳은 신조어는 접두를 떼지 않고 표면형으로 적는다 | `킹받네`, `개꿀` |
| 3-8 | 끝 자모 꼬리(ㅋ·ㅎ·ㅠ·ㅜ·ㄷ)를 떼어 앞말로 판정한다. 꼬리는 기록만 한다 | `배고파ㅠㅠ` → 밥 |
| 3-9 | 어미 벗기기(최대 2번, 긴 것부터) | 안전망 |
| 3-10 | 자모·초성 말은 표제어로 둔다. 초성이 두 말과 겹치면 더 안전한 쪽으로 정한다 | `ㅈㅅ`(죄송/자살) → 곁 대답 soft |
| 3-11 | 오타는 흔한 것만 표면형으로 넣는다. **퍼지 대조(편집 거리)는 하지 않는다** | `조아`, `힘드러` |
| 3-12 | 영어는 아포스트로피를 지운 모양 | `cantwait` |

## 4. 대조 순서 (`rules-v0.json` `order`)

1. 정규화(3-1~3-3)
2. **위기 대조**(5절의 공격형 정규화) — 가장 먼저 한다. 꼬리·접두·끼운 글자가 붙어도 약해지지 않는다. 손글씨 후보 2·3위에서만 걸리면 soft로 받는다
3. 이름 일치(기본 이름 표 + 세이브의 유저 이름) → `x.call`
4. 가림 목록 완전 일치 → `x.unknown` + `muted`
5. 표면형 완전 일치
6. 반복 접기(3-5) 뒤 다시 5
7. 강조·약화 접두(3-6) 뒤 다시 5
8. 끝 자모 꼬리(3-8) 뒤 다시 5
9. 어미 벗기기(3-9) 뒤 다시 5
10. 이모티콘 표
11. 다른 언어 사전 표면형 일치
12. 과장: `(상태어)+죽겠-` **또는 `죽겠-+(상태어)`** → 상태어의 말결, 강도 3, `hyperbole`
13. 두 말 합성 분할: **조각 하나라도 곁 대답 말이면 분할을 멈추고 `x.stay` soft**로 받는다. 아니면 마음 가족 쪽이 주 결이 되고, 다른 쪽은 `secondary`(꿈 가중 ×2에만 씀)가 된다. 위기 예외 낱말이 들어 있으면 분할하지 않는다
14. 욕설이면 강도 상한 2
15. 모두 실패하면 → `x.unknown`(모르는 말, 갸웃)

- 사전 밖 낱말은 '가장 가까운 결'을 억지로 고르지 않는다. 엉뚱하게 알아듣는 것이 모르는 말보다 나쁘기 때문이다.
- 1.x 서버 해석(동의 뒤)은 15번 자리에만 들어간다.

## 5. 위기 대조 (`rules-v0.json` `crisis`, heart-grain 8-2)

| 단계 | 내용 |
|---|---|
| ① 예외 | 그만살찌·그만살쪄·그만살찐·그만살빼·자살골·자해공갈·suicidesquad를 지운다. 예외도 전문가 검수 대상이다 |
| ② ko 변형 | 기본(한글·자모·로마자·숫자만) → 자모 결합(`ㅈㅏ살`→자살) → 음절만(끼운 ㅋ·숫자·로마자·이모지 제거) → 반복 접기 |
| ② en 변형 | 소문자 → leet(1→i, 3→e, 0→o, 4→a, 5→s, @→a, $→s, !→i, 7→t) → 글자만 → '2'→'to' 변형 → 겹글자 접기(줄기도 같이 접음) |
| ③ strong 줄기 | 부분 일치. 소리 나는 대로 쓴 변형 포함(죽고시퍼·죽구싶·주거싶·뒤지고싶·디지고싶 …) |
| ④ en 경계 줄기 | kms(strong), kys·endit·imdone·nolife·giveup(soft)는 처음·끝·낱말 단위로만 본다 |
| ⑤ soft | soft 줄기 · 완전 일치만 보는 말(살자·유서·투신 — 일상 뜻이 겹침) · 초성 3자 이상(ㅈㄱㅅ·ㅅㄱㅅ …) |
| ⑥ 후보 | 손글씨 상위 3후보 전부. 2·3위에서만 걸리면 soft |
| 익은 말 | `weakMarkers`(죽·살기·사라지·뒤지 / die·kill·dead·hurt·cut …)가 있거나 ②~⑤에서 걸리면 익은 말 끄덕임 금지 → 곁 대답 |

- **이 정규화는 위기 대조에만 쓴다.** 일반 대조에 쓰면 '죽(粥)'이 엉뚱하게 바뀌는 식으로 결정성과 정확도가 깨진다.
- 원칙은 **놓침 0이 먼저**다. 오탐을 줄이려고 줄기를 좁히지 않는다. 오탐의 비용은 '곁으로 와서 숨 쉬기'와 늘 있는 항목뿐이라 작다.

## 6. 욕설·금칙어·가림

| 종류 | 처리 | 결 | 공유 |
|---|---|---|---|
| 욕설(씨발·ㅅㅂ·존나·ㅈㄴ·미친·fuck·shit·damn 등) | `profane`, 검열하지 않음, **강도 ≤ 2** | 뾰족 | '쓴 말 보이기'를 켜도 그 글자는 가림 |

| 이름 금칙어 | 별개(B5 `name-blocklist`). **위기 줄기를 이름 금칙어에 넣는다** | — | — |
