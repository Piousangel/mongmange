## 2. 의제 1 — 오너에게 무엇을 물을지 (결정)

- 쟁점 ① 질문 수: 게임 4, UX 3. → **3 + 알림 1.** 오너는 이미 시안첩을 받았고 답이 없다. 질문을 늘리면 늦어진다(UX).
- 쟁점 ② '쓴 말 찍기'(dream-compose v2 질문 1): 공유 루프 v1 미리보기에 이미 '쓴 말·이름·링크 기본 꺼짐'이 있고, 카드마다 켜는 스위치가 있다(share-loop 0절 ②). 레드라인 4는 '기본으로 들어가지 않는다'이므로 이 설계는 레드라인 안이다. → **결정으로 두고 알림으로 알린다.** 게임의 조건(켤 수 있는 낱말은 세상 가족만 — 마음 이름은 기존 규칙대로 별도)을 붙인다. 켜면 매번 꺼진 채로 다시 시작한다(UX). 처리방침 3-4 개정 문안에 한 줄을 더하는 일은 법률 v2 몫.
- 쟁점 ③ '놀이 흔적이 다음 날 꿈에 남는다'(의제 8): 세 입장 모두 오너 질문에서 뺐다. → 팀이 정한다(7절).
- 쟁점 ④ 기한: 아트 11-28, UX 12-03. → **12-01.** 아트 처리량 실측(12-05) 전에 화풍을 정해야 72조각 손질이 한 번에 끝난다.
- 시안첩 v2: **재손질 1차(사진 질감 4조각, 약 1일) 뒤에 다시 찍는다**(아트). 들어갈 장면은 backlog 의제 1의 다섯에서 '이레 한 획 새김'을 인장판 v2로 바꾼 것이다.

## 4. 의제 3 — 렌더링 언어 통일 (결정 — 결정자 DS-1·DS-3)

- **기준 언어: 담묵 번짐 래스터 하나.** 장(마블링)과 물길은 코드 그대로 둔다. 세 입장 모두 같다.
- 규칙(아트 입장 요약):
  - **가장자리**: 외곽선 0. 젖은 테(짧은 변의 2~4%, 안쪽보다 0.10~0.15 짙게)와 바깥 번짐(σ 1~1.5%)으로 처리한다. 날카로운 가장자리는 비백 끝에만 쓴다.
  - **농담**: 몸 1.0 > 짙은 먹 0.72 > 중묵 0.45 > 담묵 0.25 > 종이. 한 조각에는 최대 세 단을 쓰고, 짙은 먹은 주연만 쓴다. 반사광·3D 음영·나무결·돌 표면은 금지다. 먹은 한 색 + 알파로 만든다.
  - **금빛**: 선으로만 쓴다. 덧말 금실 두 가닥, C 뒤 옅은 번짐(불투명도 ≤ 0.18), 기존 두 자리만 허용한다. 금점·멈춘 뒤 반짝임은 금지한다(의제 4 버튼 오독 대책).
  - **장식 층 자리표**: 밥·간식·I-061 먹구름·I-020 징검 방울은 한 화면에 동시 2개까지, 모두 담묵 이하로 하고, 둥근 검은 덩어리는 금지한다. **장식 층과 덧말 사물이 겹치면 안 된다** — 지금 밥 장식 '등불'은 덧말 1위 '등불'(13.4%)과 같다(게임 지적). → 밥 장식을 다른 사물로 바꾼다(DS-1이 고름).
