# 실험 — 6초 영상 블라인드(5프레임 스트립으로 대신함) · 2026-11-26

- 만든 것: `strips.html`(캔버스 한 파일, 탐색 전용) → `capture.mjs`로 캡처한 `strip-*.png`
  - `strip-body.png`: **몸 4획 보강안**(바깥 A 꼬리 + 속 D 보강). 몸통은 몸 속 밝은 윤 먹(`#9d9283`), 꼬리는 몸 밖 종이 위 담묵. 획은 유저 글씨(나눔손글씨 붓 글리프)에서 떼어 낸 실제 한 획이다.
  - `strip-board.png`: **인장판 네 칸**(몸 오른쪽 아래 0.46W, 2×2, 인주 테두리, 칸마다 그 이레의 한 획).
  - 두 몸 스트립은 1~3프레임(글씨 모음 → 들림 → 날아감)이 같다. 4는 꽂힘·물결, 5는 28번째 아침 초상이고, 오른쪽 칸은 64px(첫날 / 28번째 아침)이다. **자막은 넣지 않았다**(그림만으로 읽히는지 잼).
  - `strip-dutA.png`: 덧말 **(가) 현상 연출**. A(우산 = 비) → B(두 찻잔 = 친구, 담묵) → 금실이 A·B에서 뻗어 만남 → 먹 한 방울 → C(등불) 핌 + 자막 "몽망이의 꿈이 ‘등불’을 덧붙였어요".
  - `strip-dutB.png`: 덧말 **(나) 누르면 출처**. 등불이 처음부터 있음 → 손가락 → 금실이 C에서 A·B로 되감김 → "비 · 친구 → 등불" → 실이 옅게 남음.
  - `strip-style.png`: 의제 3 대표 시안(지금 대 기준 언어). 오른쪽 사물 셋은 Gemini 견본(`gen/`, gemini-3.1-flash-image, 3장, 402 없이 생성)이다. 라이선스 원장에 '탐색'으로 적었다.
- 블라인드: 제작 정보를 모르는 서브에이전트 3명(24세 직장인 여성 · 33세 남성 회사원 · 19세 대학생). 이미지 4장만 봄(`blind/` — 파일 이름 set1-X = 인장판, set1-Y = 몸, set2-P = (나), set2-Q = (가)). 보는 순서는 사람마다 바꿨다. 사용자가 아는 정도의 앱 소개와 '이번 주에 쓴 말에 비·친구가 있다'만 알려 줬다.
- 기준: 몸 = '내 글씨에서 나온 것(㉠)으로 알아봄' ≥ 2/3. 덧말 = '꿈이 덧붙인 것(㉡)으로 읽힘' ≥ 2/3.

| 판정자 | 인장판 Q2 | 몸 Q2 | 인장판 불편 | 몸 불편 | 64px 인장판 / 몸 | 보여 주고 싶음(1~5) 인장판 / 몸 | '내가 남긴 것' |
|---|---|---|---|---|---|---|---|
| 24세 여 | ㉣ 도장·출석(흐름을 보면 ㉠ 같기도) | ㉢ 상처·얼룩 | **[불쾌]** 출석·쿠폰, 빠지면 빈칸 부담 | **[불쾌]** 상처·흉터 "다쳤나?" | 조금 / 조금 | 3 / 2 | 인장판 |

| 19세 | ㉣(㉠ 반쯤) | **㉠**(㉢일 뻔함) | 없음, 몸이 변한 느낌 약함 | **[불쾌]** 할퀸 자국 | 조금 / 조금 | 2 / 4 | 몸 |
| **집계** | **㉠ 0/3**(반쯤 3/3) | **㉠ 1/3** | 부담 1 | **불쾌 3/3** | | 평균 2.7 / 2.7 | 인장판 2 · 몸 1 |

- **판정: 두 안 모두 기준(㉠ ≥ 2/3) 미달.**
- 몸 속 획은 세 사람 모두 **상처·흉터**로 읽었다. 이것은 안전 문제다(D-03 처벌 없음, 회의 1차 S1 '소멸 불안'과 같은 축). 블라인드 규칙(안전 지적은 1명이어도 반영)에 따라 **몸 속에 밝은 획을 넣는 방향(D 계열)을 멈춘다.**
- 한계: 이번 몸 안은 대비를 크게 올렸다(`#9d9283`). 아트가 제안한 D′(`#6A645B`, 대비 약 3:1)는 덜 상처 같을 수 있다. 하지만 11-25 D안(대비 1.81:1)은 64px에서 사라졌다. **보이면 상처, 안 보이면 없음**이라 구조적인 문제로 본다 [추정].
- 인장판은 세 사람 모두 **흐름(1~4)을 보면 내 글씨**라고 알아봤다. 그런데 결과(5)만 보면 **도장·출석판**으로 읽었다. 원인은 첫날부터 보이는 **빈 십자 칸**이다. 게임·UX 입장문도 같은 위험을 미리 짚었다('빈칸이 보이면 도장판·남은 개수'). → 다음 판은 **빈칸 0**: 획이 생길 때 칸이 함께 생기고, 칸 선과 테두리를 없애 낙관처럼 찍는다.

## 2. 의제 4 — 덧말 (가) 대 (나)

| 판정자 | (가) Q2 | (나) Q2 | (나) 첫인상 | 눌러 보고 싶음 (가) / (나) | 불편 | 더 잘 읽힌 쪽 |
|---|---|---|---|---|---|---|
| 24세 여 | ㉡ | ㉢ 배경 장식(글자를 보고서야 ㉡) | 장식, 고리 = '눌러 보세요' 버튼 | 조금 / 예(보상·운세) | (나) 'A·B→C'가 공식·레시피 같음 | (가) |
| 33세 남 | ㉡(자막을 보고 확신) | ㉡(처음엔 ㉢) | 배경 장식 | 조금 / 예(아이템) | (나) 게임 아이템 합성 같음 | (가) |
| 19세 | ㉡ | ㉡(㉠과 고민) | 원래 있던 장식·아이템 | 조금 / 예(보상) | (나) 조합식이 꿈 감성을 깸 | (가) |
| **집계** | **㉡ 3/3 → 통과** | ㉡ 2/3(마지막 답) | 장식·아이템 **3/3** | | 조합식 글자 3/3 | **(가) 3/3** |

- **판정: (가) 통과(3/3).** (나)는 마지막 답으로는 2/3이지만, 첫인상은 세 사람 모두 장식·아이템이었다. 'A·B → C' 글자는 세 사람 모두 '게임 조합식'이라 감성을 깬다고 했다.
- 주의: (가)에서 두 사람이 "**자막이 없었으면** 장식·아이템으로 봤을 것"이라고 했다 → 자막 한 줄은 선택이 아니라 필수다. 그리고 '빛나니 눌러 보고 싶다'는 (가)에서도 3/3 남는다(누르면 '왜 등불인지 한 줄'을 기대).
- (가)에서 '두 찻잔 = 친구'는 바로 연결되지 않았다(33세). 이것은 조각 매핑 문제다(덧말 연출과 별개).
