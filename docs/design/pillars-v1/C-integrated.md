## 0. 결론 (먼저 읽을 것)

1. **자유도는 두 갈래다(오너 11-20).** ① 키우는 방식이 결과를 바꾼다(획·성향·결·정) ② 유저가 직접 고른다(먹·이름, 1.0 직후 붓·종이·인장 글자 등). 둘 다 "사람마다 다른 몽망이"를 만든다.
2. **한눈에 보이는 차이의 주연은 여전히 손 획이다.** 그래서 획 층 가시성(첫 두름 금박 선 등)을 1주차에 한다. 체형 3 × 빗 모양 4(타고남)는 **나란히 놓아야** 보인다. 먹 4는 번짐 고리·담묵 획·밤 몸에서 나란히 놓으면 분명하고(OKLab 0.044~0.071), 썸네일 한 장에서는 '푸른 기·갈색 기' 정도다. 낮 몸 자체에서는 보이지 않는다(OKLab 0.010~0.017, 의도).
3. **출시 전 신규 5개**: M1 타고남 + 먹 고르기 / M2 이름·인장·이름표 + 이름 가락 / M3 결 이름 + 공유 꼬리표 + '획 → 몸' 랜딩 / M4 정·손 기억·반김 / M5 함께 숨 쉬기. **기능 기준 13.5개발일**(상한 15 안), 다국어·테스트·리뷰 포함 **18.75일**.
4. **빌드는 셋.** 빌드 1(11-29) = 세이브 v2 + 공유 + 평점(비공개 테스트 14일 카운트 시작) / 빌드 2(12-10) = M1~M4(기능 플래그) / 빌드 3(12-19, RC1) = M5·모티프 25. ~~동결 12-26.~~ [대체됨 → D-23: 소프트런칭 12-22 전후 = RC1 기준, 그 뒤 OTA·플래그]
5. **가용일은 거의 꽉 찬다**(가용 41 vs 필요 40.75, 4-1 표). 그래서 12-03에 실측 처리량을 보고, 모자라면 자르는 순서를 그때 바로 적용한다(12-19까지 기다리지 않는다).
6. **확정 전 관문**: 블라인드 '같은 몽망이 찾기'(카드 크기 80%·썸네일 70%, **외부 표본만**, 12-05), 서운 비네트(머뭇거림, 5명 중 0명, 12-12), 결 이름 서열(5점 평정 차이 1.0 이하, 12-05). '알아본다'·이름 지은 비율은 ~~01-19~~ 소프트런칭 판정(01-21~01-26, D-23)에서 판정한다 — 이름 비율은 집계 핑(이름 시점 A/B 주지표), '알아본다'는 설문.

- **서운 = 머뭇거림(기본, 유일안)**: 72h 이상 비운 뒤 앱을 연 첫 순간, 몽망이가 **제자리에서 고개를 한 번 갸웃하고 시선은 유저 쪽에 둔 채 0.8초 머문다.** 비켜 앉기·몸 돌리기·등 돌림·크기 줄이기·빗 납작은 **쓰지 않는다.** 순서: 마른 몸 그대로 + 머뭇거림 0.8초 → 첫 터치 → 연적 물 한 방울(시스템 3.6) → 그날 가장 큰 반김(기쁨 1.5배 + 이름 가락 2회). 머뭇거림과 물방울은 **같은 프레임에 겹치지 않는다.** 글·알림 없음.

### 2-5. 결 이름 (B)과 공유 꼬리표

- 결 = 성향 4축에서 σ 보정 argmax로 고른 축과 부호, **8개**. 이레 아침 문장 셋째 줄이 처음 부른다. **결 전환(히스테리시스 1.5배·3밤)과 전환 문장은 1.0 직후**로 미룬다(이레 공개만 출시 전).
- 한국어(가안): 느긋결 / 날랜결 · 여린결 / 굳센결 · 홀로결 / 곁결 · 아늑결 / 먼눈결.
- **영어(가안 v1.1)**: Slow-spread / Quick-breath · Fine-tip / Firm-stroke · Own-pace / Close-by · Homebody / Far-gazer. *(Slow-bleed는 '피 흘림', Nestle은 상표 연상이라 버림. 원어민 2명 이상 검수, D-17 작가 몫)*
- 공유 꼬리표 자리: 꿈 카드 아래 띠 `{이름} · {먹} · {결}` + 인장, 이름표, 두루마리 영상 끝 1.5초.
- **랜딩 기본 = '획 → 몸' 15초 루프**(D-18 ④ 미리보기 영상을 잘라 재사용). 그 위 한 줄은 링크의 먹·결을 읽어 "송연먹 · 느긋결 몽망이를 보셨군요"(2언어 한 틀, 32×2 문구를 따로 쓰지 않음). 유형별 예시 그림 32장은 만들지 않는다.
