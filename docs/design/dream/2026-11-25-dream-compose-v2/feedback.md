## 3. 타깃 유저 판정
- 한 장으로 느낀 카드: B·D·E·H / 붙여 놓은 카드: A·C·F·G("수묵 배경 위에 질감이 다른 사진 같은 오브젝트가 스티커처럼").
- **금빛 덧말**: "'꿈이 덧붙였다'는 느낌은 들지 않았다." 위 금빛 등 = 방 전등, 금빛 덩어리·점 = **눌러야 하는 아이템·보물·버튼**. E의 가는 금빛 실이 가장 의도에 가까움. → "아침에 '몽망이가 이걸 더 꿨어요' 같은 한 줄이 있어야."
- **공유**: B·E·H는 올리고 싶음(베이지 수묵 톤, 작게 자는 몽망이). 단 "카드만 올리면 친구는 '이게 뭐야?'로 끝난다. **내가 쓴 말이 카드 위에 작게 같이 찍혀야** '내 말이 꿈이 됐어'가 전달되고 '나도 해 볼래'가 나온다." 한 폭은 가로가 길어 스토리 세로에서 너무 작음 → 날짜·말이 보이는 세로 스크롤 영상이면 올림.
- **몸**: 가를 갖고 싶음(쌓인 게 확실히 보임, 다만 액세서리를 받은 느낌·헤드폰·행성 고리). 나 = 얼룩·털, 다 = 와이파이·떨고 있음 **[불편: 떨거나 아픈 것처럼]**. **셋 다 '내 글씨가 몸에 남는다'는 연결이 안 보임.**
- **새김 순간**: 흐름은 좋은데 밋밋함. 4의 금빛 물결이 가장 짜릿, 5는 남은 변화가 작아 허무. **3에서 몽망이가 회색으로 바래는 장면은 '죽은 건가? 사라지나?' 불안.** 소리 제안: 생길 때 '스윽', 빨려 들 때 '똑', 퍼질 때 풍경·싱잉볼 '띵—' + **짧은 진동 한 번**("길게 울리면 감성이 깨진다").
- 불편: 순간 3(소멸 불안), 몸 다(떨림·아픔), 몸 나(곰팡이·상처), 카드 C(쓰레기·젖은 휴지), A·F·G의 사진 질감 물건(낡고 차가움). 무섭거나 징그러운 것은 없음.
- 총평: "톤과 몽망이는 잠들기 전에 보기 좋을 만큼 예쁘지만, 소재가 많은 카드는 스티커 같고, 금빛과 몸의 획은 '내 말과 내 획'이라는 연결이 보이지 않아 아직은 '예쁜 그림'에서 멈춘다."
