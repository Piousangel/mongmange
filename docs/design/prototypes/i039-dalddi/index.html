달 띠 · 달 한 획

I-039 달 띠(함께 지낸 밤마다 그 밤 실제 달이 화첩 띠에 한 점씩) + I-033 달 한 획(보름 깸에 연습지에 그은 원 한 획이 꿈의 달이 됨).

몽망이와 며칠 밤을 지내 보세요. 연적을 누르면 재우고, 화첩을 누르면 펼쳐져요.

진행자 화면이에요. 테스터에게는 테스터 화면을 보여 주세요(질문·기록 숨김).

확인하고 싶은 질문 3
  1. 진행 막대인가 — 밤마다 띠에 달이 한 점씩 찰 때 '끝이 다가온다·며칠 남았다'로 읽나요, '그 아이가 지나온 달'로 읽나요? 볼 것: 빨리 감기 뒤 테스터 말에서 '며칠 남았', '끝', '다 채우면' 류를 센다(아래 단추). 기준 안: 5명 중 1명 이하. 하루 거르기를 넣어 '빈 칸' 말이 나오는지도
  2. 내 아이 것인가 — 시작 달이 다른 띠 둘(하나는 남반구 거울)을 나란히 보여 주면 자기 아이 띠를 고르나요? 다른 띠가 '이상하다'가 아니라 '다른 아이'로 보이나요? 볼 것: '띠 둘 보기'에서 고른 쪽(기록), 고른 까닭에 '달 모양·시작'이 나오나. 기준 안: 5명 중 4명 이상 자기 것
  3. 찌그러진 내 달 — 보름 깸에 그은 원(일부러 찌그러지게 그어 달라고 해도 됨)이 꿈 카드·띠 보름 칸의 달이 될 때 '내 달'로 좋나요, '못 그렸다'인가요? 볼 것: '못 그렸다·다시 그릴래' 류 말(아래 단추), 다시 긋는 횟수. 기준 안: '못 그렸다' 5명 중 0명. 안전: 몽망이는 칭찬·평가 몸짓 0, 원은 중심·반지름만 맞추고 떨림·끊김은 그대로

시제품 전용: 반구·태어난 날·보름 경로·빨리 감기·하루 거르기 단추는 실제 앱에 없어요. 다른 꿈 카드·밥·한 마디는 생략했어요. 그린 것은 저장되지 않고 어디에도 보내지 않아요. 페이지를 닫으면 사라져요.
