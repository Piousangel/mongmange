달 띠 · 달 한 획

I-039 달 띠(함께 지낸 밤마다 그 밤 실제 달이 화첩 띠에 한 점씩) + I-033 달 한 획(보름 무렵 깸에 연습지에 그은 원 한 획이 꿈의 달이 됨). v1.1.

몽망이와 며칠 밤을 지내 보세요. 연적을 누르면 재우고, 화첩을 누르면 펼쳐져요.

진행자 화면이에요. 테스터에게는 테스터 화면을 보여 주세요(질문·기록 숨김).

확인하고 싶은 질문 3
  1. 진행 막대인가 — 밤마다 띠에 달이 한 점씩 찰 때 '끝이 다가온다·며칠 남았다'로 읽나요, '그 아이가 지나온 달'로 읽나요? 볼 것: 테스터 말에서 '며칠 남았', '끝', '다 채우면' 류를 센다(아래 단추). 기준 안: 5명 중 1명 이하. 하루 거르기를 넣어 '빈 칸' 말이 나오는지도
  2. 하늘 결 = 기분 일지인가 — 화첩의 '하늘'(맑음·구름 한 자락·가는 비)을 고르는 것이 '오늘 밤 하늘'로 읽히나요, '오늘 기분 체크'로 읽히나요? 볼 것: 하늘을 펼쳐 고르는가, "이건 뭘 고르는 거라고 생각했어요?"에 '기분·우울·마음' 류 말(아래 단추)이 나오나. 진행자 단추로 '지난 밤 결 남김/안 남김'을 바꿔 보며 남긴 띠가 일지처럼 읽히는지. 기준 안: '기분' 류 5명 중 1명 이하(QA-3 질문 4-①)
  3. 떨린 내 달 — 보름 무렵 깸에 그은 원(떨리거나 끊겨도 됨)이 꿈 카드·띠 보름 칸의 달이 될 때 '내 달'로 좋나요, '못 그렸다'인가요? 볼 것: '못 그렸다·다시 그릴래' 류 말(아래 단추), 다시 긋기 수. 기준 안: '못 그렸다' 5명 중 0명. 안전: 몽망이는 칭찬·평가 몸짓 0, 매끈한 원과 떨린 원에 같은 반응. 렌더는 획이 둘러싼 모양을 채우고 바깥 번짐으로 떨림을 결로 보이게

시제품 전용: 반구·태어난 날·달 한 획 자리·하늘 결 남김·빨리 감기·하루 거르기·며칠 건너뛰기 단추는 실제 앱에 없어요. 다른 꿈 카드·밥·한 마디는 생략했어요. 그린 것은 저장되지 않고 어디에도 보내지 않아요. 페이지를 닫으면 사라져요.
