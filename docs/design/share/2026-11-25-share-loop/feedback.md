# 블라인드 피드백 — 공유 시안 v1 (2026-11-25)

- 방식: 시안을 만들지 않은 서브에이전트 2명이 **이미지 7장만** 보고(문서·코드 열람 금지) 타깃 유저 역할로 답했다. 앱 설명은 3줄만 줬다.
- 역할: **A** = 24세 SNS 헤비 유저(스토리 하루 3~5번, 틱톡 매일) / **B** = 34세 감성 앱 유저(Finch·일기·수면 앱, 카톡 프로필·단톡 공유, 사적 노출 꺼림)

## 4. 반영안 (시안 v1.1에 이미 반영한 것 ✔ / 설계에만 반영한 것 ◇)

1. ✔ **가리기 = 물안개.** 먹 얼룩 대신 그 자리가 한지 빛 물안개로 흐려진다(`preview-hidden-360.png`). 안전 원칙은 그대로다 — 사용자가 가린 칸, 금칙어에 걸린 칸, 그림이 없는 날의 칸이 **모두 같은 물안개 자산**이다.
2. ✔ **보낼 곳을 누르면 바로 보낸다.** '이대로 보내기'를 없애고, 각 앱의 알아보기 쉬운 아이콘 + "누르면 바로 보내져요". 미리보기는 그대로 필수다(보낼 곳이 미리보기 화면 안에 있으므로 건너뛸 수 없다).
3. ✔ **두 번째부터 접힌 설정.** "지난번 설정 그대로(쓴 말·이름·링크 꺼짐) 펼치기 ▾" 한 줄.
4. ✔ **랜딩 칩 = 실제 수묵 조각이 있는 낱말만**(비·바람·편지·이불·차·빨래), 바뀔 때 몽망이가 뒤척인다. 버튼은 둘(받기 / 앱에서 열기), '꿈 조각'은 버튼이 아니라 한 줄 설명으로. '송연먹' 대신 'N번째 밤의 꿈'.
5. ✔ 카드: 결 이름 제거, '▶ 8초' 배지 제거, 이레 획 자리 이동.
6. ◇ **이레 폭·두루마리는 칸·나열을 버리고 한 장의 물길 풍경으로.** 회의 실험 2(관계 규칙 + 물길 장 + 앵커)의 결과물을 그대로 쓴다. 28밤 동안 같은 사물은 두루마리에 한 번만 크게 두고, 되풀이된 날은 그 사물 둘레의 물결 고리를 하나씩 늘린다(되풀이 = 깊어짐). 시안은 실험 2 뒤에 다시 만든다.
7. ◇ **카드 문구 기본값을 바꾼다.** 기본 = "열두 번째 밤, 몽망이의 꿈"(질문을 부르지 않음). 미리보기에서 고를 수 있는 둘째 문구 = "무슨 말이었게?"(묻고 싶은 사람용, A의 요구). 웹 `/m` 첫 줄은 지금처럼 '누군가 건넨 말 한 마디가'를 유지한다(본 사람 쪽에서는 궁금증이 갈고리).
8. ◇ 아침 카드 하단: 몽망이를 1.5배로, 꿈 방울이 몸에서 그림까지 이어지게(DS-2, 모션은 4초 판과 같이).
