## 경미

- **L1 날짜**: `site.mjs:51`·FAQ `:64` "2027년 초 예정/목표". marketing-plan 기준은 "겨울에 만나요" 수준이고 D-22는 관문 통과 즉시·2주 단위로 미룸이라 '초'를 넘길 수 있다. geo-v1이 자체 허용했지만 PM 확인 권장.
- **L2 화면 컨셉**: 아침 카드 이미지 글 "첫 획은 여전히 몽망이의 몸에 있어요"와 하단 "App Store · Google Play"는 빌드 1(v2) 화면이다. 실제 렌더는 맞지만 아직 스토어에 없는데 스토어 이름이 보인다. v3 캡처로 교체 시 함께 처리(geo-v1 4절이 이미 인지).
- **L3 alt**: 영어 카드 alt(`site.mjs:34`)는 그림 속 글을 옮기지 않았다(한국어는 옮김). 두 찻잔에 몽망이가 둘(큰·작은) 있는데 영어 alt는 "rests in one of two teacups"라 그림과 다르다.
- **L4 markdown 방어**: `markdown.mjs`는 먼저 이스케이프하고 `https:`만 링크로 만들어 raw HTML·`javascript:`·속성 탈출은 막힌다(직접 확인). 다만 이를 고정하는 시험이 없다(변이 M3이 45개 모두 통과). 또 build.mjs 외부 주소 검사는 `https?://`·`//`만 보므로 `javascript:`·`data:` href는 검사도 통과한다. 주입 시험 2~3개 추가 권장.
- **L5 헤더**: 새 페이지는 CSP를 meta로만 둔다 — meta로는 `frame-ancestors`가 안 되고 X-Frame-Options도 없다(폼 없는 정적 페이지라 위험 낮음). `/img/**` 86400은 파일명에 해시가 없어 캡처 교체 뒤 하루 동안 옛 그림이 보인다.
- **L6 GEO 형식**: llms.txt의 '## Facts' 섹션은 링크 없는 항목이라 llmstxt.org의 'H2 = 링크 목록' 형식에서 벗어난다(해롭지 않음). JSON-LD `#app` @id가 ko·en 페이지에서 같고 description만 언어별로 달라 같은 노드에 두 설명이 생긴다 — 언어별 @id 또는 description 언어 표기 권장.
- **L7 문서 정합**: geo-v1 5절 G3이 아직 [오너 결정]으로 남았으나 DECISIONS 'PM 11-25'에 G3 채택이 있다. 처리방침 페이지(/privacy) 캡처가 없다(320·200%에서 표 가로 스크롤 확인 필요).
