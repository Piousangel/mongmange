## 1부. 앱·서버 한 쪽 요약

### 1-1. 무엇을 만드나
- **「몽망이 키우기」**(영문명 미정): 한지 위 먹 한 방울 캐릭터에게 하루 한 획씩 그어 주며 키우는 iOS·Android 게임. 한국어·영어 동시 출시.
- 운영자: 1인 개발. 개인사업자 [상호 — 오너 확인 후 기입](업종 정정 신고 중), 관할 구청 **게임제작업 등록**은 [진행 상태 — 오너 기입]. 스토어 판매자명은 운영자 실명(개인 계정).
- 수익: **1.0에는 결제·광고가 없습니다.** 확률형 뽑기는 앞으로도 넣지 않기로 정했습니다. (1.0 이후 일회성 유료 해금·소품 판매를 검토 중이며, 넣게 되면 다시 문의드립니다.)
- 광고·분석·크래시 리포트 SDK 없음. 다른 회사 데이터와 연결하는 추적 없음.

### 1-2. 서버를 쓰는 방식 — "앱이 정본, 서버는 선택 기능"
게임은 **서버 없이 기기 안에서 완전히 동작**합니다. 서버는 아래 경우에만 개입합니다.

| 누구 | 서버로 가는 것 | 식별 가능성 | 저장 위치 |
|---|---|---|---|
| 모든 이용자 | ① **이용 통계 집계 신호**: 설치일(날짜)·설치 후 며칠째·플랫폼·앱 버전·언어·실험 군(A/B)·위젯 사용 여부·보름 여부, 정해진 게임 사건 10종의 발생 여부. 계정·기기 식별자 없음. 앱 설정에서 끌 수 있음 | 식별자 없음. 단 요청 IP가 서버 요청 로그에 7일 | 서울(Google Cloud Run, 로그 서울 7일) |
| 모든 이용자(둘째 실행부터) | ② **앱 업데이트 확인**(Expo의 EAS Update): 플랫폼·버전, **기기별 무작위 설치 id가 실릴 수 있음**(확인 중), IP | 설치 id가 영속이면 기기 단위 식별 가능 | 미국(Expo) |
| 모든 이용자 | ③ 설정·콘텐츠 파일(기능 켜고 끄기 파일, 꿈 그림 파일) 내려받기 | IP만 | Google Firebase Hosting(전 세계 CDN) |
| **공유 링크를 켠 사람**(선택) | 익명 계정 id, 연령 확인 통과 기록(날짜), 인증 서비스의 로그인 세션 기록(IP·브라우저 정보일 수 있음, 확인 중), **공개 페이지 사본**(그림을 줄인 선, 캐릭터 특징 요약, 날짜, 이름은 이용자가 공개를 켰을 때만), 이미지·8초 영상 | 계정 id로 연결 | 서울(Supabase, 미국 법인) |
| **클라우드 보관('맡겨 두기')을 켠 사람**(선택) | 위 + 앱이 만든 무작위 **기기 값**·저장 시각 + **세이브 전체**: 그은 획의 좌표·시간·필압, 잠 시각 설정, **이용 시간대 패턴(24시간 칸별 방문 습관), 부재 길이, 마지막 방문 시각, 설치 시각, 시간대**, 캐릭터 이름 | 계정 id로 연결 | 서울(Supabase) |
| 링크를 받은 사람(웹) | 페이지 로드 수(쿠키·식별자 없음). **신고를 누르면** 중복 신고를 가리려고 IP에서 만든 가명 값을 신고 대상별 최대 7일 | 7일 동안은 가명 | 서울 |

- 계정은 **이용자가 링크 켜기·맡겨 두기를 처음 누를 때만** 생깁니다(1.0 직후 '밤물' 기능을 열 때도). 로그인 화면·이메일·전화번호·실명은 받지 않습니다. 기기 이동은 16자 **'되찾기 글귀'**(서버는 해시만 보관)로 합니다.
- 계정이 생기기 직전에 **중립형 연령 확인**(태어난 해·달을 고름, 기준 나이를 화면에 보이지 않음)을 합니다. 판정은 기기에서 하고 해·달은 저장하지 않습니다. 만 14세 미만이면 계정을 만들지 않고 기기에만 '미달' 기록을 남깁니다.
- 삭제: 앱 안 '서버에 맡긴 것 지우기'(즉시), 웹 삭제 페이지(공유 링크 코드 + 되찾기 글귀가 둘 다 맞을 때만), 이메일.

### 1-3. 보관 기간(설계값)
세이브 현재본 = 계정 존속 중 / 세이브 이력 = 최대 4주(충돌·복원 전 본 30일) / 백업 속 사본 = 7일 뒤 소멸 / 서버 요청 로그(IP 포함) = 7일 / 신고 가명 값 = 신고 대상별 최대 7일, 신고 기록 = 1년 / 공유 링크 조회 수 = 30일 뒤 링크 코드 없이 합계만 / 이용 통계 = 90일 뒤 월 합계 / 앱을 **2년** 동안 열지 않으면 서버에 맡긴 것 정리.

- 12-10 스토어 제출용 빌드 → **12-22 전후 소프트런칭: Google Play 캐나다·뉴질랜드·필리핀**, 같은 날 iOS TestFlight 외부 테스트(초대 테스터) → **2027년 2월 초 정식 출시**(한국 포함, 국가 범위는 [오너 결정]).

- **우리 안**: 업종 정정이 끝나는 대로 관할 구청에 게임제작업을 등록하고, 등록 전에 무료로 소프트런칭(해외 3개국)을 시작합니다.
- **확인받고 싶은 점**
