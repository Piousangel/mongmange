- 작성: 출시·정책 담당 / 2026-11-19 / 초안 v0.1
- 근거: DECISIONS D-06 R5(영문명 후보 3개와 판정 규칙), D-10 확정 조건 ③④(애착 5점 평균 3.5 이상·비교군 포함, 실루엣 자유응답), D-12(몽망이로 보이는가 + 내가 그었다고 느끼는가), 아트 바이블 14절 1·15절 1·2(빈자리 눈 vs 먹점 눈 A/B)
- 한 회차로 묶는다(D-06: "D-10 확정 조건과 같은 회차"). 응답자는 `tester-recruit.md`로 모은 사람 + 영어 원어민(1부 필수).

## 0. 만들 때 규칙

1. **유도하지 않는다.** 자유응답이 먼저, 선택형은 나중이다. 앞 페이지에서 '먹', '펫', '귀엽다', '이름' 같은 답의 힌트를 주지 않는다. 한 페이지(Forms '섹션')에 질문 하나 또는 자극물 하나만 둔다. 뒤로 가기로 답을 고치지 말아 달라고 첫 화면에 적는다.
2. **순서 효과를 없앤다.** Forms는 섹션 순서를 섞지 못하므로 폼을 **A·B·C 세 판**으로 복사해 후보 순서를 돌린다(아래 표). 테스터에게 판을 번갈아 나눠 준다.

   | 판 | 1부 이름 순서 | 2-3 눈 A/B 순서 |
   |---|---|---|
   | A | ① → ② → ③ | 빈자리 → 먹점 |
   | B | ② → ③ → ① | 먹점 → 빈자리 |
   | C | ③ → ① → ② | 빈자리 → 먹점 |

3. 설정: 이메일 수집 **끔**, 로그인 필수 **끔**(파일 업로드 문항을 넣으면 로그인이 강제되니 넣지 않는다), 응답 1회 제한 끔(로그인이 필요해짐), 진행률 표시 켬. 객관식은 '옵션 순서 섞기' 켬(척도 문항은 제외).
4. 자극물(이미지·영상)은 **실제 렌더**만 쓴다(D-04, 스파이크 02 결과). 영상은 YouTube 일부공개로 올려 Forms '동영상 추가'로 넣는다. 아래 `[IMG-…]`·`[VID-…]`가 자리 표시다.
5. 응답 시간 약 8~10분.

## 시작 화면

**제목:** 짧은 그림·이름 설문 / A short survey about a name and a drawing

**설명(한):**
> 만 14세 이상만 참여할 수 있습니다.
> 약 10분 걸립니다. 정답은 없습니다. 처음 떠오르는 대로 적어 주세요.
> 앞 페이지로 돌아가서 답을 고치지 말아 주세요.
> 이름·이메일 같은 개인정보는 묻지 않습니다. 응답은 게임 개발 판단에만 쓰고, 테스트가 끝나면 원본을 지웁니다.

**Description (EN):**
> You must be 14 or older to take part.
> About 10 minutes. There are no right answers — write whatever comes to mind first.
> Please don't go back to change earlier answers.
> We don't ask for your name or email. Answers are used only to make design decisions for a game, and raw responses are deleted after the test.

### Q0-1. 나이대 / Age group — 객관식, 필수
- 14~17 / 18~29 / 30~39 / 40~49 / 50 이상 (만 14세 미만은 선택지에 두지 않는다. 테스터·설문은 **만 14세 이상만** — 만 14세 미만 개인정보는 법정대리인 동의 필요(03 문서 4-1, 제22조의2), 11-20 팀 결정. 스토어 타깃도 11-20부터 만 14세 이상(D-06 개정·D-23))

### Q0-2. 가장 편한 언어 / Your first language — 객관식, 필수
- 한국어 / English / 기타(직접 입력)

### Q0-3. 영어 원어민입니까, 또는 영어를 매일 쓰는 나라에 살고 있습니까? / Is English your native language, or do you live where English is used daily? — 객관식, 필수
- 예 / Yes → **1부로**
- 아니요 / No → **2부로** (Forms '답변을 기준으로 섹션으로 이동')

## 1부. 이름 (영어 원어민 대상, 영어로만 표시)

> 섹션 설명: "On each page you'll see one made-up word. There's no context on purpose."
> 아래 세 블록을 판(A·B·C) 순서대로 배치한다. **각 블록은 섹션 하나**(이름 하나만 크게 표시).

### 블록 ① — 화면에 크게: **Mongmangi**
- **Q1-①a.** How would you say this word out loud? Type it the way it sounds (e.g. split into syllables). — 단답형, 필수
- **Q1-①b.** What is the first single word that comes to mind when you see it? — 단답형, 필수
- **Q1-①c.** Does it remind you of anything else — a word, a brand, a feeling? (optional) — 장문형, 선택

### 블록 ② — 화면에 크게: **Mong-mangE**
- **Q1-②a / ②b / ②c** — 위와 같은 세 문항

### 블록 ③ — 화면에 크게: **mongmangE**
- **Q1-③a / ③b / ③c** — 위와 같은 세 문항

### 1부 마지막 섹션 (세 이름을 함께 표시: Mongmangi / Mong-mangE / mongmangE)
- **Q1-4.** Which one is easiest to say? — 객관식(옵션 섞기), 필수
- **Q1-5.** Which one would you remember tomorrow? — 객관식(옵션 섞기), 필수
- **Q1-6.** This is the name of a small creature you raise in a mobile game. Which name fits it best? — 객관식(옵션 섞기) + "None of them", 필수
- **Q1-7.** Did any of these names make you think of something unpleasant? If so, which one and what? — 장문형, 선택
  - Q1-6에는 생김새·재료 힌트('ink', 'drop' 등)를 넣지 않는다. 원어민은 1부 뒤에 2부 실루엣 자유응답으로 가기 때문이다(0절 규칙 1, D-10 ④).
  - Q1-7은 유도가 있으므로 **판정에는 쓰지 않고** 참고만 한다. 판정은 Q1-①b~③b(첫 단어)로만 한다.

## 3. 집계·판정 (응답 후 팀 내부)

자유응답은 **두 사람이 따로 분류**하고(작성자 ≠ 검토자, 팀 리뷰 원칙), 엇갈린 응답은 셋째 사람이 정한다. 분류 전에 판정 기준을 바꾸지 않는다.

| 테스트 | 쓰는 문항 | 판정 | 근거 |
|---|---|---|---|
| 영문명 | Q1-①b·②b·③b(첫 단어) | 피부병·mange·옴·가려움·병든 동물 연상이 **원어민 10명 중 1명 이상이면 그 후보 탈락**. 남은 후보 중 Q1-①a~③a 발음이 의도("몽-망-이")와 맞는 비율이 높은 것, 동률이면 Q1-5 | D-06 |
| 실루엣 | Q2-1a·1b·2a | 검댕·올챙이·해마·유령·똥(💩)·벌레·폭발로 읽힌 비율을 기록 | D-10 ④, 아트 1-4·15절 1 |
| 획 보정 | Q2-4a | 실루엣 이상 응답 **10% 미만**인 단계 중에서 플레이테스트의 '내가 그었다' 최고 단계 | D-12 |
| 애착 | Q2-2b vs 비교군 | 몽망이 평균 **3.5 이상**, 비교군과 함께 보고 | D-10 ③ |
| 눈 A/B | Q2-3a·3b·3c | 빈자리 눈이 먹점 눈보다 크게 낮으면 비상구(먹점) 검토 — 기준 수치는 리서처가 응답 전에 정해 이 칸에 적는다 [리서처 기입] | 아트 14절 1 |

- 표본: D-06 판정은 원어민 10명 기준이다. 원어민이 10명에 못 미치면 판정을 미루고 원어민을 더 모은다(지인의 해외 지인, 영어권 커뮤니티 등 — 오너 결정).
- 실루엣 분류 범주(미리 정함): 먹·잉크 방울 / 펫·생물(긍정) / 검댕·블랙 슬라임 / 올챙이·해마·새 / 유령 / 똥·이모지 / 돌·조약돌 / 기타.
