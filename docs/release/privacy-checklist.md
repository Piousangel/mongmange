- **11-20 독립 리뷰(`docs/team/reviews/2026-11-20-legal-docs-review.md`, '수정 후 게시 가능') 반영**: `saves.device_id`를 방침 3-5·Data safety·App Privacy(Device ID, Linked)에 일치 / 'IP는 DB에 없다' 단정을 접고 Supabase Auth 세션·감사 기록을 [확인 필요]·질문 B-8로 / 수탁사에 메일 서비스·(도입 시) Cloudflare 자리, 질문 B-2 / 이메일로 글귀 받기 철회(질문 B-14) / Data safety 빌드 2부터 전부 선언 / 1절 '알아볼 수 없는' → '식별자를 붙이지 않는'(질문 B-1과 연결) / 보관표에 옛 사용자 30일·미커밋 업로드 6시간·문의 메일 / en 해외 이용자 권리·기관 안내 / 질문지 용어 설명·필수 질문 요약·B-15(보호책임자)·B-16(9절 예외) / 질문지 상호는 자리 표시.
- **Cloudflare 조건**: 지금은 DNS만(프록시 끔)이라 수탁·국외 이전에 적지 않는다. `/m/**` 앞단 Worker 전환(아키텍처 3-8) 또는 wasm·루프 R2 이전(아키텍처 8절, 01월) **전에** 방침 7·8절·3-6과 store-listing 7-1 공유 메모를 고친다. 방침의 `[도입 시 추가: Cloudflare …]` 대괄호는 그때 채우거나, 도입하지 않기로 하면 지운다.
- **EAS 설치 id 묶음 갱신**: 확인 결과(서버 12절 #5, 11-23)가 나오면 방침 ko·en 3-2·8절, 질문 C-1, store-listing 7-1·7-2를 같은 커밋에 같은 문장으로 고친다.
- 게시 전 실제 동작과 대조할 것(테크): 이용 통계 끄기 설정이 핑·이벤트를 모두 막는지, OTA 첫 실행 미확인, 세션 MMKV 백업 제외, `/m/` 요청 로그 제외 필터, 로그 버킷 서울·7일, 서버가 세이브에서 꺼내는 값(day_index·strokes_total·버전뿐), `saves.device_id`가 앱이 만든 무작위 값인지, **Supabase Auth가 `auth.sessions`·`auth.audit_log_entries`에 IP·User-Agent를 남기는지·끄는 법·보존 기간**, 관리 계정 2단계 인증.
