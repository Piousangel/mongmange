[운영자 실명 — 오너 기입](이하 '운영자')은 모바일 게임 「몽망이 키우기」(영문 [영문 앱 이름 — 이름 테스트 후 확정], 이하 '앱')와 공유 링크 웹 페이지(`mongmang.ink`, 이하 '웹 페이지')를 이용하는 분의 개인정보를 소중히 다루며, 「개인정보 보호법」 제30조에 따라 이 방침을 공개합니다.

## 1. 한눈에 보기

- **게임은 서버 없이 기기 안에서 완전히 동작합니다.** 게임 기록의 원본은 이용자의 기기에 있습니다.
- 로그인 화면이 없고, 이름·이메일·전화번호·광고 ID·위치·연락처·사진을 받지 않습니다. 광고·추적·결제가 없습니다.
- 서버로 가는 정보는 다음뿐입니다.
  1. **모든 이용자**: 계정·기기 식별자를 붙이지 않는 이용 통계(설정에서 끌 수 있음), 앱 업데이트 확인, 설정·콘텐츠 파일 요청 → 3-1~3-3
  2. **'링크로 공유'를 켠 분**: 공개 페이지에 올릴 몽망이 사본 → 3-4·5절
  3. **'맡겨 두기'(클라우드 보관)를 켠 분**: 게임 기록 전체 → 3-5
- 2와 3을 처음 켜는 순간에만 익명 계정이 생기며, 그 직전에 만 14세 이상인지 확인합니다(4절).
- 서버에 맡긴 것은 앱 안에서 언제든 지울 수 있습니다(12절).

## 2. 기기 안에만 저장되는 정보

아래 정보는 이용자의 기기에 저장됩니다. '맡겨 두기'를 켜지 않는 한 운영자에게 전송되지 않습니다.

| 기기에 저장되는 정보 | 용도 |
|---|---|
| 화면에 그은 획의 좌표·시간·필압 | 몽망이의 몸과 성장을 그리기 위해 |
| 잠 시각·아침 시각 설정, 잠든 시각·깬 시각, 기기 시간대 | 하루(잠 한 번)를 계산하기 위해 |
| 게임 진행 값(성향, 획 수, 아침 카드 기록, 몽망이 이름·고른 먹, 함께한 날 수, 자주 쓰다듬은 자리) | 이어서 플레이하기 위해 |
| **이용 시간대 습관**(하루 24시간 중 언제 앱을 여는지), **자리 비운 길이**(최근·가장 긴), 마지막 방문 시각, 설치 시각 | 몽망이가 이용자를 알아보는 연출을 위해 |
| 앱 설정(알림, 소리, 모션 줄이기, 이용 통계 보내기 등) | 이용자가 고른 설정을 유지하기 위해 |
| 연령 확인 결과(만 14세 미만이면 '미달'과 날짜만) | 같은 날 다시 묻지 않기 위해 |

- 기기 기울기 값은 몽망이의 시선 연출에만 그 순간 쓰이고 저장되지 않습니다.
- 홈 화면 위젯은 기기 안의 그림만 쓰며 서버로 아무것도 보내지 않습니다.

## 3. 서버로 보내는 정보

### 3-1. 이용 통계 (모든 이용자, 끌 수 있음)
- **항목**: 설치한 날짜, 설치 후 며칠째인지, 플랫폼(iOS·Android), 앱 버전, 언어, 화면 실험 군(A 또는 B), 7일째 홈 화면 위젯 사용 여부, 그날이 보름 무렵인지, 정해진 게임 사건(첫 터치, 첫 밤, 이름 짓기 등 10가지)이 있었는지.
- **식별자 없음**: 계정·기기 식별자를 붙이지 않고, 서버는 같은 조건의 개수만 더합니다. 통계 값에는 누가 보냈는지 나타내는 값이 없습니다. 다만 통신에 쓰인 IP 주소는 아래와 같이 요청 로그에 잠시 남습니다. [법률 검토: 이 통계가 개인정보에 해당하는지]
- **목적**: 게임을 계속 즐기는 비율을 재고 화면을 개선하기 위해.
- **끄기**: 공방 노트 - 설정에서 '이용 통계 보내기'를 끄면 이 정보를 보내지 않습니다.
- 통신 과정에서 IP 주소가 서버에 닿으며, 서버 요청 로그에 **7일** 남은 뒤 지워집니다(6절). 이 통계와 함께 IP를 데이터베이스에 저장하지 않습니다.

### 3-2. 앱 업데이트 확인 (모든 이용자)
- 앱은 오류 수정을 빠르게 반영하려고 **두 번째 실행부터 하루 한 번** 업데이트 배포 서비스(Expo의 EAS Update, 미국)에 새 버전이 있는지 묻습니다. 첫 실행에는 묻지 않습니다.
- **항목**: 플랫폼, 앱 버전 정보, IP 주소. 업데이트 서비스가 기기마다 만드는 무작위 설치 식별자가 함께 실릴 수 있습니다 [확인 필요: 전송 여부·보존 기간 — 확인 결과로 이 줄과 8절을 함께 고침].
- 운영자는 이 요청 내용을 받거나 보지 않습니다. 처리위탁·국외 이전은 7·8절에 적었습니다.

### 3-3. 설정·콘텐츠 파일 내려받기 (모든 이용자)
- 기능 켜고 끄기 파일과 새 꿈 그림 파일을 웹 서버(Google Firebase Hosting)에서 내려받습니다. 이때 IP 주소가 요청 처리에 쓰입니다. 운영자는 이 요청을 기록하지 않습니다.

### 3-4. '링크로 공유'를 켠 분
- **항목**:
  - 익명 계정 식별자(무작위 값), 연령 확인 통과 기록(확인 절차의 판 번호와 날짜. 태어난 해·달은 보내지 않음), 마지막 이용 월
  - 로그인 세션 기록: 익명 계정 인증 서비스(Supabase)가 세션을 관리하면서 접속 IP 주소·브라우저 정보(User-Agent)·시각을 남길 수 있습니다 [확인 필요: 기록 여부·끄는 방법·보존 기간 — 확인 결과로 이 줄과 6·8절을 고침]
  - 공개 페이지 사본: 그은 획을 단순화한 선, 몽망이의 타고난 모양 요약·먹·결 이름, 태어난 날짜, 링크를 켠 날의 함께한 날 수, 언어, 이름(**이름 공개를 켰을 때만**)
  - 앱이 만든 공개 이미지·8초 영상(이름은 이름 공개를 켰을 때만 이미지에 들어감)
- **목적**: 공유 링크 웹 페이지 제공. 공개 범위는 5절.
- **보내지 않는 것**: 획의 시간·필압, 이용 시간대 습관, 자리 비운 길이, 방문 시각, 기기 모델·운영체제 같은 기기 정보, 위치.

### 3-5. '맡겨 두기'(클라우드 보관)를 켠 분
- **항목**: 3-4의 계정 항목 + **게임 기록 전체**. 게임 기록에는 다음이 들어 있습니다.
  - 그은 획의 좌표·시간·필압
  - 잠 시각·아침 시각 설정, 잠든 시각·깬 시각, 기기 시간대
  - 게임 진행 값과 몽망이 이름
  - **이용 시간대 습관**(하루 24시간 중 언제 앱을 여는지), **자리 비운 길이**(최근·가장 긴), **마지막 방문 시각**, **설치 시각**
- 게임 기록을 올릴 때 함께 보내는 값: **앱이 기기마다 만드는 무작위 기기 값**(어느 기기에서 올린 기록인지 구분하기 위해), 기기에서 저장한 시각, 기록의 검증값(해시).
- 기기를 옮길 때 쓰는 '되찾기 글귀'는 서버에 **변환한 값(해시)만** 저장합니다.
- 위 값을 함께 보면 이용자가 **언제 앱을 열고 얼마나 비우는지 같은 생활 리듬**을 짐작할 수 있습니다. 운영자는 이 값을 게임 기록 안에 묶어 보관할 뿐, 따로 꺼내 저장·검색·열람하는 기능을 두지 않으며 공개 페이지에 넣지 않습니다.
- **목적**: 기기를 바꾸거나 앱을 지워도 몽망이를 잃지 않도록 보관·복원하기 위해.

### 3-6. 공유 링크 웹 페이지 방문자
- 페이지가 열릴 때 **페이지 로드 수**를 한 번 셉니다. 쿠키나 식별자를 쓰지 않고, 이 신호로 IP를 저장하지 않습니다.
- 운영자는 웹 페이지 요청 기록을 IP와 링크 주소가 함께 남지 않도록 수집하지 않습니다. 과도한 요청을 막으려고 IP 주소를 서버 메모리에서 잠시 쓰지만 저장하지 않습니다. 웹 페이지를 전송하는 사업자(Google Firebase Hosting)의 처리는 8절에 적었습니다.
- **신고**를 누르면, 같은 사람의 중복 신고를 가려내려고 IP 주소에서 만든 **가명 값**을 **신고 대상별로 최대 7일** 보관한 뒤 파기합니다. 신고자를 식별하는 정보는 저장하지 않습니다.

### 3-7. 의견 보내기
- 공방 노트의 '의견 보내기'는 앱 밖의 웹 설문 페이지를 열 뿐이며, 앱은 게임 기록이나 기기 정보를 함께 보내지 않습니다. 설문에 직접 적은 내용은 그 설문 서비스의 방침에 따라 처리되고, 운영자는 게임 개선에만 씁니다. [설문 도구 확정 후 이름·방침 링크 기입]

## 4. 연령 확인과 만 14세 미만 아동

- 앱은 **만 14세 이상**을 대상으로 합니다. 아동을 주된 대상으로 하지 않으며, 아동 대상 카테고리에 참여하지 않습니다.
- 계정이 생기는 기능('링크로 공유', '맡겨 두기', 이후 추가되는 '밤물')을 처음 켤 때, 그 직전에 **태어난 해와 달**을 한 번 묻습니다. 판정은 기기에서 하고, **태어난 해·달은 기기와 서버 어디에도 저장하지 않습니다.**
- 만 14세 미만이면 계정을 만들지 않고 해당 기능을 켜지 않습니다. 기기에는 '미달'과 날짜만 남겨 같은 날 다시 묻지 않습니다. 기기 안 게임과 카드 저장·공유는 그대로 쓸 수 있습니다.
- 운영자는 법정대리인 동의 절차를 제공하지 않으며, 만 14세 미만 아동의 계정을 만들지 않습니다. 3-1~3-3의 정보는 연령 확인 없이 모든 이용자에게서 전송됩니다. [법률 검토 결과에 따라 이 문단을 고침]
- 만 14세 미만 아동의 정보가 서버에 처리된 사실을 알게 되면 지체 없이 지웁니다. 보호자는 17절의 연락처로 알려 주세요.

## 5. 공유 링크 웹 페이지의 공개 범위

- '링크로 공유'는 **기본으로 꺼져 있고**, 이용자가 켤 때만 `https://mongmang.ink/m/(8자 코드)` 페이지가 공개됩니다. 링크를 아는 누구나 볼 수 있습니다.
- 공개 내용은 3-4의 공개 페이지 사본뿐이며, **링크를 켤 때(또는 '다시 만들기'를 누를 때)의 값으로 고정**됩니다. 매일 바뀌지 않으므로 링크를 아는 사람이 이용자의 접속 리듬을 알 수 없습니다.
- **이름 공개는 기본으로 꺼져 있습니다.** 켜도 금칙어에 걸리면 이름 대신 '몽망이'로 보입니다. 몽망이 이름에 실명이나 연락처를 쓰지 마세요.
- 검색 엔진에 색인되지 않게 설정하며, 공개 페이지 목록을 제공하지 않습니다.
- **끄기**: 앱에서 링크를 끄면 앱·서버에서는 즉시, 웹 페이지는 캐시 때문에 **최대 1시간 안에** 보이지 않게 되고 공개 파일은 지워집니다. 이미 다른 사람이 내려받은 화면이나 메신저에 이미 붙은 미리보기 카드는 운영자가 지울 수 없습니다.
- 서로 다른 3명이 신고하면 페이지가 자동으로 가려지고, 운영자가 7일 안에 확인해 복원하거나 삭제합니다.

## 6. 보유 기간과 파기

| 항목 | 보유 기간 |
|---|---|
| 게임 기록 현재본(맡겨 두기) | 계정을 지울 때까지 |
| 게임 기록 이전 본(되돌리기용) | 최근 3벌 + 주 1벌 **최대 4주**, 충돌·복원 전 본 30일 |
| 공개 페이지 사본·이미지·영상 | 링크가 켜져 있는 동안(끄면 즉시 삭제, 웹 캐시 최대 1시간) |
| 신고로 가려진 공개 페이지 | 최대 30일(운영자 확인 결과에 따라 복원 또는 삭제) |
| 되찾기 글귀 | 해시 값만, 계정을 지울 때까지(되찾으면 새 글귀로 바뀜) |
| 되찾기로 다른 기기에 옮긴 뒤의 옛 계정 | **30일**(그동안 옛 기기의 서버 이용은 막힘) 뒤 삭제 |
| 올리다 끝나지 않은 공개 이미지·영상 | 6시간 뒤 삭제 |
| 로그인 세션 기록(3-4) | [확인 필요: 인증 서비스 기록 여부·보존 기간] |
| 연령 확인 통과 기록 | 계정을 지울 때까지 |
| 링크 페이지 로드 수 | 30일 뒤 링크 코드 없는 합계로 바꿈 |
| 이용 통계(식별자 없음) | 90일 뒤 월 합계로 바꿈 |
| 서버 요청 로그(IP 포함) | 7일 |
| 신고 기록 | 1년(같은 페이지의 재발 판단). 신고자 가명 값은 신고 대상별 최대 7일 |
| 데이터베이스 백업 속 사본 | 7일 뒤 자동 소멸 |
| 문의·요청 이메일 | 처리를 마친 뒤 [기간 — 오너 결정] 안에 삭제 |

## 10. 기기 백업과 내보내기

- 기기의 백업 기능(iOS iCloud 백업, Android 자동 백업)이 켜져 있으면, 게임 기록이 **이용자 본인의 Apple·Google 계정 백업**에 포함될 수 있습니다. 이 백업은 Apple·Google의 정책에 따라 처리되며 운영자는 접근할 수 없습니다. 서버 접속 정보(로그인 세션)는 백업에서 뺍니다. [구현 확인 필요: 백업 포함·제외 검증 결과]
- '세이브 내보내기'로 만든 코드는 이용자가 직접 복사·보관하는 것이며, 운영자에게 전송되지 않습니다.

## 11. 알림, 카드 저장·공유

- 앱은 **기기 안에서 예약하는 로컬 알림**만 씁니다. 푸시 토큰을 수집하지 않습니다. 알림은 처음 요청할 때 허용 여부를 고르며, 기기 설정에서 언제든 끌 수 있습니다.
- 아침 인화 카드의 이미지 저장·공유는 이용자가 직접 누를 때만 일어나며, 기기의 기본 공유 화면을 통해 이용자가 고른 앱으로 전달됩니다. 운영자는 그 내용을 받지 않습니다. 사진 앱에 저장할 때 저장 전용 권한을 물을 수 있고, 기존 사진은 읽지 않습니다. [구현 확인 필요: 저장 방식과 권한 범위]

## 13. 자동 수집 장치와 추적

- 앱과 웹 페이지는 쿠키나 이와 비슷한 추적 기술을 쓰지 않습니다. 웹 페이지의 페이지 로드 신호(3-6)는 쿠키·식별자 없이 개수만 셉니다.
- 다른 회사의 앱·웹사이트 데이터와 연결해 이용자를 추적하지 않으며, 맞춤형 광고를 하지 않습니다.

## 14. 안전성 확보 조치

- 모든 서버 통신은 암호화(TLS)합니다. 게임 기록·로그인 정보가 오가는 앱 서버는 서울 리전에 직접 연결되며, 해외 전송망 서버를 거치지 않습니다.
- 되찾기 글귀는 해시 값만 저장하고, 공유 링크 코드는 추측하기 어려운 무작위 값으로 발급합니다.
- 서버는 게임 기록 본문에서 날짜 수·획 수·버전 외의 값을 꺼내 저장하지 않으며, 게임 기록을 열람하는 관리 화면을 두지 않습니다.
- 공개 페이지에는 서버가 허용 목록으로 검사한 값만 올라갑니다.
- 로그에는 로그인 토큰, 되찾기 글귀, 게임 기록 본문을 남기지 않습니다.
- 서버·데이터베이스 관리 권한은 운영자 1인으로 한정합니다. [구현 확인 필요: 관리 계정 2단계 인증]
- 기기 안의 게임 기록은 앱 전용 저장 공간(운영체제가 다른 앱의 접근을 막는 영역)에 둡니다.

## 15. 서비스 종료

서버 운영을 끝내게 되면 **90일 전에 앱 안과 이 페이지에서 알리고**, 그동안 서버에 맡긴 것을 내려받을 수 있게 합니다. 서버가 없어도 앱의 기기 안 게임은 계속 동작합니다. 종료 뒤 서버의 정보는 모두 파기합니다.
