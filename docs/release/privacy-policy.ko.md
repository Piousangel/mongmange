- **설치가 적은 시기**: 이용자가 적은 시기에는 같은 조건의 이용자가 한 명뿐인 칸이 생길 수 있습니다. 그래서 운영자가 보는 표에서는 **개수가 5 미만인 칸**을 숨기고, 개수 원표는 내보내지 않으며, 비공개 테스트 기간에는 원표를 열람하지 않습니다. 다만 공유처럼 되풀이되는 사건은 한 사람이 여러 번 셀 수 있어, 개수가 5 이상인 칸에도 한 사람만 있을 수 있습니다.
- **목적과 처리 근거**: 게임을 계속 즐기는 비율을 재고 화면을 개선하기 위해서입니다. 이 통계에는 식별자가 없지만 통신에 IP 주소가 쓰이고 설치가 적은 시기에는 한 사람만 있는 칸이 생길 수 있어, 운영자는 이를 개인정보로 보고 이용자의 동의(직접 켬 — 「개인정보 보호법」 제15조 제1항 제1호)를 근거로 처리합니다. 켜지 않거나 꺼도 게임 이용에는 아무 불이익이 없습니다.
- **켜고 끄기**: 공방 노트의 '이용 통계 보내기'. 끄면 그때부터 보내지 않고, 기기에 모아 둔 통계와 다시 보내려고 기다리던 것, 보내는 도중이던 것까지 바로 지웁니다.
- **보내는 방식**: 연결이 끊겼을 때는 기기에 최대 7일치를 모았다가 다음에 함께 보내며, 7일이 지난 것은 보내지 않고 지웁니다(2절).
- **IP 주소**: 통신 과정에서 IP 주소가 서버에 닿습니다.
  - 과도한 요청을 막으려고 IP 주소(IPv6는 앞부분 64비트)를 서버 메모리에서 **약 1분 동안** 요청 횟수를 세는 데만 쓰고 저장하지 않습니다.
  - 클라우드 사업자(Google Cloud Run)는 요청마다 IP 주소·User-Agent(앱 이름과 판, 운영체제 종류가 드러날 수 있음)·요청 경로·시각 등을 담은 접속 기록을 만들지만, 운영자는 이 기록을 **받아 보관하지 않도록** 설정했습니다. 장애를 조사할 때만 잠시 받을 수 있으며, 그때 받은 기록은 **최대 7일** 뒤 지워집니다(6·8절).
  - 운영자 서버의 기록(앱 로그·오류 로그)은 7일 보관하며, 여기에는 IP 주소와 User-Agent를 적지 않습니다.
  - 이 통계와 함께 IP 주소를 데이터베이스에 저장하지 않습니다.
  - 통계를 보내는 요청의 User-Agent는 기기·운영체제·빌드 정보 없이 앱 이름(`Mongmangi`)으로 고정합니다.

### 3-2. 앱 업데이트 확인 (모든 이용자)
- 앱은 오류 수정을 빠르게 반영하려고 **두 번째 실행부터 기기 날짜로 하루 한 번** 운영자의 업데이트 서버(Google Cloud Run, 대한민국 서울 리전)에 새 버전이 있는지 묻습니다. 첫 실행에는 묻지 않습니다. Expo 같은 외부 업데이트 배포 서비스는 쓰지 않습니다. 요청은 Google의 웹 전송 서비스(Firebase Hosting, 전 세계 네트워크)를 지나 서울의 서버에 닿습니다(7·8절).
- **예외**: 앱이 시작하자마자 오류로 멈추면(첫 실행 포함) 업데이트 장치가 고친 버전이 있는지 한 번 찾아보고, 앱이 연달아 두 번 비정상적으로 끝나면 하루 한 번 제한을 건너뛰고 바로 묻습니다. 오류 수정을 빨리 받기 위해서이며, 요청에 실리는 값은 아래와 같습니다.
- **요청에 실리는 것**: 플랫폼, 앱 실행 환경 판(런타임 버전)·업데이트 채널, 지금 쓰고 있는 업데이트와 앱에 들어 있던 업데이트의 식별자(같은 버전을 쓰는 모든 이용자가 같은 값), IP 주소와 통신에 필요한 기본 정보(브라우저 정보에 해당하는 User-Agent 등).
- **보내지 않는 것**: 앱의 업데이트 장치(expo-updates)는 표준으로 설치마다 만든 무작위 식별자, 실패한 업데이트의 식별자, 앱을 멈춘 오류 내용을 싣도록 되어 있지만, 이 앱은 이 값들을 **모든 이용자에게 같은 고정값(또는 빈 값)으로 바꿔 보냅니다.** 그래서 업데이트 확인 요청으로 설치나 기기를 구별할 수 없고, 오류 내용도 운영자에게 오지 않습니다.
- **운영자가 하는 일**: 맞는 업데이트를 고르는 데 필요한 값(플랫폼·실행 환경 판·채널·지금 쓰는 업데이트의 식별자)만 그 순간 쓰고, 데이터베이스와 운영자의 서버 기록(앱 로그)에 남기지 않습니다.
- 업데이트 파일도 같은 길(Firebase Hosting을 지나 운영자 서버)로 내려받습니다. 받은 업데이트는 다음에 앱을 새로 시작할 때 적용되며, 앱을 쓰는 도중에 바뀌지 않습니다.
- 앱은 앱을 처음 실행한 시각과 마지막으로 업데이트 확인을 시도한 시각, 앱이 정상적으로 닫혔는지 표시와 연달아 비정상 종료된 횟수만 기기에 적어 두며, 식별자는 적지 않고 서버로 보내지도 않습니다.
- 과도한 요청을 막으려고 IP 주소(IPv6는 앞부분 64비트)를 서버 메모리에서 약 1분 동안 세는 데만 쓰고 저장하지 않습니다. 클라우드 사업자의 접속 기록은 3-1과 같이 운영자가 받지 않습니다(장애 조사 때만 최대 7일). 업데이트 요청이 지나는 Firebase Hosting의 요청 기록도 운영자의 로그로 보내는 기능을 켜지 않아 운영자는 받지 않으며, Google이 서비스 운영을 위해 따로 남기는 기록은 Google 정책에 따릅니다. [확인 필요: Firebase Hosting이 자체적으로 남기는 요청 기록의 항목·보존 기간 — B6 실측과 Google 문서로 확인한 뒤 이 줄과 6·8절을 고침]
- **목적과 처리 근거**: 이용자가 설치한 앱을 제공하고 오류 수정을 전달하기 위해서입니다(앱 이용 계약의 이행, 「개인정보 보호법」 제15조 제1항 제4호). 과도한 요청을 막으려고 IP 주소를 메모리에서 잠시 세는 것은 서비스를 안전하게 운영하려는 운영자의 정당한 이익을 위한 것입니다(같은 항 제6호). 동의를 근거로 하지 않으므로 연령 확인 전에도, 만 14세 미만 이용자에게서도 같은 방식으로 처리합니다.

### 3-3. 설정·콘텐츠 파일과 손글씨 인식 모델 (모든 이용자)
- 기능 켜고 끄기 파일, 새 꿈 그림 파일, 낱말 사전 추가 파일을 웹 서버(Google Firebase Hosting)에서 내려받습니다. 이때 IP 주소가 요청 처리에 쓰입니다. 운영자는 이 요청을 기록하지 않습니다. 앱은 운영자의 전자 서명이 맞는 파일만 쓰며, 이 요청에 이용자에 대한 값을 싣지 않습니다.
- **손글씨 인식**: '한 마디'의 글씨는 Google의 ML Kit 손글씨 인식(Digital Ink Recognition)으로 **기기 안에서** 읽습니다. 처음 쓸 때 언어별 인식 모델(약 20MB)을 Google 서버에서 내려받으며, 이때 IP 주소가 쓰입니다. **쓴 글씨(획)와 인식 결과는 Google이나 운영자에게 보내지 않습니다.** 모델을 내려받지 못하면 키보드로 쓸 수 있습니다.
- **ML Kit 진단 정보**: 손글씨 인식 기능은 동작하면서 Google에 다음 정보를 보냅니다 — 기기 정보(제조사·모델·운영체제 버전과 빌드, 쓸 수 있는 연산 가속기), 앱 정보(패키지 이름·앱 버전), 설치마다 만든 식별자, 성능 값(처리 시간 등), 기능 설정 값, 설정한 인식 언어, 입력·출력 크기, 기능 판, 사건 종류, 오류 코드. Google은 이 정보를 ML Kit의 진단과 사용 분석에 씁니다. 운영자는 이 정보를 받거나 보지 않습니다. 자세한 내용은 Google의 ML Kit 데이터 공개 문서(https://developers.google.com/ml-kit/android-data-disclosure)에 있습니다.
- **목적과 처리 근거**: 설정·콘텐츠 파일과 인식 모델 내려받기는 앱의 기능을 제공하기 위해서입니다(앱 이용 계약의 이행, 「개인정보 보호법」 제15조 제1항 제4호). 동의를 근거로 하지 않으므로 연령 확인 전에도 같은 방식으로 처리합니다. ML Kit 진단 정보는 운영자가 받거나 맡기는 정보가 아니라, Google이 앱에 들어 있는 자사 구성요소를 통해 기기에서 직접 받아 자사 목적(진단·사용 분석)에 쓰는 정보입니다. 그래서 운영자의 처리위탁이 아니며, Google이 자사 방침에 따라 처리합니다(9절).

### 3-4. '링크로 공유'를 켠 분
- **항목**:
  - 익명 계정 식별자(무작위 값), 연령 확인 통과 기록(확인 절차의 판 번호와 날짜. 태어난 해·달은 보내지 않음), 마지막 이용 월
  - 로그인 세션 기록: 익명 계정 인증 서비스(Supabase)가 세션을 관리하면서 접속 IP 주소·브라우저 정보(User-Agent)·시각을 남길 수 있습니다 [확인 필요: 기록 여부·끄는 방법·보존 기간 — 실측 결과로 이 줄과 6·8절을 고침]

  - 앱이 만든 공개 이미지·8초 영상(이름은 이름 공개를 켰을 때만 이미지에 들어감)
- **공개 사본에 넣지 않는 것**: 쓴 글씨와 낱말, 말결 분류값, 그날의 마음을 드러내는 장면과 문구(그날 쓴 말에 따라 달라지는 꿈 문구, 몽망이가 말에 대답하는 장면). 결 이름에는 감정을 나타내는 이름을 쓰지 않습니다. 다만 28밤 동안 쌓인 몸의 버릇(빗 자세·먹 기미)은 그 몽망이의 모습이라 이미지·영상에 그대로 보입니다.
- 계정을 만들거나 되찾을 때 지나친 시도를 막으려고 IP 주소(IPv6는 앞부분 64비트)를 서버 메모리에서 최대 하루 세며, 저장하지 않습니다.
- **목적과 처리 근거**: 이용자가 켠 기능(공유 링크 웹 페이지)을 제공하기 위해(계약 이행, 「개인정보 보호법」 제15조 제1항 제4호). 공개 범위는 5절.
- **보내지 않는 것**: 획의 시간·필압, 이용 시간대 습관, 자리 비운 길이, 방문 시각, 기기 모델·운영체제 같은 기기 정보, 위치.

### 3-5. '맡겨 두기'(클라우드 보관)를 켠 분
- **항목**: 3-4의 계정 항목 + **게임 기록**. 게임 기록에는 다음이 들어 있습니다.
  - **한 마디**: 날마다 몽망이 몸에 붙은 한 획의 좌표와 그 말의 분류값만 보관합니다. 나머지 글씨는 기기에만 남습니다. 그래서 다른 기기로 되찾으면 몽망이의 몸과 꿈은 그대로지만, 지난날 쓴 글씨 전체는 볼 수 없습니다. 모든 날이 같은 모양으로 올라가므로 어떤 날의 말이었는지는 구별되지 않습니다
  - 그은 획의 좌표·시간·필압
  - 잠 시각·아침 시각 설정, 잠든 시각·깬 시각, 기기 시간대
  - 게임 진행 값(쌓인 말결로 생긴 몸의 버릇, 밥·간식 상태(이번 깸의 숟갈·작은 것 수, 열린 종류)와 밥 알림 설정 포함)과 몽망이 이름. 마실 날 표시는 올리지 않습니다
  - **이용 시간대 습관**(하루 24시간 중 언제 앱을 여는지), **자리 비운 길이**(최근·가장 긴), **마지막 방문 시각**, **설치 시각**
- 게임 기록을 올릴 때 함께 보내는 값: 기기에서 저장한 시각, 기록의 검증값(해시). **기기를 구분하는 값(기기 식별자·무작위 기기 값)은 보내지 않습니다.**
- 기기를 옮길 때 쓰는 '되찾기 글귀'는 서버에 **변환한 값(해시)만** 저장합니다. 되찾은 뒤 연결이 끊겨 같은 기기에서 같은 글귀로 다시 시도하면, 첫 되찾기 뒤 24시간 안에만 처음과 같은 결과를 돌려줍니다(이를 위해 새로 저장하는 값은 없습니다).
- 위 값을 함께 보면 이용자가 **언제 앱을 열고 얼마나 비우는지 같은 생활 리듬**과 **어떤 종류의 말을 자주 썼는지**를 짐작할 수 있습니다. 운영자는 이 값을 게임 기록 안에 묶어 보관할 뿐, 따로 꺼내 저장·검색·열람하는 기능을 두지 않으며 공개 페이지에 넣지 않습니다.
- **목적과 처리 근거**: 기기를 바꾸거나 앱을 지워도 몽망이를 잃지 않도록 보관·복원하기 위해(이용자가 켠 기능의 제공, 계약 이행 — 「개인정보 보호법」 제15조 제1항 제4호).

### 3-6. 공유 링크 웹 페이지 방문자
- 페이지가 열릴 때 **페이지 로드 수**를 한 번 셉니다. 쿠키나 식별자를 쓰지 않고, 이 신호로 IP를 저장하지 않습니다.
- 운영자는 웹 페이지 요청 기록을 IP와 링크 주소가 함께 남지 않도록 수집하지 않습니다. 과도한 요청을 막으려고 IP 주소(IPv6는 앞부분 64비트)를 서버 메모리에서만 쓰고 저장하지 않으며, 페이지 요청은 약 1분, 신고 횟수는 최대 1시간 뒤 메모리에서도 지웁니다. 웹 페이지를 전송하는 사업자(Google Firebase Hosting)의 처리는 8절에 적었습니다.
- **신고**를 누르면, 같은 사람의 중복 신고를 가려내려고 **IP 주소를 가명 처리한 값(개인정보)**을 **신고 대상별로 최대 7일** 보관한 뒤 파기합니다. 신고자를 직접 식별하는 정보는 저장하지 않습니다.
  - 신고는 정해진 사유 중 하나만 고르며, 글을 적는 칸이 없습니다.
  - 가명 처리한 값은 IP 주소(IPv6는 앞부분 48비트)를 **신고 대상마다 다른 무작위 값**과 섞어 되돌릴 수 없게 바꾼 값이라, 서로 다른 페이지의 신고를 이어 볼 수 없습니다. 페이지가 가려지거나 7일이 지나면 그 무작위 값과 함께 지웁니다.

### 3-7. 의견 보내기
- 공방 노트의 '의견 보내기'는 앱 밖의 웹 설문 페이지를 열 뿐이며, 앱은 게임 기록이나 기기 정보를 함께 보내지 않습니다. 설문에 직접 적은 내용은 그 설문 서비스의 방침에 따라 처리되고, 운영자는 게임 개선에만 씁니다. [설문 도구 확정 후 이름·방침 링크 기입, 7·8절에 행 추가]

## 4. 연령 확인과 만 14세 미만 아동

- **계정이 생기는 기능과 이용 통계는 만 14세 이상만 켤 수 있습니다.** 기기 안 게임은 연령 확인 없이 누구나 쓸 수 있습니다. 앱은 아동을 주된 대상으로 하지 않으며, 앱 마켓의 아동 대상 카테고리에 참여하지 않습니다.
- '이용 통계 보내기'나 계정이 생기는 기능('링크로 공유', '맡겨 두기', 이후 추가되는 '밤물')을 처음 켜기 전에 **태어난 해와 달**을 한 번 묻습니다. 판정은 기기에서 하고, **태어난 해·달은 기기와 서버 어디에도 저장하지 않습니다.** 날짜는 묻지 않으므로, 태어난 달이 이번 달이면 아직 생일 전으로 봅니다.
- 만 14세 미만이면 계정을 만들지 않고 해당 기능과 이용 통계를 켜지 않습니다. 기기에는 '미달'과 날짜만 남겨 같은 날 다시 묻지 않습니다. 기기 안 게임과 카드 저장·공유는 그대로 쓸 수 있습니다.
- 운영자는 법정대리인 동의 절차를 제공하지 않으며, 만 14세 미만 아동의 계정을 만들지 않습니다. 동의를 근거로 하는 3-1의 이용 통계와 계정이 생기는 기능은 만 14세 확인을 통과한 분만 켤 수 있습니다. 3-2·3-3의 업데이트 확인과 파일·모델 내려받기는 동의가 아니라 앱 이용 계약의 이행을 근거로 하므로, 연령 확인 없이 모든 이용자에게서 같은 방식으로 처리됩니다. 손글씨 인식 진단 정보는 Google이 앱 안 구성요소로 직접 받는 정보입니다(9절).
- 만 14세 미만 아동의 정보가 서버에 처리된 사실을 알게 되면 지체 없이 지웁니다. 확인하는 즉시 공개 페이지를 내리고, 잘못된 요청으로 다른 사람의 기록이 지워지지 않도록 앱 안에 알린 뒤 **72시간** 뒤 서버에 맡긴 것을 지웁니다. 보호자는 17절의 연락처로 그 몽망이의 공유 링크 코드를 알려 주세요. 정보를 더 모으지 않기 위해 보호자임을 증명하는 서류는 받지 않습니다. 대신 72시간 동안 앱 안에서 계정 주인에게 알리고, 그사이 주인이 연락해 오면 확인한 뒤 삭제를 멈출 수 있습니다. 되찾기 글귀를 알고 있다면 웹 삭제 페이지(12절)에서 바로 지울 수 있습니다.

## 5. 공유 링크 웹 페이지의 공개 범위

- '링크로 공유'는 **기본으로 꺼져 있고**, 이용자가 켤 때만 `https://mongmang.ink/m/(8자 코드)` 페이지가 공개됩니다. 링크를 아는 누구나 볼 수 있습니다.
- 공개 내용은 3-4의 공개 페이지 사본뿐이며, **링크를 켤 때(또는 '다시 만들기'를 누를 때)의 값으로 고정**됩니다. 매일 바뀌지 않으므로 링크를 아는 사람이 이용자의 접속 리듬을 알 수 없습니다.
- 쓴 글씨·낱말과 그날의 마음을 드러내는 장면은 공개하지 않습니다(3-4). 몸에 쌓인 버릇은 보입니다.
- **이름 공개는 기본으로 꺼져 있습니다.** 켜도 금칙어에 걸리거나 연락처처럼 보이면(숫자가 7개 이상 이어짐) 이름 없이 앱 이름('몽망이 키우기')으로 보입니다. 몽망이 이름에 실명이나 연락처를 쓰지 마세요.
- 검색 엔진에 색인되지 않게 설정하며, 공개 페이지 목록을 제공하지 않습니다.
- **끄기**: 앱에서 링크를 끄면 앱·서버에서는 즉시, 웹 페이지는 캐시 때문에 **최대 1시간 안에** 보이지 않게 되고 공개 파일은 지워집니다. 이미 다른 사람이 내려받은 화면이나 메신저에 이미 붙은 미리보기 카드는 운영자가 지울 수 없습니다.
- 서로 다른 3명이 신고하면 페이지가 자동으로 가려질 수 있습니다(이 자동 숨김은 운영 상황에 따라 켜고 끄며, 한 시간에 자동으로 가리는 수에 상한이 있습니다 — 12-1). 가려지면 운영자가 7일 안에 확인해 복원하거나 삭제합니다. 30일 안에 결정하지 못하면 다시 공개합니다(그사이 이용자가 링크를 껐으면 지웁니다). 운영자는 확인 결과에 따라 페이지는 두고 **이름만 가릴** 수 있으며, 가린 이름은 운영자만 다시 열 수 있습니다.

## 9. 제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다. 공유 링크 웹 페이지의 공개는 이용자가 직접 켠 것입니다(5절). 다만 법령에 특별한 규정이 있거나 수사기관 등이 법령이 정한 절차와 방법에 따라 요청하는 경우에는 「개인정보 보호법」 제18조 제2항에 따라 필요한 최소한의 범위에서 제공할 수 있습니다.

- 손글씨 인식 기능의 진단 정보(3-3)는 앱에 들어 있는 Google ML Kit이 Google에 직접 보내는 정보입니다. 운영자는 이 정보를 받거나 보지 않으므로 Google에 제공하지 않으며, Google이 자사 목적(사용 분석)에도 쓰므로 운영자가 업무를 맡기는 처리위탁(7절)으로도 적지 않습니다. 다만 운영자가 이 구성요소를 앱에 넣었으므로 받는 자(Google LLC), 항목(3-3), 목적(ML Kit 진단·사용 분석), 보유 기간(Google 정책에 따름)을 여기와 8절에 알립니다.

## 10. 기기 백업과 내보내기

- 기기의 백업 기능(iOS iCloud 백업, Android 자동 백업)이 켜져 있으면, 게임 기록이 **이용자 본인의 Apple·Google 계정 백업**에 포함될 수 있습니다. 이 백업은 Apple·Google의 정책에 따라 처리되며 운영자는 접근할 수 없습니다. 서버 접속 정보(로그인 세션)는 앱이 백업 제외로 표시해 백업에서 빼고, 게임 기록(세이브)은 백업에 포함됩니다. 그래서 백업으로 새 기기를 복원하면 게임은 이어지지만 맡겨 두기는 되찾기 글귀로 다시 이어야 합니다.
- '세이브 내보내기'로 만든 코드는 이용자가 직접 복사·보관하는 것이며, 운영자에게 전송되지 않습니다.

## 11. 알림, 카드 저장·공유

- 앱은 **기기 안에서 예약하는 로컬 알림**만 씁니다. 푸시 토큰을 수집하지 않습니다. 알림은 처음 요청할 때 허용 여부를 고르며, 기기 설정에서 언제든 끌 수 있습니다.
- **밥 알림**(선택, **기본 꺼짐**): 켜면 앱을 닫거나 다른 앱으로 나갈 때 몽망이가 벼루 쪽을 본다는 관찰 문장의 알림을 기기 안에 **하나만** 예약합니다. 그 깸에 한 마디를 썼으면 다음다음 깸에, 쓰지 않았으면 다음 깸에 울리며, 무엇을 썼는지와는 상관없습니다. 앱은 따로 기록하지 않으며, 예약은 휴대폰 알림 시스템에 잠시 있다가 앱을 열면 지워집니다. 이미 울린 알림도 앱을 열면 치웁니다. 서버나 이용 통계로 보내지 않습니다. 처음 알림 권한을 여쭐 때 함께 고를 수 있고, 그 뒤에는 공방 노트에서 켜고 끕니다. 켜지 않아도 몽망이는 똑같이 자랍니다. 밥 알림은 연령과 관계없이 고를 수 있으며, 광고나 구매 권유를 싣지 않습니다.
- 아침 인화 카드의 이미지 저장·공유는 이용자가 직접 누를 때만 일어나며, 기기의 기본 공유 화면을 통해 이용자가 고른 앱으로 전달됩니다. 운영자는 그 내용을 받지 않습니다. 사진 앱에 저장할 때 저장 전용 권한을 물을 수 있고, 기존 사진은 읽지 않습니다.

## 13. 자동 수집 장치와 추적

- 앱과 웹 페이지는 쿠키나 이와 비슷한 추적 기술을 쓰지 않습니다. 웹 페이지의 페이지 로드 신호(3-6)는 쿠키·식별자 없이 개수만 셉니다.
- 다른 회사의 앱·웹사이트 데이터와 연결해 이용자를 추적하지 않으며, 맞춤형 광고를 하지 않습니다.

## 14. 안전성 확보 조치

- 모든 서버 통신은 암호화(TLS)합니다. 게임 기록·로그인 정보를 처리하는 앱 서버는 서울 리전에서 실행되며, 요청과 공개 이미지·영상 업로드는 수탁자(Google·Supabase)의 네트워크를 지나 도착하며, 암호화 연결은 이용자와 가까운 국가의 거점에서 처리될 수 있습니다(8절).
- 되찾기 글귀는 해시 값만 저장하고, 공유 링크 코드는 추측하기 어려운 무작위 값으로 발급합니다.
- 서버는 게임 기록 본문에서 날짜 수·획 수·버전 외의 값을 꺼내 저장하지 않으며, 게임 기록을 열람하는 관리 화면을 두지 않습니다.
- 공개 페이지에는 서버가 허용 목록으로 검사한 값만 올라갑니다.
- 앱이 내려받는 설정·콘텐츠 파일은 전자 서명을 검사해, 위조되거나 바뀐 파일은 쓰지 않습니다.
- 서버 로그에는 로그인 토큰, 되찾기 글귀, 게임 기록 본문, 업데이트 확인 요청의 값을 남기지 않습니다. 인식된 글자는 기기의 로그에도 남기지 않습니다.
- 서버·데이터베이스 관리 권한은 운영자 1인으로 한정하고, 관리 계정에 2단계 인증을 씁니다.
- 기기 안의 게임 기록은 앱 전용 저장 공간(운영체제가 다른 앱의 접근을 막는 영역)에 둡니다.
- **유출 대응**: 개인정보가 유출되었거나 유출되었을 가능성을 알게 되면, 법령이 정한 기한 안에 앱 안 공지와 이 페이지 게시로 알리고 관계 기관에 신고합니다. 익명 계정에는 연락 수단이 없어 개별 연락 대신 이 방법을 씁니다.

## 15. 서비스 종료

서버 운영을 끝내게 되면 **90일 전에 앱 안과 이 페이지에서 알리고**, 그동안 서버에 맡긴 것을 내려받을 수 있게 합니다. 서버가 없어도 앱의 기기 안 게임은 계속 동작합니다. 종료 뒤 서버의 정보는 모두 파기합니다.

## 16. 정보 처리가 바뀔 때
