## 팀(오너 아님)이 확인할 것
- 빌드 의존성에 분석·광고·크래시 SDK가 없고, 원격 업데이트(expo-updates)는 EAS 설치 id·요청 내용이 방침 3-2와 같은지(테크). 바뀌면 Data safety·App Privacy 답이 바뀐다.
- 아침 카드 사진 저장 방식과 권한(`NSPhotoLibraryAddUsageDescription`), iCloud·Auto Backup 포함 여부(D-06) — 방침 3·5절의 [구현 확인 필요](테크).
- IARC 'OS 공유' 문항, Apple 개정 연령 설문 문구, Data safety '수집' 정의·유저 시작 전송 예외 원문 확인(출시·정책).
- 영문 긴 설명·방침 영어판 원어민 검수 1회(출시·정책).
- 심사자가 '잠 한 번' 하루를 기다리지 않고 아침 화면을 볼 방법(심사 메모 또는 빌드 설정)(테크·출시).
- 설문 눈 A/B 판정 기준 수치를 응답 전에 정하기(리서처).
- 커밋 전 작성자 ≠ 검토자 리뷰(팀 리뷰 원칙).
