### 1-1. 재지 않는 것 / 손대지 않는 것

- **댓글·DM 원문은 에이전트가 읽거나 모으지 않는다.** `docs/ops/crisis-disclosure.md` 범위에 SNS 댓글·DM이 들어 있고, 원문은 운영자(사람)만 읽는다. 팀이 받는 것은 오너가 센 **숫자**뿐이다(관심 댓글 수, 아래 2절 경계 지표 수).
- 팔로워 개인 정보·프로필은 모으지 않는다. 대량 수집 도구를 쓰지 않는다.
