# 1주차 촬영 목록 (손만)

- 찍는 사람: 오너. 장비: 폰 1대(촬영용) + 개발자 기기(S25 또는 iPhone, RC 설치). 삼각대 위에서 내려 찍기.
- 1주차 재료는 **01-09(토)** 실물 촬영, **01-10(일)~01-16(토)** 밤 화면 녹화, **01-11~01-17** 아침 카드 저장으로 모은다.
- 파일 이름: `YYMMDD-코드-설명.mp4|png` (예: `270110-R1-first-tap-nun.mp4`). 원본은 팀 공유 폴더, 저장소에 넣지 않는다(용량·개인정보).

## 0. 손만 점검표 (모든 촬영 전)

| # | 점검 |
|---|---|
| 1 | 얼굴·목소리 없음. 말하지 않는다(현장음에 말소리가 들어가면 그 구간을 쓰지 않는다) |
| 2 | **반사**: 꺼진 폰 화면·벼루의 먹물·유리컵·창에 얼굴이 비치지 않는다. 촬영 전 프레임을 한 번 확대해 본다 |
| 3 | 손목 위로 소매(무늬 없는 어두운 색). 반지·시계·문신·손톱 장식 같은 식별 요소를 빼거나 가린다 |
| 4 | 바탕: 한지 또는 어두운 나무 책상. 창밖·벽 사진·우편물·택배 송장·책 제목·다른 회사 물건이 프레임에 없다 |
| 5 | 개발자 기기: 방해 금지 모드, 알림 미리보기 끔, 상태 표시줄에 다른 앱 아이콘 없음, 배터리·시계는 그대로 둬도 된다 |
| 6 | 앱: RC 판(DEV 버튼 없음), 언어 한국어, 모션 줄이기 꺼짐(3초 대답을 그대로 보이기 위함), 공유 링크 켜지 않음 |
| 7 | 낱말: `../calendar.md` 2절 표의 그날 낱말만. 다른 말을 시험 삼아 쓰지 않는다(그 아이의 생애에 남는다) |

## 1. 실물 촬영 — 01-09(토), 약 90분

| 코드 | 무엇 | 길이·형식 | 어디에 |
|---|---|---|---|
| P1 | 벼루에 먹을 가는 손, 위에서 45° | 사진 4:5 1장 + 영상 20초(현장음) | S2 사진 1, 2주차 이후 예비 |
| P2 | 한지에 붓으로 '눈 귤 차 고양이 하늘' 세로로 쓴 한 장 | 사진 4:5 | S2 사진 2, F2 첫 장 |
| P3 | 먹 갈기 클로즈업 10초 + 붓으로 '고양이' 쓰기 전 과정 | 세로 영상 1080×1920, 현장음 | V2 0.0–4.5 |
| P4 | 붓끝이 한지에 닿는 순간 매크로 5초 | 세로 영상 | V2 커버 후보, 예비 |
| P5 | '산책'·'이불'을 붓으로 쓰기 | 세로 영상 각 10초 | 예비(하루 거름 대비, 2주차 피드) |
| P6 | 연적에서 물 한 방울 떨어뜨리기(실물 연적이 있을 때만) | 세로 영상 5초 | 예비 |

- 실물 도구는 오너가 가진 것만 쓴다. 사지 않는다(예산 0원). 도구 상표·로고가 보이면 돌려 놓는다.
- 먹 가는 소리는 '현장음'일 뿐이다. 이것으로 수면 소리 채널 영상(오너 결정 ④)을 대신하지 않는다.

## 2. 밤 화면 녹화 — 01-10(일) ~ 01-16(토)

- 기기 내장 화면 녹화(소리 포함). 녹화는 쓰기 직전에 켜고, 3초 대답이 끝나고 2초 뒤에 끈다.
- 손만 나오는 '폰을 든 손' 촬영은 2주차 형식 B 판정 전까지 하지 않는다(1주차는 화면 녹화만).

| 코드 | 날 | 무엇 | 쓰는 곳 |
|---|---|---|---|
| R1 | 01-10 일 | **첫 탭 → 눈이 열림 → 첫 안내 → '눈' 쓰기 → 3초 대답 → 연적으로 재우기** 전부(끊지 않고) | V1, T0·B0 그림(C1·C2 캡처 원본), F1 |
| R2 | 01-11 월 | '귤' 쓰기 → 대답 | 예비(2주차 이후) |
| R3 | 01-12 화 | '차' 쓰기 → 대답 | 예비(2주차 이후) |
| R4 | 01-13 수 | 벼루 갈기 → '고양이' 쓰기 → 대답 | V2 5.0–13.5 |
| R5 | 01-14 목 | '하늘' 쓰기 → 대답 | 예비(2주차 이후) |
| R6 | 01-15 금 | '산책' 쓰기 → 대답 | 예비 |
| R7 | 01-16 토 | '이불' 쓰기 → 대답 | 예비 |

- 녹화마다 팀이 같은 날 '설계 몸짓과 맞는지' 한 줄로 기록한다(맞음 / 다름 + 실제 몸짓). 원고의 `[촬영 뒤 확정]` 칸이 이 기록을 따른다.
- 인식이 틀려 다른 낱말이나 '모르는 말'(갸웃)이 나오면 **다시 쓰지 않고 그대로 둔다**(그 아이의 실제 기록). 그날 카드 글은 실제 일어난 일로 고친다 — 예: "'차'를 썼는데 몽망이는 고개를 갸웃했다."

## 3. 아침 저장 — 01-11(월) ~ 01-17(일)

- 아침에 한지를 건져 올려 카드를 받은 뒤, 앱의 공유 화면에서 **4:5와 9:16을 사진으로 저장**한다(스크린숏이 아니라 앱이 만든 이미지). 저장 파일이 `capture-list.md`의 C3~C9다.
- 01-17(일)은 이레 아침 화면도 저장한다(C10).
