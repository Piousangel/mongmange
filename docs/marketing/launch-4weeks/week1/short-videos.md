# 세로 영상 1주차 — V1 · V2 (TikTok · YouTube Shorts · 릴스 같은 파일)

- 규격: 1080×1920, 30fps, 12~15초, 소리 = 현장음·앱 소리만(음악 없음). 화면 글은 위·아래 안전 영역(위 14%, 아래 20%)을 피해 가운데 위쪽에 둔다 [팀 추정: 플랫폼 UI가 덮는 자리].
- 화면 글: 한국어 큰 줄 + 영어 작은 줄. 글꼴은 앱과 같은 Gowun Batang / Cormorant Garamond(OFL, 아트 6절). 느낌표·이모지 없음.
- 첫 1초 규칙(marketing-plan 4-1): 눈이 열리는 순간 또는 글씨를 쓰는 손. 로고·제목 카드로 시작하지 않는다.
- 끝 카드는 1.5초 이하, '몽망이 키우기 · 개발 중 / {EN_NAME} · in development'. 출시 날짜·스토어 배지 없음.
- 형식 시험(metrics.md 3-1): **V1 = 형식 A(앱 화면만)**, **V2 = 형식 B(실물 먹 → 앱 화면)**. 2주차 V3(A)·V4(B)와 함께 판정 1에 쓴다.

## V1. 눈을 뜨고, 첫 한 마디 — 01-13(수) 08:30 · 형식 A · 12초

재료: R1 = 01-10 밤 첫 탭~첫 한 마디 화면 녹화(`shot-list.md`)

| 시간 | 화면 | 화면 글(한 / 영) | 소리 |
|---|---|---|---|
| 0.0–1.2 | 한지 위 먹 방울 크게. 손끝이 닿고, 먹이 갈라지며 눈이 열린다 | 먹 한 방울에 손끝을 대면 / Touch a drop of ink | 앱 소리 |
| 1.2–3.0 | 눈을 뜬 몽망이가 손끝 쪽을 본다 | — | 앱 소리 |
| 3.0–7.0 | 쓰기 자리. 손가락으로 '눈'을 쓴다(실제 속도, 빨리 감기 없음) | 처음 건넨 말, 눈 / First word: 눈 (snow) | 종이 마찰 |
| 7.0–10.5 | 먹이 몸으로 빨려 들고, 위를 보며 움츠렸다 펴진다(3초 대답 전체) | — | 앱 소리 |
| 10.5–12.0 | 끝 카드 | 몽망이 키우기 · 개발 중 / {EN_NAME} · in development | — |

- [촬영 뒤 확정] 3.0–7.0 구간이 4초를 넘으면 쓰는 중간을 자르지 않고 영상 전체를 늘린다(손이 한 일을 줄여 보이지 않게). 3초 대답은 자르지 않는다.
- 정 자막(앱이 처음 세 번 띄우는 관찰 자막)이 화면에 나오면 그대로 둔다. 그 위에 화면 글을 겹치지 않는다.

### TikTok 캡션
```
먹 한 방울에 손끝을 대면 눈을 떠요. 처음 건넨 말은 '눈'.
Touch a drop of ink and it opens its eyes. First word: 눈 (snow).
실제 게임 화면 · real game footage
#몽망이 #indiegame #cozygames #calligraphy #hangul
```
- 설정: 상업적 콘텐츠 공개 켬 → **내 브랜드(Your brand)**. 댓글 필터 켬(`../risk-check.md` 1-3). 듀엣·이어 찍기 허용 여부는 기본값.

### YouTube Shorts
- 제목(100자 이하): `먹 한 방울에 처음 건넨 말 '눈' | One word in ink #shorts`
- 설명:
```
먹 한 방울을 키우는 게임을 혼자 만들고 있어요. 날마다 붓으로 낱말 하나를 쓰면 몽망이가 그 글자를 마시고 몸으로 대답해요. 실제 게임 화면이에요.
I'm making a game about raising a drop of ink. Write one word a day, and it answers with its body. Real game footage.
mongmang.ink
#몽망이 #indiegame #calligraphy
```
- 설정: 시청자층 **'아니요, 아동용이 아닙니다'**. 유료 프로모션 표시 = 해당 없음(제3자 대가 없음) [확인 필요: 자기 제품 홍보의 표시 기준 원문]. 변경·합성 콘텐츠 표시 = 아니요(생성형 AI·합성 없음).

## V2. 먹을 갈고, '고양이'라고 쓰면 — 01-16(토) 08:30 · 형식 B · 15초

재료: P3 = 01-09 실물 촬영(먹 갈기·붓으로 '고양이'), R4 = 01-13 밤 '고양이' 화면 녹화

| 시간 | 화면 | 화면 글(한 / 영) | 소리 |
|---|---|---|---|
| 0.0–1.5 | **실물**: 벼루 위 먹을 가는 손 클로즈업 | 먹을 갈고 / Grind the ink | 먹 가는 현장음 |
| 1.5–4.5 | **실물**: 붓으로 한지에 '고양이'를 쓴다 | 고양이, 라고 쓰면 / Write 고양이 (cat) | 붓·종이 현장음 |
| 4.5–5.0 | 컷 전환(단순 컷, 겹침·변형 효과 없음) | — | — |
| 5.0–8.0 | **앱 화면 녹화**: 벼루에 원을 그려 먹을 갈고, 쓰기 자리에 손가락으로 '고양이' | 게임에서는 손가락으로 / In the game, with a fingertip | 앱 소리 |
| 8.0–13.5 | **앱 화면 녹화**: 마시기 → 빗이 귀처럼 쫑긋 → 웅크렸다 기지개 | — | 앱 소리 |
| 13.5–15.0 | 끝 카드 | 몽망이 키우기 · 개발 중 / {EN_NAME} · in development | — |

- 실물 구간과 앱 구간을 한 프레임에 겹치지 않는다(D-04). 실제 먹이 화면 속으로 흘러 들어가는 식의 연출도 하지 않는다.
- 실물 '고양이' 글씨와 앱 속 '고양이' 글씨는 서로 다르다. 같아 보이게 맞추지 않는다.

### TikTok 캡션
```
진짜 먹으로 '고양이'를 쓰고, 게임에서도 써 봤어요. 앞은 실물, 뒤는 실제 게임 화면.
Real ink first, then the real game. 고양이 = cat.
#몽망이 #calligraphy #indiegame #cozygames #hangul
```
- 설정: V1과 같음.

```
앞부분은 진짜 벼루와 붓으로 찍은 실물 영상, 뒷부분은 실제 게임 화면이에요. 게임에서는 손가락으로 낱말 하나를 쓰면, 먹 방울 몽망이가 그 글자를 마시고 몸으로 대답해요.

mongmang.ink
#몽망이 #calligraphy #indiegame
```
- 설정: V1과 같음.
