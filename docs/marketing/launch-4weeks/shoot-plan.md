# 4주 일괄 촬영 계획 — 실물은 두 번에, 화면은 매일 3분

- 작성: 마케팅 팀 / 2026-11-25 / v0.1 — 촬영·게시 없음, 오너에게 넘기는 계획
- 근거: `calendar.md` 2절(28 낱말 표)·6절(오너 시간), `week1/shot-list.md`(P1~P6·R1~R7 정의), `week2~4/`의 원고, `risk-check.md`, 오너 결정 ③(얼굴·목소리·집 안 없음)
- 이 문서가 달력 6절의 '토요일 실물 촬영 90분 × 4주'를 대신한다. 매일 밤 녹화(약 3분)와 매일 아침 카드 저장(약 1분)은 그대로다 — 그날의 화면은 그날에만 생기므로 몰아 찍을 수 없다.

## 0. 결론

1. **실물(먹·붓·한지) 장면 16개를 두 번에 찍는다.** 세션 A = 01-09(토) 약 100분(1·2주차 재료), 세션 B = 01-16(토) 약 70분(3·4주차 재료와 형식 B 예비). 28 낱말은 미리 정해져 있어서(calendar 2절) 실물 글씨는 앞당겨 쓸 수 있다.
2. **한 번에 끝내고 싶으면 01-09에 A·B를 이어서 약 170분**(쉬는 시간 포함 3시간)에 찍는다. 두 번으로 나눈 기본안은 세션 A 결과물을 한 주 써 보고 구도·밝기를 B에서 고칠 수 있다는 점이 낫다.
3. 오너 시간: 토요일 실물 촬영이 4주 360분 → 170분으로 준다. 달력 6절 계산(하루 약 4분 × 7 + 일요일 30분 + IG 스토리 약 2분 × 7 = 주 약 72분)에 실물 촬영만 바꾸면, 세션 A는 시작 전 주(01-09), 1주차는 세션 B를 더해 **약 2시간 20분**, **2~4주차는 주 약 1시간 10분**(4주차는 02-07 아침 녹화 약 10분 더)이다 [팀 추정].
4. 앱 화면은 매일 밤 그날 낱말 하나만 쓰며 녹화한다(R1~R28). 02-07 아침에 클라이맥스 원본(RM)을 한 번 더 녹화한다.
5. 모든 촬영은 1절 **손만 점검표**를 지난다. 세션마다 시작할 때 한 번, 장면마다 짧은 점검을 한 번.

- 파일 이름: `YYMMDD-코드-설명.확장자`(예: `270116-P13-28words.jpg`, `270207-RM-final-morning.mp4`).
- 원본은 팀 공유 폴더에만 둔다. 저장소에 넣지 않는다(용량·개인정보). 세션이 끝나면 그날 안에 두 곳에 백업한다.
- 촬영한 한지는 4주가 끝날 때까지 버리지 않는다(다시 찍어야 할 때 같은 글씨를 쓰기 위해). 공개 여부와 무관하게 실명·주소가 적힌 종이와 같이 두지 않는다.

## 9. 잘 안 됐을 때

| 상황 | 대응 |
|---|---|
| 세션 A를 01-09에 못 함 | 01-10(일) 낮에 P1~P4만 먼저(1주차 필수), 나머지는 세션 B에 합침 |
| 세션 B를 01-16에 못 함 | 01-23(토)까지. P10은 01-25 게시라 01-23이 마지막 |
| 실물 연적이 없다 | P6 빼고, P7은 벼루·붓 둘. 글에서 '사진은 벼루와 붓'으로 고친다 |
| 같은 손으로 안 보인다(옷·빛이 다름) | 같은 캐러셀에 A·B 세션 사진을 섞지 않는다 |
| 밤 녹화를 놓쳤다 | 다시 쓰지 않는다. 그날 영상 재료가 필요하면 예비 R로 바꾸고 카드 글만 올린다 |
