## 4. 과장 표현

| 쓰지 않는 말 | 대신 |
|---|---|
| 세계 최초·유일한·국내 첫·1위·역대급·최고의 | 쓰지 않는다(경쟁 지형 조사는 '찾지 못했다'일 뿐 — 컨셉 리뷰 6절) |
| AI가 읽어 준다·AI 펫·AI가 그린다 | "앱이 정해진 규칙으로 그려요"(FACTS FAQ) |
| 광고 없음·결제 없음·완전 무료 | "무료로 내려받아요. 확률형 아이템과 화면을 가리는 광고는 넣지 않아요"(F7) — 질문 답할 때만 |
| 곧 출시·겨울 출시·2월 출시·사전예약 오픈 임박 | "시험을 마친 뒤 정해요"(F9) |
| 내 글씨는 절대 서버로 안 가요 | "기기 안에서 읽도록 만들고 있어요"(F12b, 현재형 약속 금지) |
| 마음을 읽는다·감정을 알아준다·위로해 준다·힐링 효과 | 몸짓만 적는다("위를 올려다보았다") |
| 중독성·무료 보석·보상·이벤트 | 쓰지 않는다 |
| 느낌표·이모지·"지금 바로" | 쓰지 않는다(아트 톤, store-listing 머리) |
| 행복해했다·좋아했다(감정 단정) | 몸짓 관찰("눈을 가늘게 휘었다") |

- 실물 먹 촬영과 게임 화면을 이어 붙인 영상(형식 B)은 캡션에 "앞은 실물, 뒤는 실제 게임 화면 · 게임에서는 손가락으로 써요"를 늘 넣는다(실물 붓으로 하는 게임으로 오해하지 않게).
- 몸짓 문장이 실제 녹화와 다르면 화면을 따른다(설계값을 사실처럼 쓰지 않음).
