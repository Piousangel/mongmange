## 3. 02-07(일) 아침 — RM 건져 올리기 녹화 (클라이맥스 원본)

| 순서 | 할 일 |
|---|---|
| 1 | 06:20 전후, `../shoot-plan.md` 1절 점검표(특히 5·6: 방해 금지, 알림 미리보기 끔) |
| 2 | 화면 녹화 켜기 → 앱 열기 → 아침 화면에서 한지를 건져 올림 → 카드 28 → 다 자란 몽망이와 낙관이 나오는 화면까지 **끊지 않고** 녹화. 최종 화면에서 5초 더 둔 뒤 끔 |
| 3 | 최종 화면 다음으로 넘어가는 버튼(화첩·새 방울 등)은 **누르지 않는다**. 녹화를 끈 뒤에도 마케팅 쪽 저장이 끝날 때까지 누르지 않는다 |
| 4 | 공유 화면에서 카드 28(C37)·최종(C39)을 4:5·9:16으로 저장. 두루마리 영상 저장이 있으면 저장(D1) |
| 5 | 06:45까지 팀 폴더에 RM·C37·C39·D1을 올림 |

- B경로(최종이 안 나옴)면 2에서 넷째 이레 스냅숏 화면까지 녹화하고 C38을 저장한다. 다른 화면을 찾으려고 앱을 뒤지지 않는다.
- 건져 올리기를 한 번 하면 되돌릴 수 없다. 녹화를 놓쳤으면 다시 하지 않는다. 그때는 V8에서 RM 구간을 빼고 C39 정지 화면 3초로 대신한다.
