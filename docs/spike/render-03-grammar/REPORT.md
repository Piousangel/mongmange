# 렌더 스파이크 03 — 획 문법 3안 비교

- 날짜: 2026-11-20 · 담당: 아트 디렉터 + 테크 리드 · 환경: 웹(CanvasKit) 캡처만. 실기기·비백 질감 판정은 못 함(R9).
- 질문: 7일차에 유저 획이 몸과 같은 먹·coverage로 합쳐져 검댕으로 읽힌다(스파이크 02 리뷰, 치명). 어떤 획 문법이면 "몽망이로 보이면서 내가 그었다"가 되는가?

## 0. 결론
- 개정 이력: 11-20 초판 → 11-20 획 문법 독립 리뷰(`docs/team/reviews/2026-11-20-grammar-review.md`) 반영판(판정 3곳 정정, 받침·귀·밤 대비·L3·테스트·성능 수정 후 재캡처).
- **C(담묵 구별)를 채택하고 B의 틈·비백을 섞었다.** 몸(핵 + 빗)은 늘 짙은 먹이고 맨 앞이다. 유저 획은 그 곁에 종이 틈(0.05W)을 두고 얹힌 담묵 붓자국(`#5F5C56`, 안쪽 농도 32%, 비백 0.45는 끝 30%만)이다. 짙은 실루엣이 0일차 방울 그대로라 서툰 손 7획에도 검댕이 되지 않는다.
- **결론 판정은 "몽망이로 보이나 / 내가 그었다" = 예 / 반쯤**(작성자 합의, 외부 응답 아님). 획이 몸 바깥 회색 부속물이라 '내 붓자국' 느낌은 아직 약하다.
- 리뷰 반영(11-20): 바램 톤 단조(`ink-mid` `#858179`·`ink-faded` `#A7A298`, 밤 `#494A50`·`#3C3E47`, 테스트 고정), 받침 = 바닥 담묵 한 띠(길이 무관, 밤에도), 머리 띠(−80°~0°) 돌출 0.12W 상한, L2 길이 상한 0.7W, L3 감기 50%, 밤 새 획 `#59585A`(밤 몸과 1.30 → 1.64:1), 비백 끝 30%. 아트 v1.2.1, D-12, 시스템 4.3·0절 7번 개정.
- 0일차 빗: 둥근 끝, 굵기 0.074W, 휨 0.2, 쉴 때 1°±2° → 불꽃이 아니라 "곧게 그은 세 획".
- 정본 개정: 아트 바이블 v1.2, D-12(금지 자리 ①은 빗 기하에서 파생해 −25°~81°, 점 단위 판정 가중치 6, L2 상한 0.33W, L3 진짜 감기 attachVersion 2), D-13 주석(한 번만 칠한다 = 가장자리 규칙).
- 아직 아닌 것: 02a처럼 획이 몸 앞을 지나는 느낌(핵이 맨 앞) → 1.x 후보. L3 감기는 50%로 낮췄으나 손가락 여지 남음.

## 3. 남은 위험
1. **몸 앞을 지나는 획 없음 → 다음 스파이크 필수 항목.** 2. L3 50%도 기준 포즈 등의 짧은 획 셋이 손가락처럼 보일 여지. 3. 비백은 S25 확인. 4. (해소) 바램 표 충돌 — 팔레트 재설정·시스템 4.3 개정·단조 테스트. 5. 금지 ① 81° + 머리 띠 상한으로 위쪽 자리 자유도가 줄었다. 6. 서툰 손 세트는 합성 → 실제 손가락 획 20개로 재검증. 7. 성능: 빗은 프레임당 1번(자세 키 캐시), 받침 정점 배열 제거. 남음: 마스크·덧칠 `ribbonsToVerts` 2회, 획별 리본 2개, `perimeterTable` 매 프레임(부착 중), **손획 `live` O(n²) 미손질** → 덧칠 포함 중급 Android 측정. 8. 밤 `stroke-ink` `#59585A` 바탕 2.45:1(장식 수준, 윤곽은 몸 테가 담당), 몸 4.01:1이 가장 밝은 먹.
