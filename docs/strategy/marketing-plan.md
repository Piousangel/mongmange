# 마케팅 기획 v0.1 — 출시 전 채널별 홍보 계획

- 작성: PM / 2026-11-21 / 초안 v0.1 (오너 결정 5개 대기 — 10절)
- 근거·관계: `docs/strategy/number-one.md`(1위 전략 v0.3)가 **무엇을**(피처드·ASO·바이럴 구조·크리에이터 시딩) 정했고, 이 문서는 그것을 **채널별로 언제·무엇을·얼마나** 할지로 풀어 쓴다. 둘이 다르면 number-one이 정본이고, 이 문서를 고친다.
- 날짜 기준: 소프트런칭 12-22 전후 → 판정 01-21~01-26 → 관문 통과 즉시 출시(2월 초 목표, 03-16 상한, D-22·D-23). 아래 날짜는 이 기준에서 거꾸로 센 것이고, 출시일이 움직이면 같은 간격으로 옮긴다.
- 표시: [팀 추정] = 근거 없는 팀 판단, [확인 필요] = 사실 확인 전.

## 0. 결론

1. **가장 큰 채널은 앱 자체다.** 아침 꿈 카드·이레 두루마리 영상·링크 페이지(`mongmang.ink/m/{코드}`)가 유저 손으로 퍼지는 구조가 이미 만들어지고 있다(B3·C7). 마케팅은 이 공유물이 처음 나갈 때 "볼 사람"을 미리 모아 두는 일이다.
2. **무예산이 기본이다.** 돈 대신 쓰는 것은 ① 플랫폼 편집팀(Apple 추천·Google 인디 코너) ② 매일 쌓는 '개발자의 몽망이' 기록 ③ 서예·코지·ASMR 크리에이터에게 무료 빌드 보내기 ④ 한국 인디 행사다.
3. **채널은 다섯 개만 직접 운영한다**(10절 오너 결정 ①): Threads(한), Instagram(한·영), TikTok·YouTube Shorts(같은 세로 영상 하나로), Bluesky(영). X·Reddit·한국 커뮤니티는 운영하지 않고, 정해진 날에만 규칙에 맞게 올린다.
4. **콘텐츠의 주연은 세 가지뿐이다**(number-one 3-2 홍보 주연 규칙): ① 눈이 열리는 얼굴 ② 내 획이 몸이 되는 과정('획 → 몸') ③ 아침 꿈 카드. 이 셋을 매일 한 장, 매주 한 편 영상으로 돌린다.
5. **지금 시작할 수 있는 일은 계정·핸들 확보와 '개발자의 몽망이' 첫 장**이다. 영문명(12-05 확정)이 정해지기 전에는 영어 핸들을 확정하지 않고, 후보만 잡아 둔다.

## 4. 채널별 계획

### 4-1. 직접 운영하는 채널 (5개)

| 채널 | 역할 | 대상 | 형식 | 빈도 | 시작 | 측정 |
|---|---|---|---|---|---|---|
| **Threads (한)** | 빌드 인 퍼블릭 본거지 | 한국 2030, 인디·다꾸·서예 관심층 | 카드 1장 + 한 줄, 가끔 짧은 개발 이야기 | 매일 아침 1개 | P0 | 팔로워, 저장·리포스트 |
| **Instagram (한·영)** | 그림 보관함 + 릴스 | 다꾸·문구·캘리그래피, 해외 수묵 팬 | 피드 = 카드 4:5, 릴스 = 세로 영상, 스토리 = 9:16 카드 | 피드 주 3, 릴스 주 1~2 | P0 | 릴스 재생·저장, 프로필 링크 클릭 |
| **TikTok + YouTube Shorts** | 처음 보는 사람에게 닿는 곳 | 코지 게임·ASMR·힐링 시청자 | 같은 세로 영상 하나를 두 곳에. 첫 1초 = 눈이 열림, 8~15초 | 주 2 | P1 | 재생 수, 완주율, 댓글의 "이거 뭐예요" 수 |

| **링크 페이지 `mongmang.ink`** | 모든 채널의 도착점 | 전부 | 소개 1화면 + 스토어 버튼 + 프레스킷 링크. 출시 전엔 "겨울에 만나요" + 테스터 안내 | 단계마다 교체 | P0 | 스토어 버튼 클릭(식별자 없는 집계, B0 방식) |

- 자동화: Threads 자동 게시 인프라를 **몽망이 전용 계정·토큰으로 분리**해 재사용한다(기존 다른 앱 계정과 섞지 않음). Bluesky는 같은 글의 영어판. Instagram·TikTok은 영상 편집이 들어가 반자동(팀이 파일·캡션 준비 → 오너가 올림, 또는 공식 예약 기능) [확인 필요: 각 플랫폼의 예약 게시 API 범위].
- **말투**: 다른 앱의 '친구 반말체'를 쓰지 않는다. 몽망이 톤(1절)으로 쓴다.

## 5. 콘텐츠 기둥과 주간 루틴

| 기둥 | 무엇 | 빈도 | 채널 |
|---|---|---|---|
| **'개발자의 몽망이 · N째 밤'** | 개발자가 실제로 키우는 몽망이의 그날 아침 카드 1장 + 한 줄 관찰 | 매일 07시 | Threads·Bluesky, 주 3장은 Instagram 피드 |
