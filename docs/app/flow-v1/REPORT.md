# 앱 흐름 v1.1 (MVP) — 하루를 플레이할 수 있는 흐름 + 독립 리뷰 반영

- 작성: 앱 개발자 / 2026-11-20 / 리뷰: docs/team/reviews/2026-11-20-app-flow-review.md

## 0. 정정(v1 판)
- v1은 OPERATING 4절 품질 관문을 하지 않았는데 적지 않았다 → v1.1에서 실시(6절).
- v1 캡처 글꼴은 맥 웹 대체 글꼴이었다(네이티브는 시스템 고딕) → v1.1에서 Gowun Batang·Pretendard 번들.
- v1의 17번과 18번은 같은 파일이었다 → 연속 캡처 19-lift-0..4로 대체.

## 1. 의존성
- 네이티브(SDK 58): react-native-mmkv 4.3.2, react-native-nitro-modules 0.37.2, expo-notifications, expo-audio, expo-haptics, expo-font, react-native-safe-area-context 5.11.1.
- JS 에셋: @expo-google-fonts/gowun-batang 0.4.1(8.4MB, 서브셋 필요), pretendard 1.3.9. 둘 다 OFL, 라이선스 원장 3절.

## 2. 화면 흐름
인트로(설치 = 첫 탭, 설치 판정 = 세이브 존재) → 낮 홈(사물이 순서대로 등장, 이미 그은 날은 sim.strokeBlock으로 붓 진입 전에 부드럽게 거절) → 한 획(알약 버튼 제거, 젖은 자국, 대체 입력은 스크린리더·노트 설정일 때만) → 밤(조수 → 안심 문구 → 처음 재운 밤에만 알림 사전 문구) → 아침(수면 위 몽망이 + 젖은 한지, 건져 올리기) → 공방 노트(먹·한지 토글, 배경 페이드). KText로 어절 단위 줄바꿈, SafeAreaProvider.

## 3. 저장 (D-13)
검증 후 쓰기, 저장소 예외는 던지지 않고 메모리로 계속 + 노트 안내. 백업 하루 한 번(깸 직후), 깨진 원문 2개, 마이그레이션 전 원문 보존, 본·백업 모두 깨지면 lostSave 안내.

## 4. 소리·알림
환경음은 resume·소리 재켜기 때 되살린다. 알림은 작업 큐 + 고정 id로 하나만, 노트에서 끄면 취소, 정산 잠으로는 묻지 않는다.

## 5. 검증
typecheck 통과, test core 119 / mobile 25, expo-doctor 20/20. 웹 흐름 25장 + 품질 관문 75장(폭 320·360·390·412·430 × 글자 100·150·200% × 낮·긋기·노트·밤·아침), 콘솔 에러 0, 터치 영역 겹침 0. 웹 글자 배율은 ?fs= 흉내. 실기기 미확인.

## 6. 남은 것
인화 카드 통합(카드 v1은 구도 수정 중), 해질녘 시각 질문, 마름 표현, 원 그리기 먹 갈기, 카드 저장·공유, 영어, 스크린리더 대체 획 입력, 원샷 플레이어 풀, Gowun Batang 서브셋, 실기기(소리 지연·덕킹, 알림, MMKV 백업 포함 여부, 줄바꿈), 오른쪽 위 짧은 획이 바닥 띠로 미끄러짐, 카피 검수.
