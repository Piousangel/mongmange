## 1. 문법
간밤 획이 물에 풀려 한지에 찍힌 한 장(스미나가시). 넓이를 보존하는 방울 사상(Jaffer & Lu)을 픽셀마다 역으로 되짚는다.
- ① 동심 고리(먼저 떨군 방울이 바깥, 금박 실선 2줄) — boldness: 고리 수·농담·회청→흑
- ② 모티프 형상(물 위 조작만) — closeness: 다른 방울, curiosity: 뻗음
- ③ 몽망이 실제 획(D-13 점열) 빗질 — 획 속도 → 끄는 세기
- ④ 결(숨 2~3번 + 소용돌이) — tempo: 너울/잔물결
- ⑤ 빈 자리: 감은 눈 몽망이
- 테두리: 밤 물 위 손뜬 한지, 세로 "몽망이·이레째", 아침 문장, 일곱 날 점, ~~몽망이 실루엣 낙관~~ **주사 '몽' 인장(이 빠짐 무늬)** [개정 11-20, 7절]
- 모티프 10: 이불(누빔), 찻잔(위에서 본 잔+손잡이), 창가의 손(맞댄 방울 4개 창살), 찻잔 둘, 산(능선 들어올림), 바다(몽망이 아래 물띠), 별(먹점·금점), 손잡고 본 바다, 비(끌린 먹점), 달(큰 맑은 방울+금박 테)
- 결정성: 시드 FNV-1a(카드 필드 + 획 점열·부착), Math.random·시각 없음. 같은 입력 PNG 바이트 동일.

## 6. 리뷰 반영 (v1.1, docs/team/reviews/2026-11-20-dream-card-review.md)
- 필수: 셰이더 지연 생성 + 실패 시 평평한 담묵 폴백(lazyEffect.ts), uniform 총 194 vec4(≤200 테스트 고정), 동어반복 테스트 → 해시 스냅샷 3개, 자르기는 바깥 고리 보존 + `trimmed` 감지(전 조합 0 테스트).
- 구도: 고리 중심을 몽망이 밖으로(테스트 고정), 맑은 자리는 몸 크기 하나. 찻잔 = 옆에서 본 잔 + 김으로 오르는 마블링, 찻잔 둘 = 두 잔과 꼬인 김, 이불 = 누빔 위 잘린 호, 달 = 소용돌이 굽이에 앉은 몽망이, 빗소리 = 비구름 호, 바다 둘 분리.
- 정리: 게 집게 회색 호 제거(획 옷은 카드에서 뺌), 가로 끌림 글리치 완화, 9:16 인화 반경 0.43, rain_b 아티팩트 제거, 글꼴 Gowun Batang(아트 바이블 6절 본명조·Cormorant와 다름 — 주석 기록).
- 직접 본 판정: 과녁 읽힘 해소 7/10(찻잔·찻잔 둘·달·산·바다·손잡고 본 바다·창). 남음: 이불 a(빈 타원), 빗소리 a·b(넓은 빈 면), 별 c. 05a 섬유 밀도에는 아직 못 미침.
- 결정성 주장은 "같은 환경에서 장면 동일"로 낮춤(플랫폼 간 픽셀 동일은 보장하지 않음).
- 검증: typecheck 통과, test core 123 · mobile 30, 캡처 오류 0. 실기기·네이티브 글꼴 미확인.

## 7. 세 기둥 통합 반영 (v1.2 문법, 11-20 — 근거 D-20, `docs/design/pillars-v1/C-integrated.md` v1.1 9절 #24)
- **아래 띠 = 공유 꼬리표**: `{이름} · {먹} · {결}` + 인장. 예: `몽실 · 송연먹 · 느긋결`. 이름이 없으면 `몽망이`, 이레 전에는 결을 빼고 `{이름} · {먹}`. 화면·카드 어디에도 '유형'이라는 말을 쓰지 않는다. 앱 이름·도메인은 `text-sub`로 그 아래.
- **실루엣 낙관 → 인장**: 테두리의 몽망이 실루엣 낙관은 [대체됨]. 주사 '몽' 인장 하나(테두리 16칸 이 빠짐 무늬가 씨앗에서 나옴)가 카드의 유일한 강조색이다. **인장 코드(`K7M3-QX9P`)는 이미지에 넣지 않는다**(공유 글 링크·이름표 길게 누르기에만).
- 금박(`gold`)은 강조색이 아니라 선 장식이다(아트 4절 v1.3). 카드의 금박 실선 고리는 그대로 두고, 획 층 가시성(첫 두름 금박 테)은 1주차 작업(D-18 개정).
- 세로 이름은 아트 6절 v1.3을 따른다(이름이 있으면 이름만 + 작은 두 번째 줄 날 세기).
- 구현은 빌드 2(M2·M3, 기능 플래그). 이 판에서는 문법만 고쳤고 코드·캡처는 바꾸지 않았다.
- 변경 이력: 11-20 7절 추가·1절 테두리 낙관 표기 개정(근거 D-20).
