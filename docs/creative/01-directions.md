# 01. 크리에이티브 디렉션 3안 — 몽망이 키우기

- 작성: 크리에이티브 디렉터 / 2026-11-19
- 전제: 첫 시안(`docs/research/art-sketches/` A 모찌·B 새싹콩·C 꿈 솜뭉치)은 "흔한 카와이 젤리"라 기준 미달 판정. 이 문서는 그 방향(동그란 덩어리 + 큰 눈 + 파스텔 + 볼터치)을 **쓰지 않는다**.
- 기준: 오너 지시 "독창적이고 세련되고 우아해야 한다"(OPERATING.md 0-1). 기획 1순위 컨셉 "꿈 반죽 몽망이"(01-game-design-market.md 4.1)와 하루 루프(4.2), 숨은 성향 축(4.3)을 그대로 받는다.
- AI 이미지는 **탐색·레퍼런스 전용**이다(OPERATING 0-1, 04-art-sound 1절). 출시 에셋은 팀이 정한 형태 언어로 코드·벡터로 다시 만든다. 생성 기록은 부록 B에 남겼다.

## 0. 결론

1. 세 안을 **재료**로 갈랐다. 흙(고체, 빚기) / 실(선, 잇기) / 먹(유체, 번지기). 셋 다 "반죽"을 다르게 해석하므로 기획 컨셉과 충돌하지 않는다.
2. **추천: A "분청 꼬집"**. 기울어진 원뿔 끝을 한 번 꼬집어 말아 올린 날흙 생물이다. 하루 동안 손으로 만진 흔적이 분청 기법(귀얄·인화·상감·덤벙) 무늬로 남고, 밤마다 꿈 가마에서 유약이 한 겹씩 쌓인다.
   - 이유 ① "반죽"과 조작(꼬집기·쓰다듬기)이 하나로 이어진다. ② 실제 분청 기법 목록을 그대로 무늬 파츠 카탈로그로 쓸 수 있어서, 수백 가지 변형을 일관되게 만들 수 있다(A3, A4에서 실증). ③ 키우기 장르에서 한국 도자 미감을 쓴 예를 찾지 못했다. 글로벌 시장에서 차별점이 된다.
3. A의 가장 큰 위험은 **실루엣이 놈(gnome) 모자나 키세스 초콜릿처럼 읽히는 것**이다. 비율 규칙(5.1)으로 막고, 다음 단계에서 실루엣 블라인드 테스트를 한다.
4. B는 구현이 가장 쉽고 "실 = 하루 타임라인"이라는 UI 발명이 좋다. 다만 몸이 선이라 쓰다듬는 맛과 애착이 약하다. C는 그림이 가장 아름답지만 생물이 올챙이·유령처럼 읽히고 늘 밤이라 질릴 위험이 있다. 두 안에서 각각 하나씩만 가져와 A에 붙인다(5.3).

## 1. 레퍼런스에서 뽑은 "우아함의 원칙"

| Sky: Children of the Light | 몸짓과 소리로 소통하고 텍스트를 최소로 줄인다. 망토가 2차 동작을 한다 | 몽망이 말버릇은 **소리·몸짓 우선**, 글은 꿈 일기에만 |
| Florence | 인터랙션이 곧 감정이다(퍼즐 조각이 대화 리듬이 된다). 글 없는 장면이 있다 | **핵심 조작 하나가 감정을 전달한다** |
| Old Man's Journey | 손으로 그린 질감, 땅을 끌어 올려 길을 만드는 조작 | **풍경을 직접 만지는 조작** |
| Behind the Frame | 사물에 가까이 다가간 화면, 붓과 물감이 메뉴 역할을 한다 | **도구 = 메뉴**(diegetic) |
| Hohokum | 선 하나로 된 주인공, 목표 없는 탐색, 색면 | 선의 리듬. B안의 출발점 |
| Cats & Soup | 정적인 장면을 짧은 반복 애니메이션으로 살린다. 방치형 수익 구조를 썼는데도 아트가 단정하다 | **작고 느린 반복 모션**이 아이들 상태를 만든다 |
| 지브리·커비의 질감 계열 | 손맛 나는 재질(털실·점토·종이)이 "만질 수 있을 것 같은" 감각을 준다 | **재질이 귀여움보다 먼저**다 |
| Apple Design Award 계열(Alba, Wylde Flowers, (Not Boring) 앱들) | 촉감 있는 마이크로 인터랙션, 햅틱과 소리를 짝지어 설계한다 | **햅틱·소리·모션을 같은 타이밍표로** 설계 |
| 일본 그래픽(하라 켄야·무인양품) | 비어 있음(엠프티니스)이 품질 신호가 된다. 소재가 그대로 보인다 | 화면의 **60% 이상을 비워 둔다** |
| 북유럽 그래픽·공예 | 낮은 채도, 기능에서 나온 형태, 선명한 강조색 하나 | **강조색은 한 화면에 하나** |
| 한국 도자(분청·백자·청자), 한지, 자수 | 불완전한 붓질, 우연이 만든 흘러내림, 손자국 | **우연 + 규칙**으로 개체마다 다른 무늬를 만든다 |

**우아함 체크리스트 (모든 시안 공통)**
1. 여백: 주인공이 화면 넓이의 15~25%만 차지하고, 위쪽 절반은 비워 둔다.
2. 절제된 팔레트: 바탕 1, 몸 1~2, 잉크 1, 강조 1. 강조색은 한 화면에 한 곳만 쓴다.
3. 모션 리듬: 빠른 반응(100~200ms) 다음에 느린 여운(800~1600ms)이 온다. 통통 튀는 스프링을 남발하지 않는다.
4. 타이포: 작게, 자간을 넓게, 문장은 하나만. 굵은 둥근 고딕은 쓰지 않는다.
5. 사운드와 UI 결합: 화면에 눈에 보이는 버튼 소리가 아니라 **재료의 소리**를 낸다.
6. Diegetic UI: 메뉴·버튼·HUD를 세계 안 사물로 만든다. 다만 **접근성 대안(길게 누르면 이름 표시, 스크린리더 라벨, '목록으로 보기' 설정)**을 반드시 둔다. 사물형 UI의 고질병은 "어디를 눌러야 할지 모른다"이다.
7. 금지 목록: 코인 더미, 빨간 알림 배지, 진행 막대, 무지개 그라디언트, 둥근 젤리 몸 + 큰 반짝이 눈 + 볼터치.

## 2. 디렉션 A — 분청 꼬집 (Buncheong Pinch) ★추천

| 항목 | 내용 |
|---|---|
| 한 줄 콘셉트 | **꿈 흙 한 줌을 꼬집어 빚은 생물.** 하루 동안 만진 손자국이 무늬로 남고, 밤마다 꿈 가마가 유약을 한 겹 입힌다. 꿈 흙은 끝내 굳지 않는다 |
| 형태 언어 | 바닥이 넓고 평평한 **기울어진 원뿔** + 끝을 한 번 꼬집어 말아 올린 **꼭지(curl)**. 얼굴은 몸 아래쪽 15% 지점에 음각 점 두 개와 짧은 선 하나. 실루엣 파라미터는 키·바닥 폭·기울기·말림·꼭지 수(1~2)·비틀림. 0일차는 꼭지가 거의 없는 "날흙 한 덩이"다 |
| 세계·배경 | 새벽빛이 드는 작은 공방 벽과 참나무 선반 하나. 선반 위에는 붓 꽂힌 청자 컵, 나무 근개(주걱), 가마 온도계, 유약 시험편이 있다. 계절이 바뀌면 창문 그림자 모양이 바뀐다 |
| 팔레트 | 회흙 `#8F8A82` / 분장 백토 `#EFE9DD` / 청자 비색 `#9FB8A6` / 철화 갈색 `#5A3E2E` / 석회벽 `#F4EFE6` / 강조 감빛 `#C9774E`(한 화면에 한 곳) |
| 질감 | 무광 석기 알갱이(Skia 노이즈 셰이더), 백토 붓질 자국, 유약 흘러내림(광택 1단계), 지문 음각. 셰이딩은 왼쪽 위 광원에 2톤 + 그레인만 쓴다 |
| 타이포 | 한글 본문: 고운바탕 또는 마루 부리(둘 다 OFL). 영문: EB Garamond·Cormorant(OFL). 철화 갈색으로 작게 쓴다. 날짜는 "Day 12" 한 줄, 그날의 시 한 줄 |
| UI 철학 | **선반 위 사물 = 메뉴.** 붓 컵 = 돌봄, 근개 = 빚기, 가마 온도계 = 하루 진행과 남은 시간, 유약 시험편 = 꾸미기·도감, 선반 끝 소포 꼬리표 = 하루 선택(외출). 시계 숫자 대신 **벽 그림자 각도**가 실시간 시각을 보여 준다. 설정은 공방 노트 안에 둔다. 사물은 길게 누르면 이름이 뜨고, 설정에서 '목록으로 보기'를 켤 수 있다 |
| 핵심 인터랙션 | **꼬집고 쓰다듬기.** 두 손가락으로 집어 당기면 꼭지가 늘어나거나 말린다(기울기·말림 파라미터가 살짝 영구 변화). 한 손가락으로 쓸면 그 궤적이 그대로 백토 붓질(귀얄)로 몸에 남는다. 그날 만진 방식(오래·짧게·톡톡·쓸기)이 성향 축 입력이 된다 |
| 모션 원칙 | 흙에는 무게가 있다. 빠르게 눌리고(120ms) 천천히 돌아온다(900ms, 감쇠 높게, 튀는 반동 없음). 아이들 모션은 3~4초 주기로 꼭지가 살짝 들썩이는 숨쉬기. 아침 연출은 가마 문이 열리고 김이 걷히면 새 유약 한 겹이 드러나는 것 |
| 사운드 톤 | 흙 문지르는 마찰음, 근개가 선반에 닿는 나무 소리, 그리고 시그니처로 **가마에서 막 나온 도자기가 식으며 내는 '틱틱' 빙열음**(아침 결과 알림음). BGM은 실내 공기음 위에 첼로나 가야금 한 줄 |
| 왜 다른가 | 키우기 게임의 "먹이 → 수치 → 진화"를 **"만진 흔적 → 무늬 → 유약"**으로 바꾼다. 결과물이 캐릭터이면서 공예품처럼 읽히고, 공유 카드가 '도자 사진'처럼 나와 SNS 공유 맥락이 장르 밖(공예·인테리어)까지 넓어진다 |

## 3. 디렉션 B — 한 가닥 (One Thread)

| 항목 | 내용 |
|---|---|
| 한 줄 콘셉트 | **꿈에서 풀려나온 실 한 가닥이 몽망이다.** 한 번도 끊기지 않은 선이 고리를 짓고 매듭을 지으며 자란다. 하루가 한 땀씩 수놓인다 |
| 형태 언어 | 연속 스플라인 하나. 머리 고리 + 몸 나선 + 꼬리 실 끝. 성장은 고리 수와 나선 감김 수로 보여 준다. 기억은 매듭(프렌치 노트)이 되고 성향은 실 색이 바뀌는 구간이 된다. 덩어리가 없는 몸이라 실루엣이 장르 안에서 독보적이다 |
| 세계·배경 | 수틀에 걸린 생리넨 한 폭. 화면을 가로지르는 실이 곧 오늘의 길이다 |
| 팔레트 | 생리넨 `#E9E1D3` / 쪽 `#233A73` / 치자 `#D9A43A` / 꼭두서니 `#B5482F`(강조) / 먹선 `#2A2622` |
| 질감 | 리넨 직조(타일 텍스처), 실 꼬임(stroke 위 사선 대시), 바늘구멍 그림자 |
| 타이포 | 단정한 그로테스크(IBM Plex Sans KR / Inter), 쪽빛, 작게. 자수 글리프 아이콘 |
| UI 철학 | **실 = 타임라인.** 홈의 가로 실 위에 아침 매듭(꿈 결과), 홈질 점선(외출 중), 십자수 별(저녁)이 놓인다. 하단 네비게이션은 바늘·실패·가위 자수 3개. 천을 위로 감아 올리면 지난날이 자수 두루마리(일기·도감)로 이어진다 |
| 핵심 인터랙션 | **실 당기기.** 꼬리 실 끝을 끌어 새 고리를 짓고, 길게 누르면 매듭이 생긴다. 당긴 방향과 장력이 성향 입력이 된다 |
| 모션 원칙 | 선이 그려지는 trim-path 애니메이션, 실 장력을 경로 위 스프링으로 표현, 꼬리 실 끝의 2차 흔들림 |

| 왜 다른가 | 키운 기록이 곧 몸이다. 30일을 키우면 그 30일이 한 폭의 자수로 남는다 |

## 4. 디렉션 C — 먹 한 방울 (Ink Drop / Suminagashi)

| 항목 | 내용 |
|---|---|
| 한 줄 콘셉트 | **잠의 수면 위에 떨어진 먹 한 방울.** 하루의 상호작용이 물결로 섞여 몽망이 둘레의 마블링 고리가 된다. 아침에는 한지를 얹어 간밤의 꿈을 찍어 낸다 |

### 5.1 A를 추천하는 이유와 조건
- **추천 A.** 조작(꼬집기·쓰다듬기), 세계관(꿈 흙·꿈 가마), 파츠 체계(실제 분청 기법)가 하나의 은유로 묶인다. 셋 중 "반죽"을 가장 정직하게 구현한다.
- **통과 조건 (다음 단계 관문)**
  1. **실루엣 블라인드 테스트**: 검은 실루엣 8종을 외부 5명에게 보여 주고 "놈 모자·초콜릿·양파" 응답이 2명 이상이면 비율을 고친다. 바로 할 수 있는 비율 규칙은 다음과 같다. 몸 높이 ÷ 바닥 폭은 1.1~2.2 사이로 둔다(0일차만 예외로 1.0). 기울기 하한을 둬서 좌우 대칭 원뿔을 금지한다(대칭이면 모자로 읽힌다). 꼭지는 반드시 **앞으로** 말린다(뒤로 말리면 놈 모자).
  2. **얼굴 가독성**: A4에서 음각 점 눈이 폰 크기에서 너무 작다. 360pt 폭 화면 기준으로 눈 지름 하한을 4pt로 정하고, 표정 6종(기본·기쁨·졸림·놀람·시무룩·집중)이 점·선만으로 구분되는지 시트로 검증한다.
  3. **질감 격차 해소**: Skia 런타임 셰이더로 석기 그레인 + 백토 붓질 마스크 + 유약 광택 1단계를 만들어, A4가 A3의 70% 수준까지 오는지 비교 캡처로 확인한다. 못 미치면 몸 질감만 사람이 그린 텍스처 아틀라스(외주 1회)로 보강하는 안을 검토한다.
  4. **사물 UI 발견성**: 처음 켠 사람이 30초 안에 "붓 컵 = 돌봄"을 찾는지 테스트한다. 못 찾으면 첫날에만 사물이 순서대로 숨쉬듯 빛나는 안내를 넣는다(글 안내는 쓰지 않는다).

### 5.2 버린 안과 이유
- B: 구현은 가장 싸지만, 키우기 게임의 핵심인 **만지는 애착**이 약하다.
- C: 가장 아름답지만, 생물이 "귀엽다"보다 "신비롭다·조금 무섭다"로 읽힌다. 13세 미만이 볼 가능성과 낮 시간 플레이를 생각하면 위험하다.

### 5.3 A에 흡수할 것
- **B에서**: "실 = 하루 타임라인"을 **선반 가장자리를 따라 이어진 유약 흘러내림 자국 한 줄**로 바꿔 하루 진행 표시로 쓴다. 지난날 기록은 '시유 시험편 묶음'(도감)으로 남긴다.
- **C에서**: "아침에 한 장 인화되는 결과물"을 **가마에서 나온 시험편 한 장**(그날 생긴 무늬 + 꿈 일기 한 줄)으로 바꿔 공유 카드로 쓴다.
